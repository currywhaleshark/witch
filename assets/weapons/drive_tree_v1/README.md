## 원본과 연결 계약

Blender 5.1.1 / MCP addon 1.8 protocol 15의 live 안전 모드에서 제작했다. `DriveV1_<id>` 아홉 장면이 새 자산이다. 같은 파일에 보존된 이전 화기 장면은 이번 자산이 아니다. 메시는 정점 위치와 회전축을 미터 단위로 저장하며, 내보내기에서만 원본 loop triangle 배열과 코너 노멀을 사용해 삼각화한다.

- `tools/build_drive_tree_v1.py`: 형상 제작. 새 장면에 `build_asset(id, rest)`로 만든다. 기존 장면을 자동 덮어쓰지 않는다. 장비용 `rest`는 `reports/drive_tree_v1/rest_frames.json`의 현재 몸체 본 좌표다.
- `tools/create_drive_trim_v1.py`: 재현 가능한 공유 트림 텍스처 생성.
- `tools/materialize_drive_tree_v1.py`: live MCP에서 `export_one(id)`와 `save()`로 재질 연결·내보내기·저장.
- `tools/package_drive_assets_v1.py`: 런타임의 텍스처를 공통 파일로 분리하며 형상·탄젠트 유지를 확인.
- `game/tests/helpers/drive_tree_demo.gd`: 검토 전용 조립/작동 샘플. 본편에서는 사용하지 않는다.

GLB는 Godot Y-up, -Z 전방, 미터 단위다. 소켓의 위치/방향, 각 부품의 `group`, `delay`, `attach_bone`는 JSON에 있다. 모델의 원점은 배치 기준이며, 회전은 해당 소켓을 중심으로 행렬을 적용한다. 개별 부품 원점을 임의로 옮기거나 부품에 비균일 스케일을 적용하면 링크/조립이 어긋난다.

단두대의 `drop` 그룹은 가이드 안에서 내려간다. 압착기의 `platen`은 전체 스트로크, `platen_stage`는 절반 스트로크만 이동해 피스톤이 끊어지지 않는다. 집행기는 `gate_*` 힌지와 `arm_*`, `saw_*` 소켓을 별도로 사용한다. 윈치의 드럼·갈고리는 강체이며 줄만 길이가 달라진다. 광역 볼트커터는 현재 지팡이의 장착 프레임을 유지한 별도 큰 날이고, 링크의 길이를 보존한 회전으로 닫힌다. 검토용 타이밍과 스트로크는 게임 밸런스가 아니다.

`exports/*.glb`에는 텍스처가 내장돼 있다. `game/assets/weapons/drive_tree_v1/*.glb`는 옆 `textures/` 폴더를 참조하므로 함께 이동해야 한다. 아홉 모델은 색 1K + OpenGL 노멀 1K + ORM 512 + 발광 256을 공유한다. 색/발광은 sRGB, 노멀/ORM은 Non-Color이며 ORM은 R=AO, G=거칠기, B=금속이다. 일반 표면과 코어 발광을 분리하고 각 부품은 한 재질 표면만 사용한다. 여덟 트림 영역의 평면 UV 반복은 의도적이며 고유 베이크 UV가 아니다. RGBA8 전체 밉 가정 텍스처량은 약 12.3MiB이며 측정한 최고 GPU 메모리가 아니다.

## 외골격 부착과 남은 간섭

현재 플레이어의 `Skeleton3D`에 `pose_global * inverse(rest_global) * part_rest`로 각 부품을 붙인다. 캐릭터의 몸체·107개 본·의상·모션·지팡이를 변경하지 않는다. 등판은 `DEF-chest`, 정강이는 `DEF-shin.*.001`, 좌상완은 `.002`, 우상완은 `.001`, 전완 장치는 기본 `DEF-forearm.*`, 왼쪽 손목 고리는 `.001`에 붙는다. 중간 비틀림 본을 모든 전완 부품에 쓰면 달릴 때 소매 안으로 회전하므로 피한다.

손과 허벅지를 비워 지팡이 잡기와 치마를 가리지 않는다. 손목은 손바닥 쪽이 열린 C형 부품이다. 장착 조립도 현재 본 포즈로 변환하며 완료 시 rest pose로 튀지 않는다. 이 원칙은 검토 코드에 구현돼 있지만 본편 장비 시스템에는 아직 연결하지 않았다.

평상복·변신복 각각 대기/달리기/휘두르기/찌르기/캐스팅/경직/스프링 점프/쓰러짐을 13시점으로 샘플링했다. 실제 Godot 본 포즈를 저장하고 두 의상 GLB의 전체 스킨 가중치로 변형한 표면과 프레임을 교차 검사했다. **208개 중 26개 자세에 옷 관통이 남는다.** 대기·달리기·경직의 검사 시점은 통과했고, 찌르기에서 각 의상 9개, 휘두르기 각 2개, 캐스팅 각 1개, 변신복 점프/쓰러짐 각각 1개가 남는다. 간섭이 있는 시점은 리뷰에서 표시한다. 헤어·맨몸·임의 포즈·연속 충돌 검사는 하지 않았다. 외골격은 이 제한을 포함한 검토 후보이며 전체 모션의 의상 간섭 해결본이 아니다.

## 검증과 범위

저장 Blender 원본과 실제 GLB 재반입에 형상 QA를 적용했다. 장착 부품은 부착 본별로 검사한다. 허용 경고는 반복 트림 UV, 평면 캡 n-gon, UV/노멀 경계의 분리 정점, 장착 프레임의 지면 밖 원점, 내부 기둥 칼라 및 독립 조립 부품의 숨은 접합면이다. 상세 판정은 `reports/drive_tree_v1/qa_adjudication.json`에 있다.

Godot 39,796개 검사에서 부품/삼각형 수, 강체 스케일, 유한 변환, 시간 역방향 스크럽 재현성과 윈치 분기를 확인했다. 1,516장 실제 GPU 캡처에는 1.75× 카메라의 1280×800 크기 비교, 9종 기구, 두 의상의 장착 조립 및 전투 포즈가 포함된다. 53개 기존 게임 코드·스킬 문서·기존 자산 기준 파일 해시를 보존했다. 최종 입력/출력 해시는 전달 명세에 있다.

환경의 사용자 셰이더 캐시·에디터 설정 저장 실패와 background Blender의 Tripo 종료 타임아웃은 로그에 남아 있으며 검사/렌더는 완료됐다. 새 적 상호작용, 피해/자원/시전 규칙, 지형·벽·부품 간 충돌, 물리식 케이블, 실시간 천/헤어 및 최종 성능은 별도 작업이다. 사용자 아트 선택이나 커밋은 아직 없다.
