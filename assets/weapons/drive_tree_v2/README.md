# 구동 장치 동작 수정 v2

2026-11-03. [동작 비교와 새 외골격 리뷰](../../../reports/drive_tree_v2/review.html).
**준비 자산과 검토용 동작**이다. 신규 스킬의 피해·적 구속·시전 시간을 본 게임에 연결한 단계는 아니다.
기존 v1 원본과 리뷰를 보존한다.

## 수정 내용

- 낙하/고정 단두대의 날 끝을 바닥 위 2mm까지 내린다. 두꺼운 받침을 앞뒤로 나눠 폭 100mm의 통로를 만들고 양쪽 발을 70mm씩 넓혔다. 톱날형도 회전 반경을 고려해 같은 높이에 도달한다.
- 고정형은 구속구만 먼저 생성하여 닫고, 닫힌 구속구를 유지하면서 기둥과 칼날을 조립한다. 구속구는 날의 통로에서 뒤로 130mm 옮겼다.
- 복합 집행기는 문 닫기 → 압착 → 프레스 상승 → 양쪽 톱 진입으로 바꿨다. 톱은 프레스가 올라오는 동안 진입하고, 압착 중에는 팔을 0.08rad 바깥에 대기시켜 프레스 가장자리와 겹치지 않게 한다. 집행기 모델은 v1을 그대로 사용한다.

| 파생 모델 | 강체 부품 | 삼각형 | 낙하 거리 |
|---|---:|---:|---:|
| 단두대 | 27 | 3,732 | 1.298690m |
| 회전 톱날형 | 27 | 6,532 | 1.019203m |
| 고정형 | 31 | 4,220 | 1.298690m |

새 파생 메시 합계 85개 / 14,484 삼각형. `drive_tree_v2.blend`의 `DriveV2_*` 장면이 원본이다.
`exports/`는 텍스처가 내장된 GLB, `game/assets/weapons/drive_tree_v2/`는 v1 공통 텍스처를 참조하는 GLB와 부품 명세다.
런타임 경로의 `../drive_tree_v1/textures/` 의존성을 유지한다.

## 검토용 시각

| 동작 | 시각 |
|---|---|
| 일반 칼날 낙하 | 1.00–1.24초 |
| 회전 톱날 하강 | 1.00–2.50초 |
| 고정형 구속구 생성 / 닫힘 | 0–0.28초 / 0.30–0.56초 |
| 고정형 본체 조립 / 칼날 낙하 | 0.60–1.25초 / 1.40–1.64초 |
| 집행기 압착 / 유지 | 1.10–1.45초 / 1.55초까지 |
| 집행기 프레스 상승 / 톱 진입 | 1.55–2.10초 / 1.92–2.45초 |
| 소멸 | 2.85–3.35초 |

이 시각은 연출 검토값이며 스킬 문서의 전투 규칙을 대체하지 않는다.
`game/tests/helpers/drive_tree_v2_demo.gd`를 후속 연결의 기준으로 사용한다.
리뷰의 단일 적은 기존 `rag`를 0.60배로 세운 정지 참고 모델이다. 실제 적 AI/속박 판정은 없다.

## 검증과 범위

- 저장 Blender와 GLB 재반입 형상 QA: 세 파생 모델 모두 오류 0.
- 120fps 시점 검사: 107,791개 assertion 통과. 강체 변환, 칼날 끝 높이, 구속구 우선 조립/고정, 프레스 상승과 톱 간격, 역방향 스크럽을 확인했다.
- Godot 실제 GPU 캡처 388장. **화면 왼쪽 v2 / 오른쪽 v1**이다. 카메라가 +Z 방향을 바라보기 때문에 world +X가 화면 왼쪽이다.
- 반복 트림 UV, 변형 없는 평면 캡, 독립 조립 부품의 숨은 접합면, GLB의 UV/노멀 경계 중복 정점은 의도된 경고로 기록했다.
- 지형·벽·적 신체와의 접촉, 실제 물리, 전투 밸런스, 성능 승인과 사용자 아트 승인은 포함하지 않는다.
