# 볼트커터 날 · 개폐 v2

사용자가 제공한 두 볼트커터 사진을 기준으로, v1의 안쪽으로 휜 집게를 **길고 뾰족한 쐐기형 날과 직선 절삭면**으로 바꾼 2026-10-29 검토 후보다. 참고 사진은 `reference/`에 원본 바이트로 보관했다. 실제 제작은 Blender 하드서피스 메시이며 Tripo 생성물로 표기하지 않는다.

- 작업 원본: `authoring/staff_transform_v2.blend`
- 게임과 동일한 GLB: `exports/staff_parts.glb`
- 부품 피벗·조립 순서·개폐 기준: `parts.json`
- 비교/실제 게임 재생: `reports/bolt_cutter_v2/review.html`
- 검증 기록과 해시: 해당 보고서의 `delivery_manifest.json`

## 날과 연결 장치

두 날은 두꺼운 등과 얇게 갈아낸 양면 절삭부를 갖는다. 절삭면은 로컬 Y 0.932–1.226m의 294mm 직선이다. 닫혔을 때 중앙 간격은 2mm로 제한해 양쪽 메시가 교차하지 않는다. 기존보다 날 끝을 길고 날카롭게 과장했으므로 실제 볼트커터의 제조 도면이나 물리 절삭 시뮬레이션은 아니다.

준비 자세는 한쪽 8도, 공격 준비는 한쪽 32도(합계 64도)까지 연다. 최대 날 끝 간격은 로컬 약 406mm다. 고정 피벗의 두 날, 길이를 유지하는 두 연결봉, 왕복하는 아래 연결부가 함께 움직인다. 연결봉은 늘이거나 스킨 변형하지 않는다.

공구는 기존과 같은 7개 강체 메시, 1,908 삼각형이다. 공통 자루와 함께 표시하면 2,936 삼각형, 인장 장식을 더하면 3,068 삼각형이다. 다른 공구와 전환할 때는 빠져나가는 부품의 비용이 일시적으로 더해진다.

## 실제 타격과 동기화

`staff_visual.gd`는 현재 공격 클립의 정규화된 진행률을 사용한다. 0.26에서 크게 열고 0.40까지 유지한 다음, 0.50의 실제 타격에 맞춰 가속하며 닫는다. 0.61까지 닫힌 상태를 유지한 뒤 0.94까지 준비 간격으로 돌아온다. 피격 등으로 공격이 중단되면 그 순간 벌어진 각도부터 부드럽게 돌아온다.

`player_visual.gd`는 캐릭터의 현재 프레임을 먼저 샘플링하고 공구를 갱신한다. v1의 이전 프레임 진행률 사용으로 생길 수 있던 타격 순간의 한 프레임 차이를 없앴다. 휘두르기와 찌르기 모두 같은 실제 release 신호를 쓰며, 피해·비용·속도·공격 범위 규칙은 아레나가 계속 소유한다. 타격 소리는 기존 연출을 재사용한다.

## 보존과 확인 범위

v1 원본과 이전 리뷰를 보존했다. v2의 공통 자루·그라인더·전기톱·장식 45개 메시는 v1 저장 파일의 데이터를 그대로 사용한다. 저장 Blender 재개방 검사에서 좌표·토폴로지·UV·재질 슬롯·트랜스폼이 일치하고, GLB 검사에서도 정점 속성·인덱스·재질 값이 일치한다. 캐릭터 v21의 메시·리그·클립·양손 부착 계약은 수정하지 않았다.

최종 검증은 1,434개 검사와 357장 GPU 캡처다. 30/60fps × IAS 0/40/10000 × 휘두르기/찌르기의 12개 실제 피해 시점에서 모두 닫힘을 확인했다. 101개 자세의 연결봉 핀 최대 오차는 약 0.000062mm다. 매우 빠른 공격에서는 준비 동작 일부 프레임이 생략될 수 있으나, 실제 피해 프레임의 완전 조립과 닫힘은 유지한다.

확대 동작은 실제 손에 부착된 공구의 모션을 그대로 촬영하며, 확인하기 쉽도록 적과 타격 섬광을 카메라 레이어에서 제외하고 조명을 추가했다. 나머지 동작과 실제 게임 크기 화면은 일반 게임 렌더링이다. 기존 공격 두 종류의 성능 동등성과 기본 공구 회귀도 통과했다. 임의 자세의 몸·옷·환경 접촉, 실제 절삭 충돌, 최종 재질·성능 예산 및 사용자 외형 승인은 아직 포함하지 않는다.

재생성은 별도 Blender에서 `tools/build_staff_transform_v2.py`를 실행한다. 사용자 Blender 장면에서 실행하면 장면이 초기화되므로 background `--factory-startup --python-exit-code 1`을 사용한다. `tools/validate_staff_source_v2.py`, `tools/validate_staff_glb_v2.py`로 원본/출력을 검사한다. `tools/run_bolt_cutter_v2.ps1`의 import/test/review와 `tools/package_bolt_cutter_v2.py`가 게임 검사와 리뷰를 만든다.
