## 원본과 좌표 계약

실제 Blender 5.1.1 / MCP 애드온 1.8(protocol 15) 라이브 세션에서 제작했다. 안전 모드 안에서 `bpy`, `bmesh`, `mathutils`만 사용했고, 저장 파일 QA는 별도 백그라운드 Blender로 수행했다. 사용자의 시작 장면 `Scene`은 보존했다. 원본은 자산마다 `FirearmV1_<id>` 장면 하나씩, 전체 배치용 `FirearmV1_Review` 장면이 있다. 리뷰 장면은 원본 메시의 연결 복사본이다.

Godot 기준 미터, +Y 위, -Z 전방이다. 세 총과 기관포는 총구를 원점에 두고 몸통이 +Z로 이어진다. 포탄은 탄두 끝이 원점이다. 기존 총구 위치/피해 선분/시전 및 사격 타이밍을 유지한다. 장총의 임시 비균일 스케일은 제거하고 전용 모델을 원래 크기로 사용한다. 새로운 화승총·장총은 시작 시 그래픽 준비에도 포함했다.

각 메시의 `part_role`, `motion_group`, `assembly_delay`와 JSON의 `parts`는 같은 정보를 담는다. JSON `sockets`의 위치와 방향은 Godot 좌표이다. GLB Empty 소켓은 로컬 +Y 방향이 아니라 **Godot -Z 방향이 소켓 direction을 가리키는 프레임**으로 내보낸다. `use_active_scene=True`와 선택 내보내기를 모두 유지하여 다른 자산이나 리뷰 복사본이 섞이지 않게 한다.

## 다음 스킬 구현에서 쓰는 구조

- **화약통:** 원점은 바닥. 회전 중심은 `(0, 0.248, 0)`, X축으로 굴린다. `drum` 그룹은 판재/끝판/테두리, `fuse` 그룹은 심지 8구간과 끝불이다. `fuse_00`은 뿌리, `fuse_07`은 끝이므로 7→0 순서로 소모한다. 리뷰는 0.9m를 굴리고 심지 소모 뒤 부품을 비산시킨다. 이 시간/거리/폭발은 **스킬 수치가 아니다**.
- **기관포:** `rotor` 그룹의 16개 메시(6총열·6총구 테두리·2연결띠·허브·축)를 소켓 `(0,0,0.42)`의 Z축 주위로 함께 회전시킨다. 나머지 몸체/급탄 드럼/받침은 고정한다. 뼈대 가중치나 부품 늘이기를 쓰지 않는다.
- **연막 발사기:** `Socket_launch_0`~`5`가 각 관의 발사 위치/방향이다. `canister_i`의 탄체와 뚜껑은 함께 이동한다. 별도 `smoke_canister.glb`도 제공한다. 연막 FX, 시야/명중 방해와 탄착 판정은 미구현이다.
- **포격·함포 포탄:** 탄두 -Z, 꼬리 +Z. 포격용 길이 약 0.335m, 함포용 약 0.507m다. `Socket_nose`, `Socket_trail` 사용. 포격/함포 발사대는 만들지 않았다.
- **반동 도약:** 이번 트리에 별도 총기 본체를 중복 제작하지 않았다. 산탄총 모델/총구 소켓을 재사용할 수 있다. 도약 동작·타이밍은 해당 스킬 구현 때 결정한다.
- **장식:** 세 총과 기관포에 독립 장식 소켓을 둔다. 현재 장비 DB나 커스터마이징 UI와는 연결하지 않았다.

동작 예시 코드는 `game/tests/helpers/firearm_tree_demo.gd`이며 게임 본편에서 로드하지 않는다. 판정·자원·RNG가 없고 임의 시간에서 원래 부품 변환을 다시 계산하므로 스크럽/반복이 가능하다. 실제 화승총·장총은 `floating_gun.gd`, 산탄총은 `shotgun_cast.gd`가 기존 조립/취소/반동/해체를 담당한다.

## 검증과 범위

9종 저장 원본과 9종 GLB 재반입의 스킬 QA를 통과했다. 초안 산탄총 총구 테두리 간 겹침을 제거했으며 화약통의 최저점을 바닥에 맞췄다. 자산 계약/소켓 방향/73개 구동 샘플 검사 827개, 기존 화승총 37개·강선 장총 18개·산탄총 205개를 통과했다. 실제 Godot Compatibility GPU 검토는 원거리/확대 실제 전투 장면, 전체 모델 정면/측면, 준비 자산 작동 예시를 포함한다. 정확한 이미지 수와 입력 해시는 전달 명세를 따른다.

허용한 QA 경고는 정적으로만 쓰는 평면 끝막음 n-gon, 공중 모델의 총구/탄두 원점으로 인한 음수 바닥 높이, GLB UV/노멀 경계의 중복 정점이다. 산탄총의 힌지 뒷면과 몸체가 맞닿는 반대 방향 숨은 면은 부품이 분리될 때도 닫힌 형상을 유지하도록 남겼다. 초기 화승 심지의 GLB UV 겹침은 면별 독립 UV로 수정했다. 모두 재반입 오류 0이며 느슨한 정점은 없다. Blender 라이브 전체 재질/와이어 검토와 Godot 실제 이미지 검토를 별도로 수행했다.

환경에서 GPU `user://` 셰이더 캐시 경로와 에디터 설정 빈 경로 경고가 남지만 렌더/반입은 완료했다. 전체 시작 준비를 포함한 GPU 검토 종료 때 참조 수 0인 `RefCounted` 하나의 ObjectDB 경고도 기록했다. 이 종료 진단을 정상 플레이 중 누수 여부나 성능 검증으로 확대 해석하지 않는다. 실시간 부품 충돌·경사면/벽·연막 시야 차단·임의 방향에서 캐릭터와 무관통·최종 성능 예산·사용자 최종 외형 승인을 주장하지 않는다. 기존 전투 수치, 플레이어 모델/모션, 구 산탄총 원본은 이번 아트 변경 범위 밖이다.
