# 세 총 비율 수정 v2 — 2026-11-03

화승총·강선 장총·산탄총이 짜리몽땅하다는 피드백에 따라 총열/개머리판의 길이와 몸통 두께를 다시 설계했다. 단순히 통째로 늘리지 않고 원형 부품·총구·나사·조준경의 치수를 따로 조정했다. **현재 시험판은 이 세 총의 v2를 사용**한다. 나머지 화기 트리 준비 자산과 이전 v1 원본은 유지한다.

## 유지하는 계약

Blender 5.1.1 / MCP 1.8의 안전 모드 안에서 새 `FirearmV2_<id>` 장면을 만들었다. 원본 `.blend`에는 v1 장면을 보존하며 `FirearmV2_Compare`에서 위 v1 / 아래 v2를 같은 미터 배율, 같은 총구 정렬로 볼 수 있다. 세 v2 장면만 각각 선택 내보내기하므로 비교 복사본은 GLB에 들어가지 않는다.

Godot +Y 위, -Z 전방, 총구 `(0,0,0)`과 객체 배율 `(1,1,1)`을 유지한다. JSON `parts[].name`은 새 `v2_<id>__<part>` 이름과 일치한다. 소켓 이름은 JSON에서 `Socket_muzzle` 등 역할명, GLB에서 `v2_<id>__Socket_muzzle` 형식이다. 개별 총열 소켓도 실제 새 위치에 맞춘다. 조립 지연/부분 등장, 어깨 옆 배치, 반동/소멸, 피해·마나·장전·발사 시점은 기존 코드 그대로다.

`floating_gun.gd`와 `shotgun_cast.gd`의 모델/JSON 경로만 v2로 바꾸었다. 시작 준비는 기존 `FloatingGun.MODELS` 참조를 통해 자동으로 v2를 사용한다. `arena.gd`, `shotgun_geometry.gd`, `summon_assembly.gd`와 플레이어 자산/모션을 이 수정에서 바꾸지 않았다.

## 검증과 범위

세 자산 모두 저장 원본/GLB 재반입의 기하 QA를 통과했다. 새 자산 계약 검사와 기존 화승총·장총·산탄총 회귀 검사, 같은 배율 옆모습 비교, 실제 게임 크기/확대 조립·사격 GPU 캡처는 전달 명세에 기록한다. 이전 v1의 9개 GLB와 Blender 원본이 그대로인지 해시로 확인한다.

허용 경고는 정적 평면 끝막음 n-gon, 공중 총의 총구 기준 원점에 따른 음수 높이, 재반입의 UV/노멀 경계 중복 정점, 독립 힌지/몸체 접합부의 반대 방향 숨은 면이다. UV 겹침·누락·부동 부품·잘못된 노멀 오류는 없다. 게임 재질은 기본 PBR 시안이며, 임의 조준각 전체의 캐릭터/벽 접촉이나 최종 성능·외형 승인을 뜻하지 않는다. 환경의 셰이더 캐시/에디터 설정 경로 및 시작 준비 리뷰 종료 진단은 로그에 남긴다.
