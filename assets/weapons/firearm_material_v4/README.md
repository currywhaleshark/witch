## 보존과 텍스처

Blender 5.1.1 / live MCP 1.8 protocol 15의 안전 모드에서 원본을 복사해 작업했다. `FirearmMaterialV4_<id>` 여섯 장면, 공통 베이크 장면, 전체 리뷰 장면이 있다. 이전 v1/v2/v3 장면은 보존한다. `before_material_live.blend`는 시작 시점의 사본이다. `M_FirearmV4_Source_*` 11개 편집용 노드 재질은 fake user로 보존하며 각 부품의 `surface_key`에 대응한다.

원본 v1의 모든 정점·폴리곤·스무딩·커스텀 노멀·피벗·소켓·부품 그룹과 조립 지연을 보존했다. 새 이름은 `v4_` 접두어다. 회전축과 그룹은 [v1 원본 계약](../firearm_tree_v1/README.md)을 따른다. 가중치 변형이나 부품 늘이기를 사용하지 않는다.

여섯 모델이 **색 1K + OpenGL 노멀 1K + ORM 512 + 발광 256** 한 세트를 공유한다. 색/발광은 sRGB, 노멀/ORM은 Non-Color. ORM은 R=AO, G=거칠기, B=금속이다. 일반 표면과 작은 발광 부품은 별도 재질이며, 각 독립 부품은 한 표면이다. 포탄/연막탄은 한 재질만 사용한다. 공통 네 맵은 RGBA8 전체 밉 가정 약 12.3MiB이며 실제 최고 GPU 메모리 측정값은 아니다.

`textures/`에는 편집용 PNG, `exports/`에는 텍스처를 내장한 이식용 GLB가 있다. `game/assets/weapons/firearm_material_v4/`의 GLB는 공통 `textures/*.png`를 참조한다. 게임 검사는 색/노멀/ORM/발광이 실제로 동일 리소스로 공유되는지도 확인한다.

재현은 제작 코드의 `prepare()` → 채널별 `bake_channel()` → `finish()`를 live MCP로 실행하고 `tools/package_firearm_material_assets_v4.py`로 공통 이미지와 노멀 보존을 정리한다. 저장 원본의 평면 n-gon은 그대로 두고, 내보낼 때만 정확한 원본 loop triangle 배열로 임시 메시를 만든다. 임시 메시 생성 중 재인코딩된 노멀은 원본 GLB의 대응 분할 노멀로 복구하고 새 UV 탄젠트를 직교화한다.

## 검증

저장 원본/재반입 GLB QA, 원본과의 형상·피벗 비교, 저장 원본과 출력 GLB의 전체 아틀라스 UV 삼각형 교차, Godot 재질/리소스/소켓 검사와 자산별 85개 동작 샘플을 확인한다. 마우스 스크럽 시 누적 오차가 없는지, 기관포의 고정 몸체가 회전하지 않는지도 검사한다. 최종 결과와 현재 파일 해시는 전달 명세를 따른다.

허용 경고는 정적 평면 캡 n-gon, 공중 총구/탄두 원점의 음수 높이, 재반입 UV/노멀 경계 중복 정점이다. 동일 선형/반복 이미지 노드를 공유하는 내보내기 샘플러 경고와 환경의 사용자 경로/셰이더 캐시/에디터 설정 진단은 기록한다. 오류·UV 겹침·부동 부품 보고는 없다.

이 마모는 고정된 표면 표현이다. 이번 선택은 새 스킬 판정, 임의 지형/벽/부품 간 물리, 연막 게임 규칙 또는 최종 성능 승인을 의미하지 않는다.
