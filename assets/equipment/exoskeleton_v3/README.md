# 외골격 v3 · 부품 분할과 캐릭터 착용 리그

2026-11-03. [앞·뒤 모션 / 분해도 / 실제 표시 크기 리뷰](../../../reports/exoskeleton_v3/review.html).

새 Tripo v2 작업본을 분할하고 현재 캐릭터에 맞춘 **첫 착용·리깅 시안**이다. 게임의 신규 스킬 발동이나 장비 UI 연결은 포함하지 않는다. 등 동력부는 등 뒤를 향하며, 어깨 장식은 팔 바깥쪽으로 회전했다. 소매와 케이프의 간섭은 아래 기록대로 남아 있다.

## 시작 파일

- `exoskeleton_v3_animated.blend`: 텍스처를 포장한 편집·모션 작업본. `ExoskeletonV3_Fit` 장면에서 Space를 누르면 본체·외골격·헤어의 8개 모션이 NLA 목록으로 함께 재생된다. `OUTFIT_Civilian` / `OUTFIT_Transformed` 컬렉션의 뷰포트·렌더 표시를 서로 바꾸어 의상을 선택한다. 각 리그의 `PREVIEW_<motion>` 트랙은 개별 편집용으로 음소거되어 있다.
- `exoskeleton_v3.blend`: 분할·피팅·가중치의 정지 원본. 기존 Blender 장면은 보존했다. 모델 수정과 GLB 재수출은 이 파일에서 시작한다.
- `exports/exoskeleton_v3.glb`: 텍스처 내장, 장비만 있는 34본 GLB. 실행용 복사본은 `game/assets/equipment/exoskeleton_v3/`에 있다. 캐릭터 메시나 기존 모션을 이 GLB에 중복하지 않는다.
- `parts.json`: 부품, 원본 피팅 행렬, 기구 좌표계, 신체 기준 행렬과 연결대 구조. 원본 면 번호는 `.blend` 각 부품의 `source_polygon_ids`에 있다.
- [검증·현재 파일 해시](../../../reports/exoskeleton_v3/delivery_manifest.json).

## 분할과 방향

| 구성 | 부품 수 | 역할 |
| --- | ---: | --- |
| 원본 파생 | 17 | 등 동력부 1, 등 연결부 2, 어깨/위팔/팔꿈치/아래팔/손목 각 2, 무릎/정강이 각 2 |
| 새 연결대 | 14 | 좌우 각 7개 중첩 부품이 미끄러지는 구조 |
| 새 등 지지대 | 2 | 동력부 앞쪽의 고정 지지 |
| 합계 | 33 | 79,242 삼각형, 본 34개, 정점당 한 본에 100% 가중치 |

원본 v2 작업본의 78,474개 면과 UV는 빠짐없이 한 번씩 사용한다. 새 연결대는 768개 삼각형이다. 원본 1개 PBR 재질/2K 이미지 3장에 연결대용 황동·강철 단색 재질 2개를 추가했다. 원본을 새로 리토폴로지하거나 재생성한 것은 아니다.

Blender 좌표는 Z-up, 캐릭터 정면 -Y이다. 원본의 표시 면 -Y를 등에서는 +Y로 뒤집고, 어깨에서는 좌우 바깥쪽으로 향하게 했다. 측면 검토 후 등 동력부를 최초 피팅보다 55mm 몸 쪽으로 이동했다. `back_link_L/R` 이름은 180도 회전 전 원본 분류를 유지하므로 등에서만 해부학적 좌우와 반대다. 실제 부착 위치는 행렬을 따른다.

금속 부품은 늘어나지 않는다. 위팔과 아래팔이 같은 팔꿈치 지점을 사용하며, 몸의 어깨·팔꿈치·손목에서 구한 굽힘 면을 고정된 좌우 부호로 따른다. 상완 비틀림과 내적해서 부호를 다시 정하면 대기 중에도 180도 뒤집히므로 그 방식을 사용하지 않는다. 거의 일직선인 팔은 기준 프레임으로 대체하지만, 이번 8개 클립은 그 특이점에 들어가지 않는다. 임의 새 모션은 다시 검사해야 한다.

## 현재 캐릭터와 연결

- 몸체: v29, 기존 107개 본과 rest/bind 유지.
- 평상복/눈: v28, 변신복: v4, 보조 헤어: v27.
- 기존 모션: 대기, 달리기, 휘두르기, 찌르기, 캐스팅, 경직, 스프링 점프, 쓰러짐.
- 런타임 예제: `game/tests/helpers/exoskeleton_v3.gd`. 현재 캐릭터 `Skeleton3D` 아래에 추가하고 `initialize(skeleton)` 후 **캐릭터 포즈를 평가한 다음** `sync_pose()`한다. 장비 GLB에 캐릭터 애니메이션을 직접 재생하거나 본체 리그와 합치지 않는다.
- 캐릭터의 기존 `MODEL_SCALE`을 상속한다. 별도 축 변환·추가 스케일을 겹치지 않는다.
- 동력부는 흉부를, 정강이는 해당 정강이 본을 따른다. 팔은 공유 관절 좌표를 계산하고, 어깨-등 사이 7단 연결대는 부품 스케일을 바꾸지 않고 이동한다. 현재 800개 표본에서 연결대 길이는 71.1–438.4mm이다.
- Blender 미리보기는 Godot에서 읽은 실제 포즈를 독립 참조 복사본에 구워 넣었다. 원래 캐릭터 GLB·원화·Blender 소스·본 게임 스크립트는 변경하지 않았다. 보조 헤어는 앵커만 맞춘 검토이며 실시간 관성/충돌 시뮬레이션은 아니다.

## 검사 결과와 남은 작업

- 저장 메시와 GLB 재반입 QA 오류 0. 원본 면의 완전한 분할, UV 최대 오차 0, 피팅 위치 최대 오차 약 0.000000248m. 원본 UV/노멀 이음 중복, 좁은 열린 경계, 내부 접합면 1쌍은 보존한다. 새 단색 연결대의 겹친 UV는 베이킹용 UV가 아니다. 착용 부품의 바닥 오프셋과 분리된 정강이는 의도된 배치다.
- 실제 Godot 400개 자세 28,005개 검사, 추가 800개 키 표본 56,005개 검사, 8개 클립 1,928개 연속 표본 340개 검사 통과. 팔꿈치 연결 오차는 최대 약 0.0014mm, 대기/달리기 루프 끝점 일치. 이 수치는 물리 접촉이나 최종 아트 승인 의미가 아니다.
- 400개 Blender 키 포즈를 비교하고 저장 파일을 다시 열어 NLA 목록을 확인했다. 실제 엔진 앞·뒤 1,568장 + 측면/표시 크기 4장 = 1,572장. [메시 검사](../../../reports/exoskeleton_v3/asset_qa.json), [연속성](../../../reports/exoskeleton_v3/continuity.json), [키 비교](../../../reports/exoskeleton_v3/bake_preview.json), [저장 재검사](../../../reports/exoskeleton_v3/saved_preview.json).
- **의상 교차 검사는 통과가 아니다.** [400개 표본 중 297개](../../../reports/exoskeleton_v3/equipment_fit.json)에 삼각형 교차가 있다. 대기·달리기에도 커프/소매의 작은 교차가 있고, 팔을 몸 안쪽으로 돌리는 공격·캐스팅은 어깨/위팔과 케이프의 더 큰 교차가 남는다. 교차 면 수는 관통 깊이나 화면 가시 면적이 아니다. 전용 소매 여유, 어깨 회전 보정과 해당 포즈의 피팅이 다음 단계다.
- 머리카락·맨몸·지면·장비 부품 사이의 연속 충돌, 임의 모션, 스킬 조립 연출, 경량화/LOD와 최종 성능은 미검증이다. 79k를 최종 실시간 예산 승인으로 간주하지 않는다. 사용자 아트 승인도 아직 없다.

## 재현

`tools/build_exoskeleton_v3.py` → `connect_exoskeleton_v3.py` → `refit_exoskeleton_v3_wrist.py` → `refit_exoskeleton_v3_bridge.py` → `refit_exoskeleton_v3_back.py` 순으로 새 작업 장면을 제작했다. 각 일회성 스크립트는 재적용 가드가 있으므로 완성 파일에서 반복 실행하지 않는다. 기존 결과를 유지하며 수정할 때는 명시적인 새 변경 스크립트를 쓴다.

최종 정지 파일에서 `tools/package_exoskeleton_v3_assets.py`, `qa_exoskeleton_v3.py`를 background Blender로 실행한다. Godot import 후 `tests/exoskeleton_v3_art.gd`와 `tests/exoskeleton_v3_continuity.gd`를 실행하며, 전자에 `-- --bake`를 주면 키용 포즈를 별도로 저장한다. `bake_exoskeleton_v3_preview.py`와 `validate_exoskeleton_v3_saved_preview.py`로 편집용 파일을 만들고 재검사한다. 실제 GPU 캡처는 `tests/review_exoskeleton_v3.gd -- --output=<절대 review 경로>`이고, `package_exoskeleton_v3_review.py`가 HTML을 만든다.

Blender 5.1.1 / MCP 1.8 protocol 15 / Godot 4.6.2로 작업했다. 백그라운드 프로세스의 썸네일 디렉터리·Godot 셰이더 캐시·에디터 설정 저장 경고는 환경 진단이며, 실제 산출물과 위 검사 결과는 따로 확인했다.
