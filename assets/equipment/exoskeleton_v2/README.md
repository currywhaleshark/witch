**생성 원본과 정리 작업본 단계**이며 아직 현재 캐릭터에 맞춘 장착본, 관절별 분할, 리깅 또는 본 게임 교체본은 아니다.

## 시작 파일

- `source/exoskeleton_tripo_h31_raw.glb`: 다운로드 그대로 보존하는 원본, 6,209,624바이트.
- `exoskeleton_v2_source.blend`: 텍스처를 포장한 원본 반입 장면 `ExoskeletonV2_Raw`.
- `exoskeleton_v2_working.blend`: 별도 장면 `ExoskeletonV2_Working`. 작은 UV 오류 12면을 최대 0.25텍셀(2K 기준) 보정하고 겹친 미세 삼각형 4개(각 0.15mm² 미만)를 제거했다. 나머지 정점 위치와 면 연결은 동일하며 커스텀 노멀은 수치 오차 내에서 유지한다. 작업본은 78,474 삼각형 / 46,139 정점이다.
- `exports/exoskeleton_v2_working.glb`: 해당 작업본만 내보낸 텍스처 내장 GLB. 전체 Blender 파일의 다른 장면은 내보내지 않는다.
- [원화와 Tripo 입력](../../reference/equipment/exoskeleton_v2/README.md), [전체 제작 기록](production.json).

## 검사와 다음 작업

- 원본 QA에서 샘플링된 UV 오류 6면을 발견했고, 전체 면을 확인해 12면을 정리했다.
- UV 경계 중복 정점과 숨은 접합면 1쌍은 원본 텍스처/노멀 보존을 위해 유지한다. 경계를 공유하면서 미세하게 겹친 네 면 쌍을 실제 투영 면적으로 확인한 뒤 각각의 작은 삼각형을 제거했다. 작은 열린 경계는 이 생성 작업본에 남으며 최종 폐쇄형 리토폴로지로 간주하지 않는다.
- 진단용 정점 용접 사본은 저장하지 않는다. 전체 용접 시 31개 면 방향 경고와 30개 비다양체 변이 생기므로 무조건적인 병합을 정리본에 적용하지 않았다. 두 정강이 장치가 떨어져 있는 것은 착용 장치 배치 의도다.
- Blender에서 앞·뒤·사선의 재질과 앞·옆의 와이어를 확인했다. 저장 작업본과 GLB 재반입 QA가 모두 오류 0으로 통과했다. 유지한 면의 노멀 벡터 최대 차이는 0.000510(약 0.029도), 최대 UV 이동은 약 0.25003텍셀이다. [원본 수치](../../../reports/exoskeleton_v2/raw_inventory.json), [정리 전 겹침 면적](../../../reports/exoskeleton_v2/pre_cleanup_qa.json), [최종 작업본 검사](../../../reports/exoskeleton_v2/working_qa.json).
- 후속 작업은 등판 깊이와 의상 여유 확보 → 어깨/상완/팔꿈치/전완/손목 및 정강이 분리 → 현재 캐릭터 본에 강체 부착 → 두 의상/전투 모션 간섭 검사 → 필요 시 경량화 순서다. 얼굴·손·허벅지·의상·지팡이를 생성 메시로 대체하지 않는다.

78k 메시를 런타임 예산 승인으로 간주하지 않는다. 모델은 원화 검토용 후보이며 사용자 아트 승인과 장착 호환성은 아직 확인하지 않았다.
