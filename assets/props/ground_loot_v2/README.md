## 외형

기존 인벤토리 그림을 참조하여 직접 작성한 정적 메시다. 새 Tripo 생성이나 유료 이미지 생성은 사용하지 않았다. MCP가 응답하지 않아 설치된 Blender **5.1.1**의 백그라운드 실행을 사용했다. 스킬의 검수 코드를 그대로 실행했으며 실제 사용 버전을 보고서에 기록한다.

| 분류 | 새로 만든 모습 |
|---|---|
| 매개체 | 받침과 고정 갈퀴가 달린 청록 구슬, 길쭉한 각진 결정 |
| 설계도 3종 | 말린 남색 도면과 산탄포·전기톱·태엽인형의 밝은 표식 |
| 부품 2종 | 짧은 포신의 탄도 부품, 구리 코일과 청록 셀을 갖춘 동력 부품 |
| 고유 2종 | 사슬과 절삭 집게가 연결된 도르래, 노출 스프링과 열쇠가 달린 쌍둥이 태엽통 |
| 머리·장신구 | 접힌 자주색 리본, 별 핀, 황동 톱니 브로치, 은 꽃 브로치, 각진 보석의 은반지 |
| 의류 | 접힌 누빈 망토, 각각 두 짝인 면장갑·가죽 장갑·운동화·가죽 장화 |
| 물약 | 빨강/파랑/보라/초록; 소형 둥근 병, 중형 긴 병, 대형 넓은 병, 완전 회복 각진 병. 소·중·대는 기본 시점의 투영 크기 증가도 검사 |
| 자원 | 각인전 묶음, 물결·잎·안개 표식을 가진 이름 조각. 문양은 외형이며 새 게임 규칙이 아님 |

유리는 기존 v1과 같이 불투명 색과 넓은 하이라이트로 표현한다. 착용할 의류·캐릭터 파츠가 아닌 **바닥 전리품**이다. 근접 확대의 세밀한 표면 무늬보다 실제 필드에서 구분되는 모양과 색을 우선한다.

## 내보내기와 게임 계약

새 모델은 각각 한 개의 메시, 최대 세 개의 불투명 PBR 표면(일반/금속/보석)이다. 색은 정점 색상에 저장하여 새 텍스처가 필요 없다. 35종 합계 **71,132삼각형**, 기존 4종 포함 **81,268삼각형**이며 이는 전체 종류를 한 개씩 합산한 값이다. 실제 동시 화면 비용이나 성능 승인을 의미하지 않는다. 모델별 상세 수치는 `models.json`을 따른다.

작성본의 독립 부품은 유지하고 내보내기 복사본만 합친다. GLB는 활성 export 장면 한 개만 내보내며 다른 모델의 선택 상태가 섞이지 않는지 재반입 검사한다. 모델 원점은 기존 회전 낙하에 맞춘 정점 경계 중심이다. 실제 최하단에서 계산한 `rest_height`로 착지 때 바닥 위 12mm에 놓인다. 전체 모델은 기존 0.7m 드롭 간격의 반경 0.35m 이내다.

`ground_loot_visual.gd`는 명시적인 프로필 경로를 사용한다. 고유 ID가 일반 베이스보다 우선하고, 각인전은 `currency`, 조각은 `bel`/`rok`/`sha`로 연결한다. 아직 정의하지 않은 ID는 기존 도형 대체 동작을 유지한다. 인스턴스별 재질 복사, 강조 후 원색·발광 복원도 유지한다.

드롭 확률·소유권·획득·가방·전투·캐릭터 자산은 바꾸지 않았다. 기존 0.95m/0.4초 낙하, 5초 라벨, Alt, 클릭 획득과 일시정지·재시작을 사용한다. 새 모델 높이로 기존 라벨 검사를 실행하자, 고정 위치에서 부동소수점 덧셈 순서로 0.000031px 오차가 발생했다. `ground_loot.gd`에서 `(anchor - previous.anchor)`를 먼저 계산하도록 고쳐 정지 라벨 위치를 정확히 보존한다. 표시 규칙과 시간은 그대로다.

## 검증과 남은 범위

최종 검사 수·실행 종료 코드·현재 입력 SHA-256은 [delivery_manifest.json](../../../reports/ground_loot_v2/delivery_manifest.json)을 기준으로 한다. Blender 저장본·GLB 재반입, 모든 39종의 실제 정점 낙하와 평지/높은 골목 착지, 강조 독립성과 원복, 정확한 ID/수량 획득, 일시정지·재시작, 기존 전리품·자원·아이템 회귀 검사를 포함한다. 리뷰의 그룹 화면과 개별 확대는 실제 게임 조명을 사용한다.

자산 QA `game` 프로필 오류는 모두 수정했다. 의도된 경고는 다음과 같이 기록한다.

- 회전용 중심 원점 때문에 `ground_z=0`이 아니다. 이는 원점 계약이며 Blender와 게임 양쪽에서 최하단 높이를 확인한다.
- 정적 평면 뚜껑·판의 n-gon은 GLB에서 삼각화한다. 변형용 메시가 아니다.
- 구슬 갈퀴 하나의 UV 겹침 경고는 상수 정점색을 사용하는 이번 출력에는 영향을 주지 않는다. 추후 고유 텍스처 베이크를 할 때 해당 UV를 다시 펴야 한다.
- 망토/깃과 태엽 열쇠/몸체의 보이지 않는 맞닿은 삼각형 쌍 10개는 닫힌 편집 부품을 유지하기 위해 남긴다. 보이는 같은 방향 표면의 z-fighting은 없다.
- 두 짝의 장갑·신발은 의도된 별개 물체이므로 각 짝을 독립 조립체로 검사했다. 두 짝 전체의 게임 경계와 간격은 함께 검사한다.

Godot 로그에는 환경의 `user://` 셰이더 캐시 경고와 에디터 설정 저장 진단이 남을 수 있으므로 빈 stderr로 보고하지 않는다. 실시간 강체 시뮬레이션, 임의 계단·벽 주변 충돌, 대량 드롭 최종 성능은 이번 검증 범위 밖이다. 새 35종은 사용자의 검토를 위한 연결본이며 외형 승인을 새로 기록하지 않았다.

```powershell
python tools/run_ground_loot_v2.py --phase import
python tools/run_ground_loot_v2.py --phase runtime
python tools/run_ground_loot_v2.py --phase regressions
python tools/package_ground_loot_v2.py
```

회귀 검사는 원래 테스트를 별도 보고서 경로로 복사해 실행하여 이전 검사 자료를 덮어쓰지 않는다. `regression_scripts/label_probe.gd`와 별도 진단 로그는 라벨 오차 재현 기록이며 최종 성공 판정은 `runtime/` 및 `regressions/{ground_loot,loot_resources,items}/` 실행 기록을 따른다.

**사용자 선택 (2026-11-02):** 위 리뷰 전달 후 사용자가 「커밋」을 요청하여 현재 추가 35종과 전체 39종 연결을 시험판용으로 선택했다([approval.json](approval.json)). 앞의 외형 선택 대기 문구를 대체하며, 기록한 QA 경고·지형/벽 충돌·최종 성능 검증 범위는 그대로다.
