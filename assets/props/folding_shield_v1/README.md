# 접이식 방패 v1 — 삼단 패널

`방패 전개`(R) 스킬의 표현용 원본 소품. `tools/build_folding_shield_v1.py`가 Blender 5.1 백그라운드에서 직접 만든다(Tripo
아님). 사용자가 보낸 경찰 접이식 방패 사진(가운데 판 + 경첩으로 접히는 양쪽 날개)을 바탕으로 마녀 쪽 색으로 옮겼다.
처음 만든 부채꼴 안은 방향이 어색해 쓰지 않았다(커밋 전 교체).

- 부품 3개, 900삼각형: 가운데 판(`centre`)과 좌우 날개(`flap_L`, `flap_R`).
- 가운데 판: 모서리를 깎은 짙은 건메탈 판, 위아래 황동 띠, 황동 톱니 문장 + 청록 코어, 오른쪽 위 청록 관측창, 양쪽 경첩 마디,
  뒤쪽 손잡이 받침. 날개: 황동 홈 세 줄과 긴 가장자리 띠(사진의 흰 선 대신).
- 날개의 원점은 각자의 경첩선이고 펼친(평평한) 상태로 저장된다. 게임이 날개를 경첩 축으로 돌려 뒤로 접거나 편다.
- 모델의 문장 면은 Godot 로컬 +Z를 향한다. 게임은 패널을 180° 돌려 바깥으로 향하게 둔다.
- 재질은 텍스처 없는 PBR 값. 이 렌더러에는 반사 환경이 없어 금속도를 0.45~0.5로 낮췄다.
- `build.json`에 부품 목록·삼각형 수·치수·blend/GLB 해시가 있다. 게임 GLB는 `game/assets/props/folding_shield_v1/folding_shield.glb`.

동작은 `game/scripts/shield_visual.gd`(표현 전용). 검토 이미지와 범위는 `reports/folding_shield_v1/README.md`.
