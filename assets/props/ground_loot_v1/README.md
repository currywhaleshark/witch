# 필드 드롭 모델 v1 — 네 종류 시범

2026-11-02 사용자가 아이콘과 닮은 필드 외형을 요청하고, 네 종류를 먼저 만들어 보는 제안을 수락했다. Blender에서 직접 작성한 정적 메시이며 아이콘 이미지는 색과 윤곽의 참고로 사용했다.

| 실제 연결 ID | 표현 | 삼각형 |
|---|---|---:|
| `health_s` | 눕힌 둥근 빨간 병, 목 테두리, 코르크 | 1,964 |
| `copper_ring` | 구멍이 열린 구리 반지와 붉은 카보숑 | 1,660 |
| `part_cutting` | 청록 모터, 놋쇠 허브, 원형 톱날 | 4,956 |
| `cotton_coat` | 접힌 무명 겉옷, 회청색 옷깃·소맷단, 단추 | 1,556 |

합계 10,136삼각형이다. 위 네 ID만 게임에 연결했으며 나머지 장비·물약과 각인전·이름 파편은 이전 모양을 사용한다. 고유 아이템은 베이스가 같아도 이 시범 모델을 빌려 쓰지 않는다.

- 재생성: [build_ground_loot_v1.py](../../../tools/build_ground_loot_v1.py)
- 저장본 재열기·GLB 재임포트 검사: [validate_ground_loot_v1.py](../../../tools/validate_ground_loot_v1.py)
- [크기·삼각형·내보내기 해시](models.json), [게임 GLB](../../../game/assets/props/ground_loot_v1/)

`ground_loot_visual.gd`가 ID에 맞는 장면을 캐시하여 기존 낙하 transform 아래에 붙인다. 실제 정점 경계를 기준으로 원점을 중앙에 두고 최하단이 바닥 위 12mm에 놓이도록 높이를 설정했다. 네 모델은 기존 0.7m 간격의 반경 0.35m 안에 들어간다. 여러 표면 재질을 인스턴스별로 복제하여 한 아이템을 가리켰을 때 그 물체만 밝아지고, 포인터가 떠나면 원래 재질 색·발광을 복원한다.

기존 0.95m 높이, 0.4초 회전 낙하, 5초 라벨 숨김, Alt 누르는 동안 표시, 클릭 획득, 가방 소유권은 그대로다. 모션은 기존 연출이며 물리 강체 시뮬레이션을 추가하지 않았다. 유리병은 작은 화면에서 구분되는 불투명 색과 넓은 하이라이트로 표현했다.

## 검증 및 검토 범위

Blender 5.1.1에서 저장본 4개 장면과 다시 불러온 GLB의 해시·크기·바닥 지지 높이 등 24항목을 확인했다. Godot 4.6.2 실제 GPU 검사 60항목은 새 모델 연결, 전체 정점의 낙하 중 평지 관통 여부, 높은 골목 바닥의 착지, 재질 강조 독립성·복원, 획득/일시정지/재시작과 캡처 12장을 포함한다. 기존 전리품 55항목·자원 26항목·아이템 61항목도 통과했다. 결과와 현재 입력 해시는 [delivery_manifest.json](../../../reports/ground_loot_v1/delivery_manifest.json)에 있다.

리뷰는 기본 카메라와 같은 각도의 2.7배 확대를 사용한다. 실제 골목 지형과 조명에서 찍었으며 모델 비교를 위해 적을 화면 밖으로 옮겼다. 촬영 전에는 맵의 충돌/내비게이션 갱신을 기다린다. 임의 계단·벽 주변 전체 메시의 충돌이나 대량 드롭 성능을 보증하는 검사는 아니다. 사용자는 2026-11-02 「커밋하고 푸쉬」를 요청하여 네 종류의 현재 외형과 연결을 프로토타입용으로 선택했다([기록](approval.json)). 전체 아이템으로의 확대는 아직 하지 않았다.

재현: `godot --path game --resolution 1280x800 --script res://tests/ground_loot_art.gd -- --capture`.
