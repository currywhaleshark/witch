## 총기와 시간

채택된 v2 포탑의 조립 사본 `turret_assembly_v1/authoring/turret_parts.blend`에서 상부 약실·포신·톱니·태엽을 골랐다. 다리·회전 받침대를 제외하고 0.72배 균일 축소, 총구 원점 이동만 적용했다. 원본을 덮어쓰거나 새 Tripo 생성을 하지 않았다. 40개 강체 메시, 8,732삼각형, 기존 1K PBR 아틀라스 재질 하나이며 스킨/클립은 없다. 로컬 `(0,0,0)`이 총구이고 `-Z`로 발사한다.

조립은 기존 발동 시점에 맞춘다. 기본 산탄 동작 0.25초 중 50%인 **0.125초**에 총기가 완성되고 피해·비용·발사가 한 번 실행된다. FCR 40은 약 **0.078846초**다. 완성 뒤 포신이 최대 7.5cm 뒤로 반동하고, 총기는 약 **0.45초**에 소멸한다. 탄선은 0.08초, 총구 섬광은 0.085초의 표시다. 조립과 발사에 기존 기계음을 사용하며 게임의 음소거 설정을 따른다.

기본 배치의 **우클릭**으로 시험한다. 시전 중단·마나 재검사 실패·슬롯 변경 때는 현재까지 생성된 부품만 그 자세에서 빛으로 해체한다. 총구 섬광/피해/마나·쿨다운은 실행하지 않는다. 작은 피격/막기는 기존 시전을 유지한다. 목표가 사라져도 방향 지정 산탄은 기존 마지막 지점으로 발사한다. 일시정지는 조립·반동·소멸을 정지시키며, 재시작/맵 교체는 활성 및 소멸 중 총기를 모두 정리한다.

## 발사 위치와 판정

현재 배치 기준은 `shotgun_geometry.gd`의 상수다. 평소 총구는 플레이어 전방 0.62m·오른쪽 0.52m·발밑 기준 높이 1.12m다. 가까운 커서/전방 적에 맞춰 앞·옆 오프셋을 줄이고 높이를 올려, 가까운 적보다 총구가 먼저 나가지 않게 한다. 벽은 총구 이동 경로와 총기 중심/양옆 선분으로 검사하며, 오른쪽이 막히면 왼쪽·위쪽 후보를 확인한다. 후보가 모두 막히면 플레이어 위쪽 원점으로 되돌린다. 임의 모서리에서 총기 전체 부피의 충돌 여유를 보장하는 방식은 아니다.

모델 원점, 총구 섬광, 피해 부채꼴과 일곱 탄선은 하나의 `Transform3D`를 공유한다. 시전 중 살아 있는 목표를 추적하고 실제 발동에서 같은 규칙으로 확정한다. **최대 사거리는 플레이어 기준 기존 8m를 유지**한다. 산포각의 기준값 0.86도 유지한다. 탄선 끝은 플레이어 기준 거리 한계와 월드/바닥 충돌로 잘라 그린다. 광선 때문에 벽 너머까지 발사되는 것처럼 보이던 표시를 방지한다.

피해량 30, 마나 10, 쿨다운 1.2초, 방향 지정/즉시 제자리 시전, 명중 판정 생략·적별 치명타 등 기존 산탄 규칙은 유지한다. **부채꼴 꼭짓점과 엄폐물 시야 원점이 플레이어 중심에서 총구로 바뀌므로**, 가장자리나 모서리 근처의 명중 결과는 이전과 달라질 수 있다. 발사 위치 변경에 따른 체감/균형 승인은 별도다. 동시 작업자의 태엽인형 비용/노드와 고저차 조준 수정도 보존한다.

## 확인한 범위

- 신규 산탄 검사 305개: FCR 0/40, 부품 수·삼각형, 단계적 생성, 발동 전 무비용/무피해, 모델/발사 원점, 반동/소멸/일시정지, 15/50/85% 중단의 현재 자세 보존, 자원 실패, 슬롯 변경, 이동/사망 표적, 독립 재시전과 정리.
- 0.25/0.5/1/1.5/4/7.99m 적은 명중하고 8.1m 적은 제외한다. 네 방향 조준, 정면 벽의 피해·탄선 차단, 오른쪽 벽에서 왼쪽 후보 선택을 확인했다.
- 기존 경직/방패 20, 누르기/연타 41, 명중/치명/등급 22, 접근 시전 27, 공구 연계 21개 회귀. **합계 436개, 실패 0**. 모든 최종 headless 실행 exit 0/빈 stderr/입력 해시 변경 없음.
- 실제 arena의 60Hz 시전·발동·피해·중단을 실행해 7장면×49프레임과 모델 1장, **344장 GPU 렌더**. 렌더 exit 0이며 stderr는 알려진 `user://` 셰이더 캐시 폴더 생성 안내만 있다. 영상 리타이밍은 없고 비교 페이지의 재생 속도로 느리게 볼 수 있다.
- 원본 보존, 파생/게임 GLB 해시 일치, 40개 정적 메시·8,732삼각형·무스킨/무클립, 각 실행의 입력 파일 사본/해시를 저장했다. GPU 정점 readback이나 전신 접촉 해석을 수행했다는 뜻은 아니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_shotgun_cast_v1.ps1 -Phase test -Test shotgun_cast
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_shotgun_cast_v1.ps1 -Phase review
python tools/package_shotgun_cast_v1.py
```

재생성은 Blender 5.1.1에서 `tools/build_shotgun_cast_v1.py`, 이후 runner의 `-Phase import`를 사용한다. 이번 작업은 별도 background Blender에서 수행해 사용자의 열린 장면을 유지했다. 리뷰는 무음이다. 브라우저의 로컬 파일 자동 조작은 도구 정책상 사용할 수 없어 렌더 이미지와 HTML 구문/파일 연결로 확인한다. 부품별 실시간 충돌, 모든 벽 모서리/캐릭터 자세에서의 여유, 최종 성능 및 사용자 외형 승인은 남은 범위다.
