# 기계 수렵견 — Tripo 원본·분할 v1

2026-11-05. [원화](../concept_v1/mechanical_hound_v1.png) 한 장으로 Tripo H3.1 HD 모델을 생성하고 정밀 분할했다. [검토 페이지](../../../../reports/automation_batch2_v1/review.html)에서 원화와 여러 방향의 모델, 부품 구분을 볼 수 있다.

## 시작 파일

- `source/hound_raw.glb`: 생성 직후 원본, 76,914 삼각형 / 1 메시 / 2K PBR 3장.
- `hound_raw.blend`: 해당 GLB를 그대로 가져온 packed 원본과 검토 조명·카메라.
- `source/hound_segmented.glb`: Tripo에서 저장하고 UV 패킹하여 내보낸 분할 원본. 60 메시 / 76,870 삼각형 / 68,998 Blender 정점 / 공유 PBR 재질 1개 / 2K 이미지 3장.
- `hound_segmented.blend`: 분할 원본의 packed Blender 사본. 원본 검사 오류는 별도 기록에 남아 있다.
- **`hound_working.blend`**: 다음 작업의 시작점. 60 메시 / **76,862 삼각형**, 작은 중복·겹침 면 8개만 제거했다.
- `exports/hound_working.glb`: 작업용 사본을 다시 내보내고 새로 불러와 검사한 정적 GLB. 게임용 최종 자산이 아니다.
- `production.json`: 생성 설정, 비용, 파일 위치와 제한.

현재 배율은 Tripo 원본 기준이다. Blender에서 전체 경계는 약 1.000 × 0.350 × 0.634 단위이며 꼬리·안테나를 포함한다. 이를 몸길이 0.95m 또는 머리 높이 0.62m로 간주하지 말 것. 어깨·머리·발 기준 측정 및 정면 변환은 다음 단계에서 한다.

## 생성·분할 기록

- [Tripo 작업실](https://studio.tripo3d.ai/ko/workspace/segmentation/af4d77b6-a9e6-4c5b-a45c-fe99ef1326d5)
- 비공개 H3.1 HD, 목표 80,000 삼각형, 2K 텍스처와 PBR, 울트라·AI 완성·8K는 끔.
- 부분별 생성 옵션을 켜면 텍스처 옵션이 꺼져, 텍스처 포함 원본 생성 후 정밀 분할하는 순서로 진행했다.
- 모델 생성 30 + 정밀 분할 40 = **70 크레딧**. 잔액 2455 → 2385. 추가 생성·유료 리토폴로지는 하지 않았다.
- 분할 직후 UI는 `tripo_part_0`~`60`의 61개 / 76,914면이었다. 저장·내보내기 후 실제 GLB는 `tripo_part_11`이 없는 60개 / 76,870면이다. 재접속 UI의 분할 미리보기 라벨은 표준으로 표시됐으나 실행 시 정밀 선택과 61개 결과는 스크린샷에 기록돼 있다. 파일 수치를 기준으로 사용하고 원본과 동일한 완전한 면 분할이라고 주장하지 않는다.
- 내보내기 대기 연결이 한 번 시간 초과되어 저장된 모델의 내보내기만 재개했다. 재생성이나 추가 분할 비용은 없었다.

## 최소 정리와 검증

`tools/inspect_automation_batch2_v1.py`가 원본/분할 GLB를 가져와 packed 파일, 통계, 원본 진단과 여러 각도 이미지를 만든다. 설치된 Blender 5.1.1을 사용했다. live MCP는 연결되지 않아 별도 background 프로세스로 검사했다.

분할 원본에는 7개 파트의 동일 방향 공유 모서리와 파트 53/6 사이 작은 겹침이 있었다. `tools/prepare_automation_hound_v1.py`가 진단된 면 8개(각 면적 0.0000005 원본 단위² 미만)를 작업용 사본에서 제거했다. 남은 정점 위치·면 연결·UV는 정확히 유지하며 부품 변환과 재질·텍스처를 변경하지 않는다. Blender의 custom normal 재인코딩 오차는 보고서에 기록한다. 두 다운로드 GLB는 변경하지 않았다.

작업용 저장본과 새 GLB 임포트의 `blender-asset-qa` 오류는 0개다. 원본 GLB의 2개 오류 및 분할 원본의 8개 오류는 원본 진단으로 보존한다. 경고 64개는 60개 파트의 UV/노멀 분리 정점과 4개 파트의 숨겨진 반대 방향 접합면이다. 원본 재질과 경계를 보존하기 위해 현재 단계에서는 유지한다. 이 검사는 폐곡면·움직이는 관절의 안쪽 면·전체 접촉·게임 준비 완료를 보증하지 않는다. 저장 후 다시 연 메시 수와 삼각형 수, 이미지 패킹, 새 GLB 임포트와 원본 SHA도 확인했다.

전체 증거는 `reports/automation_batch2_v1/`의 `raw/`, `segmented/`, `working/`, `delivery_manifest.json`에 있다. thumbnail 폴더 쓰기 경고는 로컬 환경 진단이며 .blend 저장과 렌더는 성공했다.

## 남은 작업

자동 분할 조각은 관절·강체 부품 설계와 다르다. 턱, 상·하체, 다리 관절, 피스톤 실린더/막대, 발, 태엽, 꼬리를 실제 구동 단위로 묶고 필요한 안쪽 면과 축을 만들어야 한다. 5~7천 삼각형 경량화, 1K 아틀라스, 별도 발광 면, 100% 단일 본 리그, 24fps 클립, 소켓과 실제 게임 크기 확인은 아직 진행하지 않았다. 신호기·거대 자동인형 모델, 강화용 부품, 게임 규칙·FX 연결, 최종 성능 및 사용자 외형 승인은 이번 범위에 포함하지 않는다.
