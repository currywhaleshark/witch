# 자동화 2차 소환체 — 아트 작업 요청서

2026-11-05. 자동화 트리 2차로 넣을 **기계 수렵견·유인 신호기·거대 자동인형** 세 모델의 제작 사양이다. 게임 규칙(피해·수명·노드)은 [03 §5.9](../../../docs/03_skills.md)가 원본이다. 이 문서는 모델과 동작만 다룬다. 수치는 모두 시험값이고, 사용자 외형 승인은 아직 없다.

## 1. 공통 원칙

- **외형 방향:** 사용자가 고른 소환물 색인 **낡은 황동 + 깊은 청록**. 기계장치 마녀와 같은 세계관이다. 기준은 현재 게임의 [태엽인형·자동포탑 v2](../summons_v2/README.md)와 [태엽인형 A/B 노드](../automaton_nodes_v1/README.md)다. 빛나는 동력부는 청록색이고, 경고·신호 램프만 호박색을 쓴다.
- **보이는 크기:** 게임 카메라는 1.75배 내려다보기 구도다. 1280x800에서 마녀 키가 약 111px로 보인다. 위에서 작게 봐도 실루엣으로 구분되어야 한다. 아래 크기는 모두 마녀 키를 약 1.5m로 잡은 값이다.
- **좌표:** Y가 위, 정면은 −Z, 미터 단위, 오브젝트 배율 1. 원점은 바닥 위, 발(받침) 중심이다.
- **리그:** 강체 부품만 쓴다. 정점마다 부품 뼈 하나에 100% 연결하고, 한 삼각형이 두 부품 뼈에 걸치지 않게 한다. 늘어나거나 휘는 변형은 쓰지 않는다. 관절 피벗은 실제 회전축에 둔다.
- **재질:** 모델마다 1K PBR 아틀라스 한 벌(색·노멀·ORM)과 작은 발광 맵을 쓴다. 발광 면은 별도 재질로 나눠 밉맵 번짐을 막는다(스태프 v3와 같은 이유).
- **애니메이션:** 24fps에 상수 트랙을 유지한다. 루프 클립은 첫 키와 끝 키가 같아야 한다. 게임 임포트 때는 애니메이션 최적화와 압축을 끈다.
- **파괴:** 적에게 부서질 때는 폭발 없이 **부품이 흩어지며 무너진다**(summons v2의 `death`처럼 구워 둔다). 자폭은 없다.
- **산출물:** packed 원본 `.blend`, 게임용 GLB(`game/assets/actors/automation_batch2/`), 부품·그룹·소켓을 적은 `parts.json`, README(삼각형 수, 부품 수, 뼈 수, 클립 목록), 실제 게임 카메라 크기 캡처가 있는 검토 페이지.
- **소켓 이름:** `Socket_attack`(타격·물기 접점), `Socket_signal`(신호 발생점, 신호기만), `Socket_bar`(체력 막대 기준, 머리 위), `Socket_core`(청록 동력부 중심). 바닥 그림자 반경은 parts.json에 숫자로 적는다.

## 2. 기계 수렵견 (티어 II, 이동 소환)

**역할:** 빠르게 달려가 한 적을 끝까지 물고 늘어진다. 태엽인형보다 작고 빠르며, 다리가 넷이다. 화면 안 먼 적, 특히 원거리 전선 까마귀까지 쫓아간다.

| 항목 | 사양 |
|---|---|
| 크기 | 몸길이 0.95m, 어깨 높이 0.50m, 머리를 든 높이 0.62m |
| 실루엣 | 그레이하운드처럼 가늘고 긴 사냥개. 허리는 잘록하고 가슴통이 깊다 |
| 몸통 | 황동 갈비뼈판이 청록 도장 척추 프레임을 감싼다. 등에 태엽 열쇠 하나 |
| 머리 | 길고 납작한 덫 모양 턱(톱니 이빨). 외눈 청록 렌즈. 귀 대신 작은 안테나 둘 |
| 다리 | 뼈대가 드러난 다리. 허벅지와 정강이 사이에 피스톤 힘줄 |
| 꼬리 | 2마디 전선 안테나. 끝에 작은 청록 불빛 |
| 삼각형 | 5,000~7,000 |
| 부품(예시, 약 19개) | 골반, 가슴, 목, 머리, 아래턱, 다리 4×(허벅지·정강이·발), 꼬리 2, 태엽 열쇠, 렌즈 |

**노드별 외형** (같은 메시에 부품을 더하거나 배율만 바꾼다. 태엽인형 A/B처럼 기본 부품의 정점은 바꾸지 않는다):
- **기본:** 위 사양 그대로.
- **사냥 무리:** 게임에서 0.8배로 줄여 3마리씩 나온다. 새 부품은 없다. 등에 번호판(1~3)이 보이면 좋다.
- **중장 추적기:** 1.2배. 머리 장갑판, 어깨 장갑판 2장, 톱날 턱을 덧붙이는 별도 부품 세트다.

**클립:**

| 클립 | 길이 | 내용 |
|---|---|---|
| `spawn` | 0.4초 | 웅크린 상태에서 다리를 펴며 일어남 |
| `idle` | 1.0초 루프 | 숨쉬듯 가슴이 오르내리고 태엽 열쇠가 돌고 꼬리가 흔들림 |
| `run` | 0.5초 루프 | 질주 보행. 6.5m/s 기준 한 주기에 3.25m를 간다. 주기 거리를 README에 적는다 |
| `bite` | 0.6초 | 몸을 낮췄다가 덮치며 턱을 닫는다. **50%(0.3초)에 턱이 닫힘** = 피해 시점 |
| `hit` | 0.25초 | 짧게 움찔 |
| `death` | 약 1.2초 | 부품이 흩어지며 무너짐 |

## 3. 유인 신호기 (티어 II, 설치·CC)

**역할:** 바닥에 꽂으면 종을 치고 램프를 돌려 주변 적을 끌어모은다. 적은 신호기를 때리러 온다. 포탑·처형 장치·화약통 앞에 적을 모으는 장치다.

| 항목 | 사양 |
|---|---|
| 크기 | 전체 높이 1.5m, 받침 지름 0.9m |
| 실루엣 | 포탑과 헷갈리지 않는 **가늘고 높은 세로형**. 위에서 볼 때 램프가 가장 먼저 보여야 한다 |
| 받침 | 땅에 박히는 접이식 삼각대 다리 3개. 아래에 작은 태엽 드럼 상자 |
| 기둥 | 2단으로 늘어나는 황동 기둥 |
| 꼭대기 | 회전하는 호박색 램프(셔터가 돌며 깜박임)와 청록 렌즈. 옆에 종과 종 치는 망치, 나팔형 송신기 |
| 기타 | 안테나 하나 |
| 삼각형 | 3,000~4,500 |
| 부품(예시, 약 14개) | 다리 3, 드럼 상자, 기둥 하단·상단, 램프 몸통, 회전 셔터, 렌즈, 종, 망치, 나팔, 안테나 |

**클립:**

| 클립 | 길이 | 내용 |
|---|---|---|
| `deploy` | 0.5초 | 시전과 같은 길이. 다리가 펴지며 땅에 박히고, 기둥이 늘어나고, 램프가 켜짐 |
| `pulse` | 1.0초 루프 | **0초에 망치가 종을 침** = 신호 시점. 셔터는 계속 돌아감 |
| `hit` | 0.25초 | 기둥이 흔들림 |
| `shutdown` | 0.4초 | 시간이 끝남. 램프가 꺼지고 기둥이 내려가고 다리가 접힘 |
| `death` | 약 1.0초 | 부서짐. 기둥이 넘어지고 부품이 흩어짐 |

신호 범위(반경 6m) 고리와 음파는 게임 FX가 그린다. 모델에는 넣지 않는다.

## 4. 거대 자동인형 (티어 IV, 대형 소환)

**역할:** 자동화의 최종 성장 상징. 크고 묵직한 전투기계로, 앞에 버티고 서서 두 주먹으로 바닥을 내리친다. 초급 태엽인형을 단순히 키운 모습이 아니라, 복잡한 관절과 동력계가 보이는 고급 기계여야 한다([03 §5.4](../../../docs/03_skills.md)).

| 항목 | 사양 |
|---|---|
| 크기 | 높이 2.8m(마녀의 약 1.9배), 어깨 너비 1.8m |
| 실루엣 | 고릴라처럼 어깨가 크고 팔이 길다. 주먹을 앞으로 짚는 자세. 다리는 짧고 발이 넓다 |
| 몸통 | 보일러·태엽 드럼형 몸통. 가슴에 크게 드러난 회전 톱니. 머리는 가슴에 반쯤 묻힌 청록 감지 바이저 |
| 등 | 굴뚝(배기관) 2개와 큰 태엽 열쇠 |
| 주먹 | 망치처럼 큰 주먹. 손목에 피스톤 |
| 삼각형 | 12,000~16,000 |
| 부품(예시, 약 28개) | 골반, 몸통, 가슴 톱니, 바이저, 굴뚝 2, 태엽 열쇠, 팔 2×(어깨·위팔·아래팔·주먹·손목 피스톤), 다리 2×(허벅지·정강이·발) |
| 게임 충돌 반경 | 0.9m |

**노드별 외형:**
- **기본:** 위 사양 그대로. 1기만 유지한다.
- **단일 강화:** 1.1배. 어깨·팔뚝 장갑판과 더 큰 주먹 덮개를 덧붙이는 별도 부품 세트다. 가장 위압적이어야 한다.
- **다수 운용:** 0.75배로 최대 3기가 나온다. 새 부품은 없다. 가슴판에 번호(1~3)가 보이면 좋다. 줄어도 거대 기계의 무게감이 남아야 한다(작은 태엽인형과 헷갈리면 안 됨).

**클립:**

| 클립 | 길이 | 내용 |
|---|---|---|
| `assemble` | 1.2초 | 시전과 같은 길이. 부품이 위에서 내려와 아래부터 맞물리고, 마지막에 바이저가 켜짐 |
| `idle` | 2.0초 루프 | 가슴 톱니가 돌고 굴뚝에서 김이 나고 어깨가 무겁게 오르내림 |
| `walk` | 1.2초 루프 | 무거운 보행. 2.6m/s 기준 한 주기에 3.12m를 간다. 주기 거리를 README에 적는다 |
| `slam` | 1.8초 | 0~0.55초에 두 팔을 들고, **0.55초에 두 주먹으로 앞 바닥을 내리침** = 피해 시점. 이후 일어선다 |
| `hit` | 0.3초 | 상체가 조금 밀림 |
| `death` | 약 1.8초 | 무릎이 꺾이고 부품이 무너짐 |

`Socket_attack`은 내리친 두 주먹 사이 바닥 지점이다. 부채꼴 충격(반경 2.2m)과 먼지는 게임 FX가 그린다.

`assemble`을 클립으로 만들기 어려우면, 자동포탑 시전처럼 **정지 부품 사본 GLB**를 따로 줘도 된다([turret_assembly_v1](../turret_assembly_v1/README.md) 방식). 게임 쪽 조립 연출은 이 사본으로 만들 수 있다.

## 5. 넘겨줄 때 확인할 것

- 세 모델 모두 1.75배 게임 카메라에서 마녀·태엽인형·자동포탑·적 세 종과 한 화면에 놓은 비교 캡처.
- 피해 시점 프레임(물기 50%, 종 0초, 내리치기 0.55초)이 표에 적은 대로인지.
- 루프 첫 키와 끝 키의 일치, 주기 거리.
- 정점별 단일 뼈 100% 연결, 늘어나는 부품이 없는지.
- 노드 부품 세트를 켜고 끌 때 기본 부품 정점이 바뀌지 않는지.

게임 연결(규칙·표적·FX·노드 전환)은 모델이 들어온 뒤 코드 작업에서 한다.
