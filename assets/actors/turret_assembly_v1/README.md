## 원본과 완성 시점

채택된 `summons_v2/authoring/turret_v2.blend`의 idle 첫 프레임에서 86개 강체 부품을 추출했다. 기존 17,556삼각형·UV·1K PBR 아틀라스를 유지한다. 원본 v2 모델·리그·조준·파괴 동작을 수정하거나 다시 생성하지 않았다. 사본 GLB는 독립 메시 86개, 아틀라스 재질 1개이며 스킨·클립이 없다. 시전 중에는 부품별 투명도/발광 때문에 재질 인스턴스를 나눠 사용한다.

기본 시전은 기존 0.6초, 발동은 그 85%인 **0.51초**다. FCR 40의 발동은 약 **0.32169초**다. 시전 시작 때 유효한 바닥 위치를 고정하고, 기존 발동 재검사가 성공하면 그 자리에서 실제 v2 포탑 하나로 교체한다. 마나 15와 쿨다운 5초도 기존 발동 때 적용한다. 조립 중에는 공격/피격 대상이나 충돌체가 아니다.

멀리 지정하면 기존 사거리 확보 이동을 마친 뒤 조립을 시작한다. 시전 중 커서가 옮겨져도 설치 위치는 바뀌지 않는다. 발동 전에 설치 지점이 다른 유닛으로 막히거나 자원이 부족하면 재검사가 실패하고 조립 외형이 무너진다. 바닥 지정 시전은 커서 아래 적이 사라져도 그 이유만으로 취소하지 않는다.

## 중단과 공통 동작

- 큰 피격 경직·사망·슬롯 변경·발동 실패·필드 종료: 현재 부품 자세를 유지하며 붕괴한다.
- 아직 나타나지 않은 부품은 취소 후 생성하지 않는다. 미완성 잔해는 공격하거나 폭발하지 않는다.
- 작은 피격·방패 막기는 시전을 유지한다. 성공 발동 뒤의 피격은 이미 설치된 포탑을 취소하지 않는다.
- 일시정지·재시작·맵 교체를 따른다. 취소 잔해가 남은 동안 포탑/태엽인형을 다시 시전해도 별도로 처리한다.
- 기존 기계 충돌음을 조립/낙하 때 재사용한다. 검토 페이지의 렌더 캡처는 무음이다.

태엽인형과 포탑은 `summon_assembly.gd`를 공유한다. `automaton_assembly.gd`는 기존 부품/순서를 지정하는 프로필로 바뀌었고 기존 태엽인형 검사도 재실행했다. 과거 태엽인형 전달 매니페스트는 해당 커밋의 기록으로 보존하며 현재 공유 코드의 해시·검증은 이 포탑 전달 매니페스트를 따른다.

## 검증과 재생성

설치된 Blender에서 `tools/export_turret_assembly_v1.py`를 background로 실행하면 보호된 원본에서 사본을 재생성한다. 이번 작업에서 Blender MCP는 연결되지 않아 Blender 5.1.1 CLI를 사용했다. 이후 `tools/run_turret_assembly_v1.ps1 -Phase import/test/review`와 `tools/package_turret_assembly_v1.py`를 사용한다. `-Phase test -Test automaton_assembly`와 `-Test automaton_spawn_anchor`가 기존 인형 회귀다.

포탑 **2,371개 검사**, 기존 태엽인형 **405개 검사**, 기존 소환 위치 **20개 검사**를 통과했다. 태엽인형의 전체 전투/소환물 파괴 등 다른 과거 검사를 이번 실행으로 세지 않는다. 완성 정적 사본과 실제 스킨 모델의 24,333개 정점을 각 FCR에서 비교해 최대 차이는 약 **0.00746mm**였다. CPU 정점 좌표 비교이며 GPU readback은 아니다. 30/60fps × FCR 0/40 전체 physics 프레임에서 설치 완료 후 이동은 **0m**였다.

실제 arena 시전·피격 경직을 실행한 GPU **370장/7장면**을 기록했다. 성공/초반·중간·완성 직전 취소, 실제 크기/확대, FCR 40을 비교할 수 있다. 각 성공 장면에서 실제 소환체 위치와 idle 상태도 검사한다. 촬영에서만 취소 후 외형 시계를 명시적으로 진행했다. 실행 환경의 `user://` 캐시 진단은 실행 JSON에 구분한다.

공유 프로젝트에서 진행 중인 태엽인형 A/B 특화 변경도 보존했다. 각 최종 실행의 `inputs_before.json`/`inputs_after.json`으로 코드·설정이 검사 도중 바뀌지 않았는지 기록하며 매니페스트 생성 때 현재 파일과 대조한다. 해당 특화 규칙 자체의 구현·승인은 이 아트 작업의 범위가 아니다.

낙하는 120Hz 고정 간격의 표시용 중력·바닥 지지 계산으로 약 1.7초 뒤 정리한다. 부품끼리·벽과 충돌하는 실시간 물리 시뮬레이션이나 임의 지형 검증은 아니다. 86개 부품의 동시 조립에 대한 최종 성능 예산과 사용자 연출 평가는 별도다.
