## 1. 공통 원칙

## 2. 자율공방 (티어 IV, 설치·지원)

**역할:** 바닥에 펼치는 소형 정비 거점이다. 주변 소환체를 고치고, 부서진 태엽인형을 다시 조립해 내보낸다. 공격하지 않는다. 최종 성장의 상징인 거대 자동인형과 겹치지 않게, 위압감보다 **일하는 공장**의 인상을 준다.

| 항목 | 사양 |
|---|---|
| 크기 | 받침 약 2.0×1.6m, 전체 높이 1.7m(마녀와 비슷). 거대 인형(2.8m)보다 확실히 낮게 |
| 실루엣 | 포탑(삼각대 + 포신), 신호기(가늘고 높은 기둥)와 헷갈리지 않는 **넓고 낮은 작업대형**. 위에서 볼 때 조립 받침과 크레인 팔이 가장 먼저 읽혀야 한다 |
| 받침 | 접이식 철제 작업대. 네 모서리에 땅에 박히는 지지 다리 |
| 조립 받침 | 작업대 앞쪽의 회전 원판. 태엽인형이 이 위에서 조립된다(인형 모델은 게임이 따로 띄우므로 넣지 않는다) |
| 크레인 팔 | 뒤쪽 기둥에서 조립 받침 위로 뻗는 2관절 팔. 끝에 집게 |
| 수리 장치 | 작업대 옆의 청록 렌즈 또는 수리 안테나 하나. 수리 신호의 발생점 |
| 동력부 | 뒤쪽 태엽 드럼과 큰 톱니, 굴뚝 하나 |
| 부품 상자 | 옆에 부품이 담긴 상자 한두 개(고정 장식) |
| 삼각형 | 6,000~9,000 |
| 부품(예시, 약 18개) | 작업대, 지지 다리 4, 회전 원판, 기둥, 크레인 위팔·아래팔·집게 2, 수리 렌즈, 태엽 드럼, 톱니, 태엽 열쇠, 굴뚝, 부품 상자 |
| 게임 충돌 반경 | 0.9m |

노드는 아직 없다. 추가 부품 세트는 필요 없다.

## 3. 클립

| 클립 | 길이 | 내용 |
|---|---|---|
| `deploy` | 1.0초 | 시전과 같은 길이. 다리가 펴져 땅에 박히고, 기둥과 크레인 팔이 일어서고, 동력부가 켜짐 |
| `idle` | 2.0초 루프 | 톱니와 원판이 돌고, 굴뚝에서 김이 나는 작동 대기 |
| `repair` | 1.0초 | 수리 신호. **0초에 수리 렌즈가 가장 밝음** = 수리 시점. 2초마다 재생되며 끝 포즈는 `idle` 시작 포즈와 같다 |
| `assemble` | 1.0초 | 재조립. 크레인 팔이 원판 위로 내려와 작업한다. **0.8초에 팔이 올라가기 시작** = 태엽인형이 원판 위에 나타나는 시점. 끝 포즈는 `idle` 시작 포즈와 같다 |
| `hit` | 0.25초 | 작업대가 흔들림 |
| `shutdown` | 0.5초 | 시간이 끝남. 동력부가 꺼지고 팔과 다리가 접힘 |
| `death` | 약 1.4초 | 부서짐. 크레인 팔이 꺾이고 부품이 흩어짐 |

`repair`와 `assemble`은 겹쳐 재생될 수 있다. 관절이 겹치지 않게 **`repair`는 렌즈·안테나·톱니만**, **`assemble`은 크레인 팔·집게·원판만** 움직인다.

수리 범위(반경 6m) 고리와 수리 빛줄기는 게임 FX가 그린다. 모델에는 넣지 않는다.

## 4. 소켓

`Socket_repair`(수리 렌즈 중심), `Socket_assemble`(조립 원판 윗면 중심, 태엽인형 등장 위치), `Socket_bar`(체력 막대 기준), `Socket_core`(청록 동력부 중심). 바닥 그림자 반경은 parts.json에 숫자로 적는다.

## 5. 넘겨줄 때 확인할 것

- 1.75배 게임 카메라에서 마녀·태엽인형·자동포탑·유인 신호기·거대 자동인형과 한 화면에 놓은 비교 캡처.
- 시점 프레임(`repair` 0초, `assemble` 0.8초)이 표에 적은 대로인지.
- `idle` 루프 첫 키와 끝 키의 일치, `repair`·`assemble` 끝 포즈와 `idle` 시작 포즈의 일치.
- `repair`와 `assemble`이 움직이는 뼈가 서로 겹치지 않는지.
- 조립 원판 위에 태엽인형을 세웠을 때 크레인 팔과 부딪히지 않는지.
- 정점별 단일 뼈 100% 연결, 늘어나는 부품이 없는지.

게임 연결(규칙·표적·FX)은 모델이 들어온 뒤 코드 작업에서 한다.
