## 원본과 부품

`source/*_segmented_v2.glb`는 사용자가 완료한 Tripo 분할 결과를 추가 생성 없이 내려받은 원본이다. 각 원본의 packed `.blend`도 보존한다. 초기 통합 GLB와 v1 작업본도 `../combat_set_v1/`에 그대로 있다.

| 종류 | 사용자 분할본 | 게임용 강체 부품 | 삼각형 | 뼈 | 재질/맵 |
|---|---:|---:|---:|---:|---|
| 태엽인형 | 12 | 13 | 9,791 | 26 | 1재질, 1K PBR 3장 |
| 자동포탑 | 86 | 86 | 17,556 | 92 | 1재질, 1K PBR 3장 |

태엽인형의 part 8에 함께 들어 있던 좌우 다리 축을 작업 사본에서 좌우로 나눴다. 다른 부품의 사용자 분할 경계를 합치지 않았다. 포탑의 작은 금속 테두리/톱니를 유지하기 위해 v1 통합면의 7,999삼각형보다 작업 예산을 늘렸다. 166,205삼각형 분할 원본의 별도 경량 사본이다. 원본은 손대지 않았다.

부품 안에서만 5μm 이내의 중복 좌표를 용접해 UV/노멀 경계가 따로 축약되어 깨지는 문제를 줄였다. UV는 면 코너별로 유지한 뒤 원래 파트별 텍스처를 1K 아틀라스로 재배치했다. 파트별로 별도 재질 12개/86개를 유지하지 않고 각각 1개로 합쳤다. 모델을 새로 칠하거나 디자인을 재생성한 작업은 아니다.

각 정점은 부품 뼈 **하나에 100%** 연결한다. 하나의 삼각형이 서로 다른 부품 뼈에 걸치는 경우를 허용하지 않는다. 포탑은 하부 고정 / 상부 회전대 / 포신 반동 / 뒤 구동 톱니 / 태엽을 구분한다. 월드 수직 회전을 전체 rest 체인으로 변환해야 하며 v1의 로컬 rest 변환만 사용하면 새 리그가 다른 축으로 꺾인다.

## 동작과 게임 연결

- 인형: `idle`, `move`, `attack`, `hit`, **`death`**, **`explode`**.
- 포탑: `idle`, `attack`, `hit`, **`death`**. 조준은 상부 관절에 런타임 합성한다.
- 일반 파괴/포탑 수명 종료: 부품이 아래로 흩어지고 바닥에서 감쇠하며 주저앉는다. 통째로 앞으로 넘어지는 root 회전은 없다.
- 인형 수명 종료 자폭: 기존 폭발 피해가 실행되는 순간 `explode`로 분기한다. 청록 섬광/불꽃과 함께 부품을 더 넓고 빠르게 비산시킨다. 기존 기계 충돌음을 재사용한다.
- 사망 직전의 조준/공격 자세에서 0.12초간 파괴 동작으로 이어 붙여 중립 자세로 튀는 것을 막는다.
- 실제 대상/충돌은 기존 규칙대로 즉시 제거한다. 외형만 남아 약 2초 동작 후 0.25초 뒤 정리한다. 일시정지와 필드 초기화를 따른다.
- 피해량/범위/타깃/마나/쿨다운/수명/전투 RNG는 변경하지 않았다. 적에게 파괴된 인형은 자폭 피해를 내지 않는 기존 시험판 규칙을 따른다.

24fps이며 GLB 애니메이션은 **0초부터 시작**한다. `remove_immutable_tracks=false`를 유지한다. export에서 `export_anim_slide_to_zero=True`가 필요하다.

## 검증과 재생성

`tools/pack_summon_atlases_v2.py` → Blender `tools/build_summons_v2.py` → `tools/validate_summons_v2.py` → `tools/run_summons_v2.ps1 -Phase import/runtime/review` 순서다. 저장 blend에서 빠르게 다시 내보낼 때는 `tools/export_summons_v2.py`를 사용한다.

독립 GLB 검사에서는 모든 삼각형의 단일 강체 뼈, 단위 scale, 정규화 회전, 파트 수, 아틀라스, 게임 사본 해시를 검사한다. 실제 Godot 검사 `game/tests/summons_v2.gd`는 모든 클립의 변환, 360도 조준/하부 고정, 바닥, 일반 파괴·수명 종료 분기, 실제 폭발 피해/범위, 시작 자세 보존, 일시정지/정리를 검사한다. 기존 `combat_actors`, `enemy_types`, `boss`, `smoke_arena` 결과는 전달 manifest에 포함한다.

검토의 확대/실제 크기 영상은 실제 Godot 렌더 686장이다. 동작 이미지는 연출을 재생한 캡처이며, 전투 규칙 검사는 별도 런타임 결과를 따른다. 작업 환경의 알려진 `user://` 캐시 진단은 실행 기록에 남긴다.

## 남은 범위

부품의 강체 이동/회전과 바닥 접촉을 미리 구운 연출이다. **실시간 물리 파괴나 부품끼리/벽과의 충돌 해결은 아니다.** 잔해끼리 겹치는 부분과 분할 경계 안쪽/축약한 금속 테두리는 확대 시 보일 수 있다. 현재 평면 시험장용 연출은 사용자가 채택했다. 임의 지형과 최종 성능 예산은 별도 검증 대상이며 사용자 분할 원본과 v1은 비교/복구용으로 보존한다.
