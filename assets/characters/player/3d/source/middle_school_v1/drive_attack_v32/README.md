# 구동 공격 모션 v32 — 디딤발과 체중 이동

사용자 피드백(v31): 디딤발이 안정적이지 않고, 휘두르고 찌르는 자세가 어정쩡하다.

v31 진단:

- 찌르기·지속절단: 발이 대기자세 폭(발목 간 21.6cm, 평행)에 거의 그대로 있고 골반은 2.5~4.5cm만 내려 무릎이 거의 펴져 있다. 찌르기 거리 대부분이 팔에서 나오고(원본 곡선 이동량의 23%, 약 9cm) 체중 이동이 없다.
- 진입 스텝: 오른발이 들리지 않고(`lift=0`) 바닥에서 미끄러지며 앞으로 나간다.
- 그라인더: 발 폭은 그대로이고 상체만 돈다. 오른발이 공중 중간에 살짝 들렸다 내려온다.
- 회전 베기: 발 위치를 원본 Mixamo 발 궤적에서 축소·회전시켜 몸통과 같이 돌리므로 두 발이 원을 그리며 미끄러진다.

## v32 변경

모든 프레임을 명시적인 발 배치에서 다시 계산한다. 각 발은 **고정**(앞꿈치 위치 고정, 뒤꿈치를 들고 앞꿈치를 축으로 회전 가능) 또는 **스텝**(들어 올려 호를 그리며 내딛기) 상태이며, 고정된 발은 절대 이동하지 않는다. 무릎은 발끝 방향을 향하고, 골반은 두 발 사이에서 체중을 싣는다.

| 동작 | 스탠스 | 몸 동작 |
|---|---|---|
| 볼트커터 연속 찌르기 | 오른발이 앞으로 약 40cm 내딛고, 왼발은 제자리에서 앞꿈치로 48° 바깥으로 돈다 | 찌를 때 뒷다리가 밀어 골반이 약 15cm 전진, 상체 13° 숙임·어깨선 회전, 뒤꿈치 24° 들림. 자루 진행 약 40cm(팔+몸+슬라이드) |
| 그라인더 반원 | 왼발이 앞·바깥으로 스텝(넓은 스탠스), 오른발은 앞꿈치 회전 | 오른쪽으로 감기(골반 −34°, 어깨 −62°) → 골반 선행·어깨·공구 순으로 풀림. 체중이 오른발→왼발로 이동, 오른발 뒤꿈치 30° 들림 |
| 전기톱 지속절단 | 왼발이 공구 쪽 앞으로 스텝, 오른발 38° 바깥 회전 | 버티는 자세에서 골반·상체가 앞뒤로 작게 밀기 |
| 전기톱 회전 베기 | 오른발을 넓게 벌린 뒤, 왼발 앞꿈치를 축으로 360° | 축발 고정·뒤꿈치 16° 들림. 오른발은 낮게(6.5cm) 따라 돈 뒤 원래 자리에 착지, 이후 대기 위치로 스텝 |

이 리그는 대기자세에서 다리가 거의 펴져 있어(엉덩이–발목 거리가 다리 길이의 98%) 골반을 5cm만 내려도 무릎이 15cm 이상 앞으로 나온다. 쪼그려 앉은 인상을 피하려고 골반 하강은 2~6cm로 제한했다.

그립 규칙(오른손 앞/위, 26/13/22/11cm 간격, `staff_slide_tracks`, `grip_spacing_tracks`)과 재생 계약(24fps, `clip_time = normalized_phase * duration`, 상수 채널 유지, optimizer/compression 비활성)은 v31과 같다. 진입/루프/복귀 키 수와 `duration`, `preview_duration`도 v31과 같다. 스텝 이동은 골격 내부의 시각적 이동이며 대기 자세로 정확히 돌아온다.

기술 변경:

- 다리 IK: 무릎 pole을 발 방향으로, 허벅지/정강이 회전은 실제 무릎 hinge 평면에서 계산한다(팔과 같은 방식). 발가락은 앞꿈치를 축으로 들 때 바닥에 평평하게 남는다.
- 손 회전: 왼쪽 팔뚝이 자루와 거의 평행할 때 손 회전 정렬을 줄이고, ±180° 근처에서 직전 프레임 쪽 분기를 유지한다. 회전 베기에서만 자루 축 회전을 프레임당 9°로 제한하며, 대기로 돌아갈 때는 제한을 푼다. 이것이 없으면 중간 프레임 보간에서 보조손이 자루에서 최대 5cm 벗어났다.
- 그라인더: 변신복의 넓은 오른쪽 소매에 왼손이 들어가지 않도록, 왼쪽으로 넘어갈 때 오른쪽 팔꿈치를 v31보다 일찍(t=0.40) 든다.
- 루프의 진입/루프 twist branch는 연속으로 이어 굽고, 복귀는 진입의 정확한 역순이다(v31의 polish 단계가 따로 필요 없다).
- v29의 34메시 / 107 rest / 64 기존 액션을 보존한다. v30/v31 원본·GLB와 메인 게임 연결은 바꾸지 않았다.

## 검증

- 저장·보간 자세 968개: 양손과 몸통·골반, 양손 서로, 반대쪽 소매 교차 **0건**. 그립 기준점 최대 오차 2.826mm(기준 4mm), 다리 IK 오차 < 0.001mm.
- 보존 검사 통과, 8 GLB 내보내기·다시 가져오기 구조 확인, Godot 4.6.2 검사 272,971개 통과, 실제 GPU 캡처 300장 + 확대 24장.
- 이 PC에는 `blender-asset-qa` 스킬이 없어 carrier/reimport의 메시 QA 단계는 건너뛰고 `skipped`로 기록했다(carrier 모듈은 v30 이후 변경 없음). 구조 검사(107본, 액션 1개, carrier 1개)는 수행했다.

## 남은 범위

손목/소매 겹침과 블라우스·케이프 가장자리 접촉, 손가락과 자루의 완전한 밀착, 머리/외골격/모든 의상 간 충돌, 임의 phase 취소, 실제 스킬 속도·판정·성능, 사용자 최종 모션 선택은 이 검토본에 포함되지 않는다.
