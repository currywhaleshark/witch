# 짧은 이동 떨림 수정 v1 (2026-10-29)

사용자 보고: 캐릭터 바로 앞이나 벽 쪽을 찍으면 잠깐 빠르게 부르르 떤다.

## 원인

- 바로 앞(0.2~0.35m)이나 벽을 찍으면(목적지가 벽에서 약 0.5m 떨어진 보행 가장자리로 당겨짐) 이동이 3~5프레임 만에 끝난다.
- 그 사이 ① 방향이 한 프레임에 60~180° 꺾이고 ② 대기→달리기→대기가 연달아 전환되며 매번 클립을 0프레임부터 다시
  시작하고 ③ 대기(지팡이 세움)와 달리기(지팡이 가로) 자세가 0.1초 안에 오가 지팡이가 휘둘렸다.
- 위치 자체는 벽에서 튕기지 않고 정상 도착했다(실측).

## 수정 (`game/scripts/player_visual.gd`, 표현 전용)

- **방향:** 게임플레이 방향(`player_visual` 노드, 시전 조준 기본값으로도 쓰임)은 그대로 즉시 바뀐다. 보이는 몸(`AssetFacing`)만
  초당 20rad(180°≈0.16초)로 따라 돈다. 공격·시전·피격·사망 중에는 지연 없이 바로 대상 방향을 본다.
- **달리기 섞기:** 상태를 통째로 바꾸지 않고 대기·달리기 자세를 가중치로 섞는다. 0.2초에 걸쳐 들어가고 0.15초에 걸쳐 빠지며
  부드러운 곡선을 쓴다. 대기 동작은 자기 위상을 계속 이어가 멈출 때 처음부터 다시 시작하지 않고, 멈춘 뒤의 달리기 자세는 마지막
  보폭에서 멈춘 채 빠져나간다. 지팡이 슬라이드 값도 같은 비율로 섞는다.
- **아주 짧은 이동:** 위 곡선 때문에 2~3프레임 이동은 달리기 비중이 0.1~0.2 정도에 그쳐, 제자리에서 몸을 돌리며 살짝 기우는
  정도로 보인다.
- 이동 속도, 도착 판정, 경로, 공격 시작 시 즉시 방향 전환 등 규칙은 바꾸지 않았다. 행동이 끝난 뒤 이동으로 돌아가는 전환은 기존처럼
  바로 해당 클립으로 간다.

## 확인

- `before_short_moves.png` / `after_short_moves.png`: 실제 골목 맵(alley_v2), 실제 물리 루프에서 매 렌더 프레임을 근접 촬영.
  1~2행 짧은 앞 이동, 3~4행 뒤쪽 짧은 이동(약 180° 전환), 5~7행 긴 이동 후 정지(수정 후에만). `capture_script.gd`로 재촬영.
- 회귀 27종 exit 0, 실패 0, 스크립트 오류 0. 처음 실행에서 player_visual의 "도착 후 2프레임에 대기 클립 선택" 1건이
  실패해, 섞는 동안에도 현재 상태의 클립을 마지막에 고르도록 순서를 바꾼 뒤 player_visual·player_motion_v18·approach_cast·
  hold_input·smoke_arena를 다시 돌려 통과했다(나머지 22종은 순서 변경 직전 실행에서 통과).

## 추가 수정: 누른 채 짧게 찍을 때 위치 떨림 (`arena.gd`, 이동 규칙)

- 사용자 보고: 바로 앞을 찍으면 애니메이션은 괜찮아졌지만 위치가 부르르 하는 구간이 있다.
- 원인: 버튼을 누르고 있는 동안 커서 지점이 매 프레임 목적지가 되어 조금씩 움직이는데, 경로는 목적지가 0.4m 넘게 움직이거나
  0.5초가 지나야 다시 계산된다. 계단·높은 바닥 근처에서는 내비 경로의 끝점이 목적지와 어긋나 있어서, 캐릭터가 옛 경로 끝점을
  지나치면 그쪽으로 되돌아가고, 거기서 다시 목적지로 가며 8cm를 매 프레임 왕복했다(실제 마우스 입력으로 재현, 40프레임에 26번 반전).
- 수정: 경로 마지막 구간에서 목적지가 경로 끝점에서 0.6m 안이면 끝점 대신 목적지로 곧장 향한다(`follow`, 소환체 이동에도 공통).
  도착 판정과 제자리 대체 이동 방향은 수평 거리만 본다(발은 항상 바닥을 따르므로). 일반 이동이 목적지 0.6m 안에서 턱·소품에
  막혀 거의 못 나아가면 그 자리를 도착으로 친다(접근 후 시전은 제외).
- 확인: 골목 맵의 평지와 높이 0.4~1.2m 지점 9곳 × 커서 방향 3개 = 27회, 실제 마우스 누름·6프레임 유지·뗌. 수정 전 1곳에서 26회
  왕복, 수정 후 전부 왕복 0회이고 모두 멈춤.

## 추가 수정: 바닥에 쏜 산탄이 바닥으로 박힘 (`shotgun_geometry.gd`, `arena.gd`)

- 원인: 산탄 조준점이 클릭한 바닥 지점보다 1.2m 위였다. 총구는 1.12~1.8m 높이라, 가까운 바닥을 찍거나 낮은 쪽 바닥을 찍으면
  포신과 산탄이 아래로 기울었다(높은 바닥에서 아래쪽을 찍을 때 -8~-30°, 탄 끝 2.4~5.9m에서 바닥 충돌).
- 수정: 적을 겨눈 경우는 그대로 적 가슴 높이를 겨누고, 바닥을 찍은 경우는 총구 높이에서 수평으로 쏜다. 피해 판정(수평 원뿔·사거리·
  엄폐 광선)은 기존과 같고, 포신 모델과 탄선 그림만 수평이 된다.
- 확인: 같은 지점·같은 클릭에서 수정 전후 포신 기울기와 7발 탄선 길이를 비교. 높은 바닥(1.0m)에서 2m 앞 아래쪽을 찍으면
  -12.2° / 5.2~5.9m → 0° / 대부분 8m(벽에 막힌 탄 제외).

## 남은 한계

- 전용 한 걸음 동작이 없어 짧은 이동은 발을 거의 떼지 않고 미끄러지듯 옮긴다(게임 배율 20~30픽셀).
- 섞이는 중간 자세에서 양손과 지팡이의 접촉은 따로 검증하지 않았다(기존 정지 섞기에서도 최대 약 21mm 벌어짐이 기록돼 있음).
- 플레이 감각 승인은 아니다.
