# 대기 → 이동 지팡이 전환 수정

2026-10-30. 지팡이 기본형·공구 조립·볼트커터 v2·선택된 재질 v3는 `a8b8cfb`로 커밋했다. 이어 사용자가 지적한 이동 시작 시 지팡이의 큰 좌우 회전을 수정했다. `review.html`에서 같은 실제 게임 입력의 전후를 비교한다.

사용자가 「좋아 커밋」으로 이 전환 수정을 시험판용으로 선택했다. `approval.json`에 기록한다.

## 원인과 변경

대기는 v20, 달리기는 팔꿈치와 손목을 고친 v21 동작이다. 오른팔 아래팔의 분할 뼈와 손에 각각 약 109~110도의 로컬 회전 차이가 있었다. 이전 혼합은 이를 뼈별로 더해, 끝 자세끼리의 지팡이 방향 차이보다 훨씬 크게 중간 회전을 만들었다. 고정 방향으로 이동해도 재현되므로 캐릭터의 방향 전환 때문은 아니다.

`game/scripts/staff_locomotion_blend.gd`는 부분 혼합 구간에서 지팡이 하나의 공간상 위치·회전을 보간하고, 두 손을 그 기준에 맞춘다. 팔꿈치는 두 자세의 위치를 이어 팔 길이를 유지하는 두 관절 해법으로 구하고, 3개씩 나뉜 위팔/아래팔의 회전은 같은 공간에서 잇는다. 이동/정지의 기존 0.20/0.15초 혼합 시간을 그대로 사용한다. `player_visual.gd`의 호출 지점은 6줄 추가다.

전체 대기·달리기 및 나머지 5개 동작, 107개 기준 뼈, 자산/재질, 하체·의상·손가락 로컬 트랙과 전투 수치는 바꾸지 않았다. 바뀌는 것은 부분 혼합 중 양팔의 14개 뼈다. 오른손 위·왼손 아래의 26cm 간격을 유지한다.

## 검증

- 대기 4위상 × 달리기 16위상 × 혼합 11단계와 30/60fps의 세 이동 속도, 짧은 정지/재출발·회전·일시정지: 총 1,514개 샘플.
- 손 간격 최대 오차 0.051735mm, 팔 길이 최대 오차 약 0.000477mm. 나머지 93개 로컬 뼈 채널 오차와 이동/회전/달리기 시계 차이는 0이다. 양 끝의 원래 동작과도 이어진다.
- 신규 검사 14개, 기존 player_visual 192개, player_motion_v18 787개, bolt_cutter_v2 278개: 합계 1,271개 통과. 네 실행 모두 종료 0·빈 stderr·입력 변경 없음.
- 실제 게임 전후의 이동 위치·방향·재생 시간이 동일한 455장 GPU 캡처. 확대 정면/비스듬한 시점의 전후와 기존 1.75배 카메라의 수정 후 화면이다. GPU 실행은 종료 0이며 기존 작업 폴더 shader-cache 진단만 stderr에 남았다.

지팡이 끝의 첫 0.2초 모델 좌표 X 범위는 이전 -0.684~+0.415m에서 수정 후 -0.614~-0.474m로 바뀌었다. 반대쪽을 크게 돌던 경로는 사라지고 원래 달리기의 작은 흔들림이 남는다. 실제 화면의 세계 크기는 모델 스케일을 적용한다.

검증 해시는 `delivery_manifest.json`을 따른다. `player_visual_before.gd`는 수정 전 전체 파일을 보존한다. GPU 비교의 이전 버전은 그 파일의 `_sample_locomotion`만 그대로 사용하는 파생 컨트롤러로, 동일한 현재 재질/게임 환경에서 원인을 비교한다.

변신복을 새로 촬영한 검사나 모든 의상 접촉 해결, 최종 성능 예산은 포함하지 않는다. 현재 게임 일상복에서 확인한 전환 수정이다. `tools/run_run_entry_v22.ps1 -Test run_entry_v22`와 같은 실행기의 기존 회귀/`-Phase review`, `tools/package_run_entry_v22.py`로 재검증한다.
