# 소환체 따라가기 방향·겹침 수정 v1 (2026-10-29)

사용자 보고: 인형이 자기 목표로 갈 때는 괜찮은데 플레이어를 따라올 때는 방향을 바꾸지 않고 걷기만 한다. 그리고 다 겹쳐 있다.

## 원인

- 방향: `_tick_allies`는 목표가 있을 때만 `look_at`으로 몸을 돌렸다. 따라가기(목표 없음, 화면 밖 복귀)는 위치만 옮겼다.
- 겹침: 모든 이동형 소환체가 같은 대기 지점(`automaton_spawn_position()`, 마녀 기준 (1, 0, 0.6))을 따라가서 한 자리에 쌓였다.
  같은 적을 공격할 때도 서로 거리를 두는 처리가 없었다.

## 수정 (`game/scripts/arena.gd`)

- **자리 나누기:** 이동형 소환체마다 마녀 주변 고정 자리(`FOLLOW_SLOTS`, 8곳)를 하나씩 맡는다. 첫 자리는 기존 대기 지점과 같아서
  1기만 있을 때의 시전·대기 위치는 바뀌지 않는다. 새 인형은 비어 있는 가장 앞 자리를 받고, 조립 미리보기도 그 자리에 놓인다.
- **간격 유지:** 소환체끼리(포탑 포함, 포탑은 움직이지 않음) 0.85m(바닥 고리가 닿지 않는 거리)보다 가까우면 매 틱 최대 2m/s로
  서로 밀어낸다. 걸을 수 없는 곳으로는 밀지 않는다. 무작위 수는 쓰지 않는다.
- **방향 전환:** 따라가기와 화면 밖 복귀 중에는 이동 방향으로 부드럽게 몸을 돌린다. 목표를 쫓을 때는 기존처럼 목표를 바로 본다.
- 공격·피해·사거리·자폭 범위 규칙은 바꾸지 않았다. 다만 간격 유지로 실제 서는 위치가 조금 달라질 수 있다.

## 확인

- `follow_and_fight_sheet.png` / `follow_and_fight_log.txt`: 평지에서 인형 3기 소환 → 마녀가 두 방향으로 이동 → 적 1기와 교전.
  실제 물리 루프, 4프레임마다 기록. 따라가는 동안 세 인형 사이 거리는 각자의 자리 간격(1.5~2.5m)을 유지하고 모두 이동 방향으로
  돈다. 교전 중 최소 간격 0.85m. `capture_script.gd`로 재촬영.
- 회귀 27종 exit 0, 실패 0. 처음엔 `automaton_spawn_anchor`가 인자 없는 `automaton_spawn_position()`을 "다음 빈 자리"로 해석해
  4건 실패했다. 인자 없는 호출은 기존 대기 지점(0번 자리)을 뜻하게 되돌리고, 시전 쪽만 `free_follow_slot()`을 넘기도록 바꿔 소환 관련
  10종을 다시 통과했다(나머지 17종은 직전 실행에서 통과).

## 남은 한계

- 자리는 세계 기준 고정 오프셋이라 마녀가 바라보는 방향과 무관하다(기존 대기 지점과 같은 방식).
- 좁은 골목에서 자리가 벽 너머일 때는 걸을 수 있는 가장 가까운 지점으로 붙는다. 그 경우 두 인형의 자리가 가까워질 수 있다.
- 몸끼리의 물리 충돌이 아니라 간격만 맞추는 방식이다. 적·마녀와의 겹침은 다루지 않았다.
