# 시전 마법진 v1 (2026-10-30)

사용자 요청: 캐스팅할 때 발밑에 마법진을 띄운다. 공통 모양에 화기·구동·자동화 트리 각각의 고유 특징을 더한 모양으로.

## 모양 (`game/shaders/cast_circle.gdshader`, 극좌표로 그리는 절차적 무늬)

- **공통:** 계기판 같은 겹 테두리와 눈금, 안쪽 고리, 가운데 점. 바깥 테두리는 나타날 때 한 바퀴 그어지듯 생긴다.
- **화기 (주황):** 천천히 도는 6연발 실린더(약실 6개)와 고정된 조준 십자선.
- **구동 (황동 금색):** 바깥 톱니가 한 방향, 안쪽 기어와 바퀴살이 반대 방향으로 돌고, 네 곳에 작은 톱니가 맞물린다.
- **자동화 (청록):** 가운데 태엽 스프링(나선), 시계 눈금(3시간마다 굵게), 서로 이어진 다섯 노드가 도는 연결망.
- 밝은 바닥에서도 색이 하얗게 날아가지 않도록 프리멀티플라이드 혼합을 쓴다(처음 더하기 혼합은 화기·구동이 흰색에 가깝게 보였다).

## 동작 (`game/scripts/cast_circle.gd`, `arena.gd`, 표현 전용)

- 트리 구분: 산탄 = 화기, 볼트커터·그라인더·전기톱·방패 = 구동, 태엽인형·포탑·표적 중계 = 자동화(`SKILL_TREES`).
  기본 공격에는 마법진이 없다.
- 시전 시간이 있는 기술(산탄·태엽인형·포탑): 시전을 시작하면 발밑에 커지며 나타나고, 진행될수록 밝아지며 빨리 돈다. 발동 순간
  번쩍 커졌다가 0.45초에 걸쳐 사라진다. 취소·실패되면 번쩍임 없이 사라진다.
- 즉시 기술(방패·공구·표적 중계): 발동 순간 마법진이 번쩍 떴다가 사라진다.
- 마녀를 따라 움직이고, 일시정지 중에는 멈추며, 리셋 때 지운다. 시전 규칙·비용·발동 시점은 그대로다.

## 확인

- `cast_circle_sheet.png`: 평지에서 실제 슬롯 입력으로 산탄, 방패, 태엽인형, 포탑을 차례로 시전하며 각 2·10·20·32·44프레임.
  재촬영은 `game/tests/review_cast_circle.gd`.

## 한계

- 산탄은 시전 시간이 0.125초로 짧아 충전 단계는 거의 보이지 않고 발동 번쩍임 위주로 보인다.
- 어두운 골목·다른 이펙트와 겹치는 상황의 가독성, 플레이 감각, 성능은 따로 보지 않았다.
- 트리 구분은 이 시험판의 기술 목록에 맞춘 고정 표다. 새 기술은 표에 추가해야 마법진이 뜬다.
