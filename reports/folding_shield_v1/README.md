# 접이식 방패 · 물약 빛 · 공구 교체 링 제거 (2026-10-30)

사용자 요청: 물약은 물약 색 빛 효과로, 공구 교체 링은 제거, 방패는 새 모델로 — 접이식 방패가 조립되고 전개되고 끝나면 분해된다.
처음 고른 형태는 **앞에 뜨는 부채꼴 방패**였고, 확인 후 사용자가 참고 사진과 함께 **양옆 삼단 접이식 패널 두 개**로 바꿨다.

## 접이식 방패 (`game/scripts/shield_visual.gd`, 모델 `assets/props/folding_shield_v1/`)

처음엔 앞에 뜨는 부채꼴 방패로 만들었으나, 막는 방향을 알 수 없어 앞쪽 고정이 어색하다는 의견에 바꿨다. 지금은 사용자가 보낸
경찰 삼단 접이식 방패를 본뜬 패널 **두 개가 마녀 양옆**에 뜬다. 둘러싸면 마녀가 가려지고 지팡이 공격에 걸릴 수 있어 양옆만 맡는다.

시전 즉시(기존과 같이 시전 시간 없음) 생긴다. 지속 시간·막기 확률·막은 공격의 무경직은 모두 기존 규칙 그대로이고, 이 스크립트는
보여 주기만 한다.

1. 조립 0.3초: 각 패널의 가운데 판이 먼저, 이어 양쪽 날개가 청록빛을 띠며 날아와 접힌(날개를 뒤로 접은) 상태로 모인다.
2. 전개 0.22초: 날개가 경첩에서 펴져 살짝 앞으로 오목하게 잠기고, 그 순간 청록 섬광·불꽃·소리가 난다.
3. 유지: 마녀 좌우 0.66m, 허리 높이에 살짝 떠서 각각 바깥 앞쪽(55°)을 보며, 마녀가 보는 방향을 부드럽게 따라 돈다.
4. 막기: 가장 가까운 적이 있는 쪽 패널이 마녀 쪽으로 튕겼다 돌아오고 빛이 번쩍이며, 막기 효과가 그 패널 앞면에서 터진다.
5. 끝: 지속 시간이 끝나거나 마녀가 쓰러지면 0.16초에 날개를 접고 0.4초 동안 부품이 흩어지며 사라진다. 리셋 때는 즉시 지운다.
   다시 시전하면 펴진 방패는 그대로 두고 시간만 갱신, 사라지는 중이면 새로 조립된다. 일시정지 중에는 멈춘다.

기존 막대 고리(`shield_ring`)는 이름만 남은 빈 노드다(리뷰 스크립트 호환).

## 물약 빛 (`combat_vfx.gd` `potion_glow`, `glow_light`)

마시는 순간 물약 색(체력 빨강, 마나 파랑, 회복 보라, 속도 초록)의 실제 점광원이 주변을 0.7초 비추고, 가슴 높이 섬광과 몸 둘레로
감아 오르는 빛 입자가 생긴다. 기존 바닥 고리 대신이다.

## 공구 교체

공구를 바꿀 때 발밑에 퍼지던 고리를 없앴다. 지팡이가 직접 변형하는 모습으로 충분하다.

## 확인

- `shield_sequence.png`: 실제 아레나 경로로 R 시전 → 조립·전개 → 막기(이 캡처에서만 막기 확률을 1로) → 지속 시간 끝 → 접기·분해.
- `shield_facings.png`: 펴진 두 패널을 마녀가 여섯 방향을 볼 때의 게임 카메라에서. 어느 방향이든 한쪽 패널의 앞면이 보인다.
- `reports/potion_glow_v1/potion_glow_sheet.png`: 골목에서 네 종류 물약을 마신 직후부터.
- 회귀 결과는 세션 기록·커밋 메시지에 있다.

## 한계

- 막기 판정에 공격 방향 정보가 없어, 반응하는 패널은 가장 가까운 적의 위치로 고른다.
- 실제 물리 충돌·관통 검사는 없다. 넓게 휘두르는 공격 동작과 패널이 겹치는지는 따로 확인하지 않았다.
- 재질은 텍스처 없는 단색 PBR이다. 아트 승인·성능 측정이 아니다.
