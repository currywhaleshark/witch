# 도구 전환 강조 v1 (2026-10-30)

사용자 의견: 도구 전환 시 이펙트가 부족해 잘 안 보인다. (앞서 발밑 고리는 사용자 요청으로 뺐다.)

## 바뀐 것 (표현 전용)

- `combat_vfx.gd` `tool_shift`: 지팡이 머리에서 그 도구 색의 섬광·짧은 실제 점광원·별빛 선·위로 튀는 불꽃, 양옆으로 빠지는 증기.
  0.22초 뒤(지팡이 부품 조립 시간과 같음) 부품이 맞물리는 두 번째 금빛 '철컥' 섬광과 불꽃이 한 번 더 난다.
  지연 방출은 새 `later()`로 이펙트 자신의 시계에서 처리해 일시정지 중에는 멈춘다.
- 도구 색은 아레나의 기존 `TOOL_COLORS`(볼트커터 황동, 그라인더 강철, 전기톱 빨강)를 조금 밝게 쓴다. 맨 지팡이로 돌아갈 때는
  청록이고 70% 세기다.
- `arena.gd` `flash_tool_change`: `tool_changed`(장착·교체), `tool_released`(수동 해제와 마나 소진 해제) 사건에서 호출한다.
  위치는 실제 지팡이 머리(`staff_root` 기준 0.9m)다. 공구 규칙·마나는 그대로다.

## 확인

- `tool_switch_sheet.png`: 골목에서 실제 슬롯 입력으로 볼트커터 → 그라인더 → 전기톱 → 해제, 각 전환 뒤 1·4·8·14·20프레임.
  재촬영은 `game/tests/review_tool_switch_vfx.gd`.
