# 바닥 링 제거 · 선택 테두리 · 등급 후광 v1 (2026-10-30)

사용자 요청: 아래 링을 없애고, 선택한 적은 링 대신 테두리를, 강화·정예 몬스터는 링과 머리 위 상자 대신 후광 같은 느낌을 넣는다.
플레이어와 소환수 링도 뺀다.

## 바뀐 것 (`game/scripts/arena.gd`, 셰이더 3개, 표현 전용)

- **제거:** 마녀 발밑 청록 링과 공구별 색 링(지팡이 모양이 이미 현재 공구를 보여 줌), 소환체 발밑 링, 적 등급 링과 머리 띠 상자,
  마우스를 올린 적의 빨간 바닥 링. 클릭 목적지 표시, 방패 고리, 적 사망 순간의 고리 효과는 링이 아니라 이벤트 표시라 남겼다.
- **선택 테두리:** 마우스를 올린 적의 메시 위에 덧그림(material overlay)으로 빨간 테두리를 그린다. 메시를 법선 방향으로 3cm
  부풀려 그리되, 먼저 그린 스텐실 마스크가 몸이 차지한 픽셀을 표시해 두므로 실루엣 바깥에만 깨끗한 띠가 남는다. 적의 크기와
  무관하게 같은 굵기다.
- **사망 링 제거:** 적이 쓰러질 때 바닥에 퍼지던 빨간 고리도 없앴다(쓰러지는 동작이 그 역할을 한다). 공구 전환·방패·물약 순간
  고리는 그대로다.
- **등급 후광:** 강화는 파랑, 정예는 금색. 첫 버전이 너무 진하다는 의견에 7cm 껍질, 세기 0.55로 은은하게 낮췄다. 부풀린 껍질을 더하기 혼합으로 실루엣 바깥에만 그리며, 몸 쪽이 가장 밝고 바깥으로
  흐려진다. 위로 올라가는 일렁임과 느린 호흡으로 살아 있는 느낌을 준다. 기존 등급 색(`7f9fd6`, `d8b77b`)은 더하기 혼합에서
  흰색에 가깝게 보여 채도를 높인 색을 따로 쓴다. 보스 등급은 대상이 아니다.
- 죽은 적의 쓰러지는 잔해에는 테두리·후광을 남기지 않는다. 판정·체력·등급 규칙은 그대로다.
- 리뷰 스크립트들이 캡처 전에 숨기던 `hover_ring`, `tool_rings`는 이름만 남겼다(빈 노드·빈 목록).

## 확인

- `flat_*.png`, `alley_v2_*.png`: 평지와 골목에서 일반·강화·정예 적, 선택된 적 1기, 마녀와 소환체 2기를 게임 배율(`native`)과
  확대(`close`)로 촬영. 재촬영은 `game/tests/review_enemy_marking.gd`.
- 회귀 결과는 세션 기록과 커밋 메시지에 있다.

## 한계

- 스텐실은 Godot 4.5+ 기능이며 현재 Compatibility 렌더러에서 동작을 확인했다. 다른 렌더러는 확인하지 않았다.
- 몸에 가려진 다른 물체 앞쪽으로도 테두리 일부가 보일 수 있다(깊이 쓰기를 하지 않는 덧그림).
- 성능 측정은 하지 않았다. 표시된 적마다 메시를 2~3번 더 그린다.
