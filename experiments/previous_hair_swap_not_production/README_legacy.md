# 마녀도시 SCG 헤어스타일 교체 시제품 02

새 원화를 생성하지 않고 기존 세미롱/트윈테일 원화 두 장으로 제작한 교체 테스트.

## 여는 법

`witch_scg_hair_swap_demo.html`을 Chrome, Edge, Safari 등 브라우저에서 직접 열면 모든 그림이 내장되어 있어 오프라인 동작합니다. HTML의 헤어 선택 버튼으로 세미롱과 트윈테일을 전환하고 같은 머리색/눈색/의상색을 비교하세요. PNG 저장과 설정 JSON 저장 지원.

## 구현 방법

- `base_semilong.png`: 원래 세미롱 캐릭터 기준 그림
- `twin_hair_delta_experimental.png`: 트윈테일 원화에서 만든 교체 영역 RGBA 패치. 원래의 머리 부분을 지우기 위해 일부 배경/피부/의복 픽셀도 포함합니다.
- `swap_mask.png`: 두 그림의 머리 색과 실루엣 차이를 바탕으로 교체할 픽셀을 지정하는 마스크.
- `twin_hair_[color].png` 및 `semilong_hair_[color].png`: 헤어스타일별 색상 오버레이.
- `semilong_iris_[color].png`, `semilong_cardigan_[color].png`: 기존 시제품의 색상 오버레이 재사용.

## 한계

이는 완전한 독립 2D 머리파츠가 아니라 이미지 간 차이 영역을 겹쳐 합성하는 델타 패치 프로토타입입니다. 얼굴/의상 대부분을 그대로 유지하지만, 머리와 맞닿은 일부 피부·배경·의복 픽셀이 변경됩니다. 실전에서는 원화 단계에서 공통 얼굴·기본 몸체·앞머리·뒷머리·측면 머리를 별도 그려 완전히 겹침을 제어해야 합니다. 수작업 마스크 품질 검증 필요.

트윈테일 패치 소스: `차분한_트윈테일_교복_소녀.png`; 기준 원화: `차분한_교복_소녀_초상화.png`. 모든 원본 이미지는 그대로 보관.
