# 능력치·성장·자유 초기화 — 설계 초안

> **현행 v0.3 · 2026-10-25.** 이 문서는 모든 마녀 공통 **스탯·명중·치명타·지속 피해 계산의 단일 규칙 원본**이다. 스킬 입력은 [02](02_combat.md), 개별 스킬은 [03](03_skills.md), 적 등급 후보는 [05](05_content.md), 테스트는 [06](06_vertical_slice.md)을 참조한다.

## 1. 합의한 기본 방향

- **[합의] 스탯 포인트를 플레이어가 직접 배분**한다. 캐릭터가 레벨업할 때 정해진 스탯으로 자동 성장하는 방식만으로 빌드를 고정하지 않는다. **얼마나 자주/몇 점씩 획득하는지**는 아직 정하지 않았다.
- **[합의] 스킬과 스탯은 모두 무료로 자유롭게 초기화**할 수 있다. 초기화 아이템·게임 내 화폐 지불·횟수 제한 등으로 빌드 실험을 막지 않는다.
- **[합의된 기존 원칙]** 화기·구동·자동화는 기계장치의 마녀라는 하나의 이름 안에서 **스킬로 선택하는 권능 활용 방식**이다. **[사용자 요구·현재 방향] 기본 스탯 자체는 모든 마녀가 공유하는 보편적 자질**이어야 한다. 특정 기본 스탯을 찍지 않았다고 특정 트리의 공격·소환이 원천적으로 불가능해져서는 안 된다.
- **[합의된 기존 원칙]** 스킬 습득·스킬 레벨 상승·일반 강화 노드·특화 노드는 **같은 스킬 포인트 풀**을 사용한다. **스탯 포인트와 스킬 포인트까지 하나의 풀을 공유할지**는 별개 문제이며, **[제안] 우선 서로 다른 포인트 풀**로 관리해 밸런스와 리셋 UI를 분리한다.
- **[미결]** 초기화 메뉴의 구체적인 위치·진행 중 전투에서 사용 가능한지·확인 동작·프리셋 저장 기능. **초기화 자체의 무료·무제한 원칙은 결정 완료**다. 리셋 후 스탯 포인트와 스킬 포인트가 각각 전액 반환되어 다른 배분이 가능해야 한다는 것은 자연스러운 [구현 제안].

## 2. 공통 기본 스탯 — [명칭 합의]

모든 마녀가 같은 기본 스탯을 사용한다. '출력·정밀·내구·동력'은 기계장치의 마녀에 치우친 **폐기된 이름 후보**이며 현재 공통 명칭이 아니다.

| 스탯 | 1차 역할 | 적용 원칙 |
|---|---|---|
| **위력** | 피해량 | 근접·원거리·소환 등 다양한 직접 공격에 유효해야 함. 출혈과의 관계는 **§2.3 미결** |
| **기교** | 명중률 + 치명타 확률 [현재 방향] | 확률적 명중 판정이 없는 직접 공격에도 치명타로 기여 |
| **활력** | 최대 체력 | 마녀 자신의 체력. 소환체 내구도 상속은 미결 |
| **의지** | 최대 마나 | 권능 발동·공구 지속 유지에 쓰는 자원. 마나 회복 등 부가효과는 미결 |

**[합의]** 캐릭터가 스탯 포인트를 직접 배분하며, **스탯과 스킬 초기화는 모두 무료·무제한**이다. 한 스탯을 투자하지 않았다고 특정 스킬트리가 원천 봉쇄되지 않게 한다. **[제안]** 스탯 포인트와 스킬 포인트를 별도 풀로 관리한다(아직 미승인).

### 2.1 명중·치명타 판정 — [현행]

| 피해 사건 | 확률적 명중 굴림 | 치명타 |
|---|---|---|
| 일반 근접 타격·직접 사격 등 명중형 공격 | 공격별로 적용 [구체 범위 미결] | 적용 |
| 확정 적중·자동 추적 공격 | 생략 | 적용 |
| 광역 폭발·장판 등 직접 광역 피해 | 생략 | **피해받는 적마다 독립 판정 [합의]** |
| 자동인형·포탑의 직접 공격 | 개별 공격 방식에 따라 적용 | 적용 [상속 계수 미결] |
| **출혈 지속 피해** | 해당 없음 | **불가 [합의]** |

- **명중 굴림 생략 ≠ 공간 판정 생략.** 발사체 충돌, 범위, 사거리, 실제 표적 유효 여부는 판정한다.
- **[합의] 광역 직접 피해는 적마다 치명타를 따로 굴린다.** 스킬 1회에 단일 치명 결과를 뽑아 모두에게 적용하지 않는다.
- **[합의] 출혈은 직접 타격과 별도인 비치명 피해 사건이다.** 출혈을 발생시킨 전기톱 타격 자체에는 정상 명중·치명 규칙이 적용된다.
- **[미결]** 일반 명중률 공식과 기본값/상한, 치명 배율/상한, 여러 차례 타격하는 광역기의 판정 시점, 소환체의 기교·장비 치명 확률 상속.

### 2.2 출혈 상태의 피해 계산 — [단일 원본]

**[합의]** 출혈은 **방어력을 무시하고 치명타가 발생하지 않는 지속 피해**다. 출혈 유발 타격의 직접 피해는 별도로 계산한다. 방어력 감소(그라인더 등)가 **출혈 자체의 피해를 증가시키지는 않는다**. 방어 이외의 저항·피해 감소를 모두 무시한다는 뜻은 아니다.

**[사용자 제안·현재 방향]** 피해는 **적 최대 체력 비례**이며 **적의 전투 등급에 따라 적용 비율을 낮춘다**. 일반·강화·정예·보스의 4단계 명칭은 [05 몬스터 문서](05_content.md)의 **제안**이고, 단계 수·등급별 수치는 미결이다. 보스 출혈 비율을 0으로 두어 완전 면역으로 만들지는 않는 방향을 시험한다.

**[제안 공식, 계수 미확정]** `출혈 1회 총 피해 기준값 B = 대상 최대 체력 × 적 등급별 출혈 비율`.

- **[합의]** 출혈은 **한 적당 최대 5중첩으로 우선 시험**한다(최종 상한이 아니라 플레이 테스트 기준).
- **[합의]** 중첩 피해는 **합연산**이고 뒤에 쌓는 출혈일수록 피해 기여가 줄어든다. 전체 피해에 반복 곱셈을 하지 않는다.
- **[합의]** 각 중첩은 **적용 시점부터 독립적인 지속시간·만료**를 갖는다. 새 출혈이 기존 모든 중첩의 타이머를 갱신하지 않는다. 앞선 중첩이 만료되어도 나머지 타이머는 그대로 유지한다.
- **[설명용 수치, 확정 아님]** `n`개의 활성 중첩이 모두 온전하게 유지될 때의 상대 기여를 `B × (w1 + ... + w_n)`(`n ≤ 5`, `w1 > w2 > ... > 0`)으로 생각할 수 있다. `100% + 50% + 25% = 175%`는 첫 3개 중첩의 **예시**이지 실제 계수나 3중첩 한도가 아니다.
- **[미결]** 비율이 **1회 총 출혈 피해**에 적용될지 개별 틱 피해에 적용될지, 틱 간격·지속시간 길이, 감쇠 가중치, 5중첩 상태에서 6번째 출혈의 **무시/단일 중첩 교체/해당 중첩만 갱신**, 만료 뒤 피해 가중치 재배치, 중첩 재적용을 통한 보스 피해 폭주 방지, 방어 이외 저항 계산.

### 2.3 출혈과 위력·스킬 레벨의 관계 — [미결, 구현 전 결정 필요]

**현재 출혈 기준 공식에는 위력 스탯도 출혈 스킬 레벨도 포함되어 있지 않다.** 이것은 **효과를 주지 않기로 합의한 게 아니라 아직 정하지 않은 설계 공백**이다. 그대로 구현하면 위력을 높이거나 출혈 스킬 레벨을 올려도 출혈 피해가 증가하지 않을 수 있다.

- **[검토안 A]** 위력·스킬 레벨이 출혈 비율에 보정되도록 하되, **적 등급별 비율/총 피해 상한으로 보스 폭주를 제한**한다.
- **[검토안 B]** 위력은 **출혈을 부여하는 직접 타격**에만 적용하고, 스킬 레벨은 출혈의 **지속·적용·중첩 효율** 등으로 성장시킨다.
- **[미결]** 두 방식 중 어느 쪽인지, 혼합안인지, 피해 스냅샷/동적 갱신 방식, 장비·패시브가 출혈에 관여하는지. **사용자 승인 전에는 출혈의 위력/레벨 보정식을 확정하거나 임의 수치를 넣지 않는다.**

## 3. 파생 능력치와 장비의 관계 — [기존 합의 + 제안 구분]

기존 장비 문서([04_items.md](04_items.md))의 **시전 속도(FCR/패캐), 공격 속도(IAS/공속), 타격 회복(FHR/패힛)**는 서로 분리된 파생 능력치다. **[사용자 제안·현재 방향]** 장비·패시브 등으로 얻은 같은 종류의 속도 보너스는 합산 후 소프트캡 적용. **재사용 대기시간 감소(쿨감) 도입 여부와 규칙은 아직 미결**이다.

**[제안]** 기본 스탯 네 축이 FCR·IAS·FHR을 직접 대량 제공하면 **장비 속도 옵션 vs 생산 효율 패시브**의 선택 관계가 무너질 수 있으므로, 당장은 속도 능력치를 **장비와 특정 기계 패시브 중심**으로 유지하고 기본 스탯과의 연결은 나중에 검토한다.

**[제안]** 장착 아이템의 요구 스탯이 지나치게 높아서 장비 선택이나 잦은 초기화를 방해하는 **엄격한 힘·민첩·지능 요구치**는 지양한다. 실제 스탯 요구 장비를 도입할지, 리셋 후 장착 요건을 잃은 장비를 어떻게 처리할지 결정되지 않았다.

## 4. 자유 초기화의 의도와 테스트 — [합의 + 제안]

**[합의]** 스킬·스탯 초기화에 재화 소모나 사용 횟수 제한은 없다. 새 장비를 얻으면 같은 마녀로 **구동 근접 ↔ 화기 원거리 ↔ 자동화 소환** 빌드를 여러 번 자유롭게 시험할 수 있어야 한다.

**[제안]** 스킬과 스탯을 **따로 초기화**할 수 있게 한다. 하나의 장비 옵션을 실험할 때 스킬트리까지 전부 다시 찍어야 하는 불편을 줄인다. 필요하다면 양쪽을 동시에 돌리는 '전체 초기화' 메뉴도 추가할 수 있다. 이는 UX 권고이지 아직 확정된 입력·메뉴 사양은 아니다.

**[미결·특히 중요]** **전투 중에도 즉시 초기화하고 스탯·스킬을 재배치하게 할지**는 별도로 논의해야 한다. 자유·무료 초기화와 전투 중 즉시 변경 허용은 다른 문제다. 보스 전투 도중 빌드를 실시간으로 교체해 제약을 없애는 전략이 의도인지 확인해야 한다. **[제안] 전투 외에는 언제나 즉시 무료 초기화**할 수 있도록 먼저 시험한다.

시험 케이스와 통과 기준은 [06 · 시험판 명세](06_vertical_slice.md)에만 작성한다.

## 5. 미결 사항

- **우선 결정:** §2.3 **위력·스킬 레벨이 출혈에 영향을 주는 방식**.
- **피해 계산:** 명중·치명 계수, 적 등급별 출혈 비율, 출혈 총량/틱 기준·보스 보정, 중첩 가중치·상한에서의 재적용/교체, 소환체의 스탯 상속.
- **성장 체계:** 스탯/스킬 포인트 관계(별도 풀 [제안]), 지급량, 체력·마나 회복, 기본 스탯과 장비/패시브의 중첩 효율.
- **초기화 UI:** 초기화 자체는 무료·무제한 [합의]. 스탯/스킬 별도 초기화, 전투 중 사용 가능 여부, 프리셋·장착 요구 스탯 처리 등은 [미결].

> **현행 권위:** 스탯·명중·치명·출혈 계산은 이 문서, 스킬 사용·마나 토글은 [02](02_combat.md), 개별 기술 특화는 [03](03_skills.md), 검증은 [06](06_vertical_slice.md). 변경 이력은 [결정 로그](decisions.md)로 확인한다.
