# Godot 전투 필드 실행 안내

2026-10-27 갱신 · **Godot 4.6 + GDScript** 전투 필드다. 사용자가 승인한 **v21 달리기 + v20 오른손잡이 동작 6종**을 본 게임 기본값으로 연결했다. 일상복 기본 외형과 1.75× 카메라를 사용하며, 휘두르기/찌르기 50:50 선택과 기존 전투 규칙을 유지한다. 검사는 **4.6.2 stable / Compatibility / Windows**의 실제 `game/`에서 수행했다. 이 선택은 현재 시험판 동작에 대한 승인이다.

[선택한 달리기 비교](../reports/run_arm_v21/review.html), [현재 원본·게임 연결 안내](../assets/characters/player/3d/source/middle_school_v1/run_arm_v21/GAME_INTEGRATION.md), [본 게임 적용 기록](../reports/run_arm_v21/integration/delivery_manifest.json)을 참고한다.

## 실행

Godot 4.6에서 [game/project.godot](../game/project.godot)을 열고 F6가 아닌 **F5(프로젝트 실행)**를 누른다. Windows에서는 저장소 루트에서 다음 명령으로도 실행할 수 있다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/run_godot.ps1
# 자동 탐색되지 않는 경우
powershell -ExecutionPolicy Bypass -File tools/run_godot.ps1 -GodotPath 'C:\path\Godot_console.exe'
```

실행기는 PATH 또는 사용자 Downloads의 Godot 4 실행 파일을 찾고 자산 임포트 후 실행한다. 엔진이나 추가 패키지를 다운로드하지 않는다. 플레이 가능한 소스 프로젝트이며 독립 실행 파일 배포본은 아직 만들지 않았다.

## 구현 경계와 시험 선택

입력·자원 원본은 [02](02_combat.md), 기술 원본은 [03](03_skills.md), 피해 규칙 원본은 [07](07_attributes.md), HUD 원본은 [10](10_ui.md)다. 아래 내용은 이 시안의 임시 구현 선택이며 기획 승인으로 바꾸지 않는다.

- [trial.json](../game/data/trial.json)은 `test_values_not_approved_balance`로 비용·재사용·피해·적 체력·유지비·회복·소환 수명 등을 보관한다. 산탄은 부채꼴 즉시 공간 판정이며 탄도 시뮬레이션은 아니다.
- 비용/쿨다운/공구의 단일 시전 검사는 Python 참조 구현과 같은 정책이다. Godot 이동 계층이 사거리 부족 결과를 받아 대상을 기억하고 접근한 뒤 다시 검사한다. 좌클릭 적 공격 성공은 이전 클릭 이동을 대체하고, 우클릭·QWER 시전은 이동 명령을 지우지 않는다(아래 이동 중 시전). Shift 바닥 조준은 방향을 선택하며 실제 피해 사거리를 제한한다. 설치는 필드 경계·거리·캐릭터/소환체와의 겹침을 검사한다.
- 기술마다 `targeting: direction` 표시가 있으면 공간 판정에서 사거리 부족을 내지 않아 접근 후 시전을 건너뛴다. 현재 산탄만 방향 지정형이며, 기본 공격·포탑·표적 중계·태엽인형은 기존대로 접근한다. 이 표시는 Godot 시험 설정이며 Python 규칙 계약은 바뀌지 않는다.
- 접근 중에는 적의 현재 위치를 추적하고 지면 좌표는 고정한다. 시작 시 자원은 소비하지 않으며 실제 시전 때의 자원으로 기술/좌클릭 대체 여부와 사거리를 다시 판단한다. 현재 직선 이동이 1.5초간 진행하지 못하면 취소한다. 이 시간과 취소·대기 세부 정책은 [02 §1.1](02_combat.md)의 구현 시험값이다.
- 물리 프레임마다 쿨다운/유지비 → 0마나 해제 → 외부 자연회복(시험값 2 MP/s) 순으로 처리한다. 회복으로 공구가 자동 재활성화되지는 않는다. GDScript는 부동소수점과 1e-8 소진 허용오차를 사용하며 소수 유지비 고갈도 검사했다.
- 기본 태엽인형은 **소환 시점부터** 시험 수명이 진행되고 마지막에 범위 자폭한다. 포탑은 위치를 유지하며 근처 적에게 사격한다. 이동형은 화면 밖이면 플레이어에게 돌아온다. 소환체 몸막·복잡한 장애물 길찾기는 아직 없다(소환체 체력과 피격은 아래 항목).
- 기본 공격은 재사용 대기 없이 **공격 동작 시간**으로 반복 간격이 정해진다. [04 §4.1](04_items.md)의 제안 곡선 `최소 + (기본 − 최소) / (1 + k × 공속 점수)`에 시험값(기본 0.6초, 볼트 커터 0.95초, 최소 0.25초, k 0.04, 시작 점수 0)을 넣었다. 동작 중에는 이동하지 않고, 그 사이 마지막 입력은 동작이 끝난 뒤 실행한다. 산탄 등 다른 기술의 시전 시간은 공격 속도와 무관하고, 별도의 시전 속도 점수(F8)로 같은 곡선을 따라 줄어든다. 최저 시간은 기술별 기본값의 40%, k 0.04다.
- **발동 시점:** 기본 공격과 정지형 기술은 입력 때 Python 규칙과 같은 검사를 미리 돌려 동작만 시작하고, 동작의 `release_ratio`(기본 공격·산탄 0.5, 태엽인형·포탑 0.85) 지점에서 규칙 `press`를 실제로 호출해 비용·쿨다운·효과를 적용한다. 따라서 Python 규칙 계약은 그대로이고 호출 시점만 늦다. 발동 때 표적이 사거리 밖이면 문구 없이 빗나가고(타격음·효과 없음), 사라졌으면 취소하며, 산탄은 마지막 위치 쪽으로 쏜다. v12는 [캐릭터 표시 제어기](../game/scripts/player_visual.gd)가 공격·시전 클립의 타격/발동 지점을 이 전투 시계에 맞춘다. 공격 속도·시전 속도가 달라져도 피해·자원 판정은 기존 전투 코드가 담당한다. 동작 중 입력은 동작이 끝난 뒤 실행한다.
- **이동 중 시전:** [02 §1](02_combat.md)에 따라 바닥 좌클릭 유지는 기술 입력과 별도로 기억되므로 Q·우클릭 등을 누르고 떼도 끊기지 않는다. `trial.json`의 `while_moving: true`(볼트 커터·표적 중계기)는 걸음을 멈추지 않는다. 나머지는 시전 시간 동안 멈춘 뒤 유지 중인 커서 이동이나 마지막 클릭 목적지로 다시 걷는다. 이 동작 동안 들어온 입력은 기본 공격 동작과 같이 끝난 뒤 실행한다. 접근 후 시전은 접근 중 이동 유지보다 우선한다. 시전 시간은 `cast_seconds` 기본값(산탄 0.25·태엽인형 0.6·포탑 0.6초)에 시전 속도 점수를 적용한 값이며, HUD 슬롯에 현재 값이 표시된다. 분류와 시간은 시험값이다.
- **카메라 각도는 고정**이다(사용자 요청). 직교 투영에 좌우 45°·내려다보는 각 30°를 써서 바닥 격자가 2:1 마름모로 보이는 2D 쿼터뷰 형태다. 마녀를 따라갈 때 평행 이동만 하고 지연·회전 없이 마녀를 화면 중앙보다 약간 아래에 둔다. v12 연결에서는 사용자가 선택한 **1.75배**를 실제 게임에 설정했다(직교 크기 `20 / 1.75`, 1280×800 기준). 2026-10-28 사용자가 마녀 키를 **1.5m**로 정했다. 원래 모형은 머리카락 끝까지 1.711m이므로 `player_visual.gd`가 모형 전체(지팡이 포함)를 1.5/1.711배로 줄이고, 달리기 주기 거리도 같은 배율(3.2428→약 2.843m)로 줄여 발이 미끄러지지 않게 한다. 카메라 직교 크기도 같은 배율(약 10.02)로 줄여 화면 속 마녀 크기는 그대로 두었으므로, 같은 화면에 보이는 바닥 범위는 약 12% 좁아졌다. 충돌 반경·사거리·이동 속도 같은 전투 수치는 바꾸지 않았다. [표시 크기 사양](../assets/characters/player/3d/config/display_review.spec.json)을 따르며 이 설정의 실제 게임 화면을 캡처해 확인했다. 기존 약 111px는 중립 아트 기준 측정값이며 새 게임 동작의 픽셀 높이를 다시 측정한 값은 아니다.
- 적 선택은 이동 충돌 캡슐과 별도인 **모델 전체 크기의 선택 원기둥**(Area3D)으로 판정한다. 적이 어느 방향을 보더라도 머리·팔·발을 눌러 선택할 수 있다.
- 플레이어와 적은 충돌체가 있고 바깥 벽을 통과하지 않는다. 내부 장애물이 없는 평면 필드라 클릭 이동은 직선 이동이다. 적은 일반/무거운 도형 2종이며 추격·공격 예고·피격·처치가 가능하다.
- 기본 피해는 **고정 시험값**이고, 그 위에 명중·치명 굴림과 적 등급이 붙는다(아래 B단계 항목). 성장 스탯·출혈은 아직 없다. 표적 중계기의 스킬 레벨 보너스·전기톱·공통 공구 공격 2종·스킬 성장/특화도 후속 범위다.
- **고정 시험 맵 `alley_v2`([05 §3.0](05_content.md) 1단계, [08 §6.1](08_scenario_draft.md) 배치):** 일반 실행은 이 맵에서 시작한다. v2는 v1을 **1.2배**로 키웠다. 골목 A 중간의 **실제 계단 6단**(단당 0.2m)을 올라가면 B·C는 1.2m 높이에 있다. 바깥 경계는 **필지(lot)를 이어 붙인 가장자리**다(`edges`). 필지는 세 종류다. **집**은 골목 쪽 담장(바닥 위 1.5m, 계단 옆에서는 계단을 따라 층져 내려감)에 **닫힌 철 대문**(1.2m 외문 또는 2.4m 쌍문, 가끔 작은 차양)을 달고, 마당만큼 물러나 1~2층 집이 선다. **가게**는 담장 없이 골목에 바로 붙는다. 1층은 셔터나 유리 진열창과 출입문이고 그 위에 간판(세탁소·슈퍼·철물점 등, B 막다른 골목 끝은 바랜 **문방구**)과 가끔 차양이 있으며 1~3층이다. **민담장**은 공터 둘레와 모서리에 쓰고, 가끔 마당 나무가 보인다. 담장 기둥은 필지 끝과 대문 기둥에만 선다. 건물 조각은 층 블록·층 띠·창틀·출입문·옥상 난간·물탱크·실외기(2층 이상 창 아래 받침대에 걸거나 A5 기록의 `counts`에 명중·빗나감·치명·경직·막기 합계가 남는다. 2026-10-26부터는 `by_source`(지팡이 `staff`·`bolt_cutter`·`grinder`·`shotgun`·`automaton`·`automaton_blast`·`turret`별 명중·빗나감·치명·실제 피해)와 `by_grade`(등급별 처치, 마녀에게 준 타격 수·피해·경직, 막힌 횟수)도 함께 남는다. 설정에는 태엽인형·포탑 레벨도 기록된다. 2026-10-27부터 모든 A5 기록에 `build`가 붙는다. `git_commit`(실행한 저장소의 짧은 커밋 해시, 저장소 밖에서는 `unknown`), `trial_md5`(`trial.json` 내용), `scripts_md5`(`game/scripts/*.gd` 전체 내용)다. 커밋하지 않은 수정도 해시로 구분되므로, 같은 커밋이라도 해시가 다르면 다른 규칙으로 플레이한 기록이다. 그 이전 기록에는 이 항목이 없다. 경직은 실제 피해가 기준 이상이고 마녀가 살아 있을 때만 센다. 자동 검사는 굴림 결과를 고정하고(`force_rolls`), 굴림 자체는 [등급·명중 검사](../game/tests/grades_hits.gd)가 따로 확인한다.
- **물약([04 §8.2](04_items.md)):** 회복은 시간에 걸쳐 차오르고(일반 5초, 완전 회복 3초) 쿨타임은 종류별 묶음(체력·마나·이동 속도)이다. 회복 물약과 완전 회복은 체력·마나 쿨타임을 둘 다 돌린다. 쿨타임 6초, 이동 속도 물약은 +20% 20초·쿨타임 60초. 0개가 되면 빈칸으로 남고 자동 보충하지 않는다. 체력·마나 게이지에는 앞으로 차오를 양이 옅은 층으로 보이고, 이동 속도 버프는 왼쪽 위에 남은 시간과 함께 표시된다. 등급별 회복량(체력 25·45·70, 마나 20·35·55, 회복 15/12·30/22·45/35)은 04의 미결을 채운 시험값이다. **방어·상태이상 감소 물약은 방어 공식과 플레이어 상태이상이 아직 없어 넣지 않았다.** A5 기록에는 물약별 사용 횟수가 `metrics.potions`로 남는다. 재시작하면 등록과 개수가 처음으로 돌아간다.
- **피격 경직과 방패(A8 검증용):** 막지 못한 피격 중 최대 체력의 10% 이상(`hit_stun_min_ratio`)인 것만 0.4초 경직(타격 회복 점수로 최저 0.15초까지 단축). 진행 중 준비 동작·접근·클릭 이동·대기 입력을 취소하며, 자원은 발동 시점에 쓰므로 아무것도 소비되지 않는다. 경직 중에는 마녀가 움직이지 않으며 캐릭터 표시 제어기가 회복 시간에 맞춰 피격 클립을 재생한다. 방패 전개는 이동하면서 쓰는 즉시 기술(12 MP, 재사용 10초, 지속 6초)이며, 지속 중 강철색 고리가 보인다. 막기 확률 = 20% + 3%×(레벨−1) + 0.4%×기교, 상한 75%다. 막으면 피해·경직 없이 금속음과 강철색 파동만 나고 하던 행동이 계속된다. 기교·방패 레벨은 아직 성장 시스템이 없어 F10·F11 시험값으로만 바뀐다. 모든 수치는 시험값이다.
- **공구 2종(A4 검증용):** 볼트 커터(Q)와 그라인더(R, F9로 등록)는 같은 토글 규칙([02 §3](02_combat.md))을 따르며 서로 교체된다. 액티브 6슬롯이 모두 차 있어 R을 F9로 방패·그라인더·표적 중계 중에서 바꿔 넣는다(숨은 7번째 슬롯 없음). 공구별 값은 `trial.json` 스킬 항목에 있다. 볼트 커터: 동작 0.95초·피해 34·둔화 2초(이동 속도 ×0.45). 그라인더: 동작 0.4초·피해 12·방깎 4초. 07에 방어력 공식이 아직 없어서 **방깎은 "직접 피해 ×1.25"로 근사**했다. 산탄·소환체 공격 등 모든 직접 피해에 적용된다. 디버프는 적마다 공구별 타이머로 따로 유지되고, 공구를 바꿔도 지워지지 않는다. 같은 디버프를 다시 걸면 시간이 처음으로 돌아간다(반복 중첩은 02 미결). 모든 값은 시험값이다.
- **전기톱·출혈 시험 구현 (2026-10-28, [07 §2.2~2.3](07_attributes.md)):** 사용자 요청으로 출혈 검증용 세 번째 공구를 넣었다. 수치는 모두 `trial.json`의 시험값이다.
  - **전기톱:** R 슬롯 공구 토글(F9로 등록, 유지 5 MP/s). 기본 공격이 동작 0.5초·피해 14의 작은 전방 부채꼴(사거리 2.6m, 정면 ±60°) 절삭으로 바뀐다. 부채꼴 안의 적마다 따로 명중·치명을 굴리고, 맞은 적에게 출혈을 하나 건다.
  - **출혈 1중첩:** 총 피해 = 적 최대 체력 × 등급 비율(일반 24%·강화 18%·정예 12%·보스 4%) × 중첩 가중치. 4초 동안 0.5초마다 8번 나눠 들어간다. 명중 판정·치명타·방깎·경직이 없고, 위력도 적용하지 않는다.
  - **중첩:** 적마다 5중첩까지. 가중치는 이미 걸린 중첩 수에 따라 1·0.8·0.6·0.45·0.35이고 걸리는 순간 정해진다(만료돼도 남은 중첩의 가중치는 다시 매기지 않는다). 중첩마다 타이머가 따로 돌고, 새 출혈이 기존 타이머를 갱신하지 않는다. 6번째 출혈은 가장 오래된 중첩을 교체한다.
  - **레벨 성장 비교:** 전기톱 레벨(Shift+F9, 1·4·5·10)이 무엇을 올릴지 Ctrl+F9로 바꿔 본다. **A안**은 레벨당 피해 비율 +6%(Lv10 ×1.54). **B안**(사용자 선택, 기본값)은 모든 레벨에서 지속시간 +0.2초(초당 피해는 같아 총량이 늘어남, Lv10 5.8초)를 올리고, 뒤 중첩 가중치는 5의 배수 레벨마다 1까지 남은 차이의 20%씩만 1에 가깝게 올린다(마지막 중첩 0.35 → Lv5 0.48 → Lv10 0.61). Lv4와 Lv5를 비교하면 가중치 단계 상승을 볼 수 있다.
  - **기록:** A5 기록의 출처별 피해에 `bleed`가 따로 쌓이고(명중·빗나감 수에는 넣지 않음), 건 출혈 수·틱 수, 전기톱 레벨, 성장 안이 함께 저장된다. 적 머리 위에는 「출혈 N」으로 중첩 수가 보인다.
  - **참고 계산:** 0.5초마다 계속 베면 5중첩이 유지되고 교체가 반복되어 가중치가 0.35로 수렴한다. 이때 보스는 최대 체력의 4% × 0.35 × 5 / 4초 ≈ 초당 1.75%를 출혈로 잃는다(시험 보스 1,440 기준 초당 약 25). 첫 플레이에서 사용자는 계속 베기가 쉽지 않아 B안 5중첩도 유지가 어렵다고 보고, 보스 비율 4%를 유지했다([06](06_vertical_slice.md)).
- 적 머리 위 HP/둔화, 상단 공구 상태·고갈 경고, 플레이어 머리 위 실패 문구, 하단 6슬롯의 쿨다운/마나 부족 및 세로 HP/MP 게이지를 표시한다. 피해 숫자와 음성 안내는 없다.
- **플레이어 표시(v21):** [player_visual.gd](../game/scripts/player_visual.gd)는 `run_arm_v21/` 파트 세트와 동작별 지팡이 위치 데이터를 사용한다. 달리기는 `combat_run_rh_v21`, 대기·휘두르기·찌르기·캐스팅·경직·쓰러짐은 오른손 위 그립으로 교정한 v20 동작이다. 양손 달리기와 오른손 한 손 캐스팅, 동일 성능의 50:50 공격 두 종류, HP 0 쓰러짐과 마지막 자세 유지에 대응한다. 현재 선택 동작은 7개이며 이전 v20 달리기 1개는 비교용이다. 107본·최대 8웨이트, 기존 이동 거리/발동 시간·전투 RNG를 유지한다. [현재 사양과 다음 의상 안내](../assets/characters/player/3d/source/middle_school_v1/run_arm_v21/GAME_INTEGRATION.md)를 따른다. 변신복 기본 적용·트윈테일·독립 2D 레이어·실시간 천 물리는 별도다.
- 효과음 1개는 로컬 Agent Audio로 생성하고 앞 타격을 잘라 사용했다. 이벤트별 피치와 음량을 적용하며 M으로 끌 수 있다. [음원 검사](../reports/combat_audio_report.json)는 길이·피크·무클리핑 확인이며 에이전트가 청취 평가한 결과는 아니다.

## A5 마나 고갈 시험

[06 A5](06_vertical_slice.md)의 "아무 기술도 못 쓰는 구간"을 직접 플레이하며 재기 위한 시험 모드다. 측정 기능이며 마나 규칙이나 수치를 바꾸지 않는다.

1. 게임을 실행하고 **F5**로 연속 교전을 켠다. 적이 쓰러지면 2.5초 뒤 마녀에게서 먼 필드 가장자리에서 같은 종류가 다시 나와 적 6마리를 유지한다. 필드 정리 완료 화면은 나오지 않는다.
2. 평소처럼 **Q 볼트 커터를 켠 채** 산탄·태엽인형·포탑을 섞어 싸운다. 회복량을 비교하려면 **F7**로 1·2·4 MP/s를 바꾸고 각각 2~3분씩 싸운다. 기본값 2는 첫 A5 시험 뒤 사용자가 고른 약간 모자란 기준이다([02 §3.1](02_combat.md)).
3. 왼쪽 패널에서 실시간 값을 본다. **기술 공백**은 공구가 꺼져 있고 마나를 쓰는 등록 기술을 하나도 쓸 수 없는, 즉 기본 공격만 남은 교전 시간이다. 총 시간·교전 대비 비율·횟수·최장 시간, 지금 공백인지, 마나 부족 실패·좌클릭 대체 공격·공구 자동 해제 횟수를 표시한다. 공구는 비용 0이라 마나가 조금만 있어도 켤 수 있지만 곧 다시 해제되므로 공백 판정에서 제외했다.
4. 기록은 `reports/playtest/a5_mana_<시각>_<이유>.json`에 저장된다. **F6**, 사망, 일시정지·사망 후 Enter 재시작, F5 종료, 창 닫기 때 저장한다. F7·F4·F1(및 F8~F12)로 설정을 바꾸면 **바꾸기 전 설정으로** 그때까지의 기록을 저장하고 새로 잰다. 한 기록에 두 설정이 섞이지 않게 하려는 것이다. 2026-10-26 이전의 `settings_changed` 기록에는 바뀐 뒤 값이 적혀 있다([06 기록 주의](06_vertical_slice.md)). 기록에는 회복량·스킬 비용·재사용 대기·유지비·등록 슬롯, 스킬별 비용 부족 시간, 시전 횟수가 들어간다. F2/F3 사용 횟수는 `debug_mana_edits`로 남는다. F8도 설정 변경으로 새로 재며, 기록에 시전 속도 점수와 기술별 실제 시전 시간이 들어간다.
5. 숫자와 함께 **답답했던 순간과 그때 하려던 행동**을 메모해 둔다. 기록 파일은 체감을 대신하지 않는다.

HP 회복과 물약이 없어서 오래 싸우면 쓰러질 수 있다. 사망하면 그 시점까지의 기록이 저장된다. 시험 설정의 원본은 [trial.json](../game/data/trial.json)의 `mana_regen_steps`, `a5_respawn_seconds`다.
