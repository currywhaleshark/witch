# Godot 전투 필드 실행 안내

2026-10-25 · Godot 권고 뒤 사용자의 “푸시하고 시작해보자” 요청을 받아 **Godot 4.6 + GDScript**로 첫 도형 전투 시안을 구현했다. 설치된 **4.6.2 stable / Compatibility / Windows**에서 검사했다. 기존 인계·Python 작업은 `9b711cd`까지 `origin/main`에 푸시 완료했다. 이번 Godot 구현의 작업 상태는 Git 상태를 별도로 확인한다.

## 실행

Godot 4.6에서 [game/project.godot](../game/project.godot)을 열고 F6가 아닌 **F5(프로젝트 실행)**를 누른다. Windows에서는 저장소 루트에서 다음 명령으로도 실행할 수 있다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/run_godot.ps1
# 자동 탐색되지 않는 경우
powershell -ExecutionPolicy Bypass -File tools/run_godot.ps1 -GodotPath 'C:\path\Godot_console.exe'
```

실행기는 PATH 또는 사용자 Downloads의 Godot 4 실행 파일을 찾고 자산 임포트 후 실행한다. 엔진이나 추가 패키지를 다운로드하지 않는다. 플레이 가능한 소스 프로젝트이며 독립 실행 파일 배포본은 아직 만들지 않았다.

## 구현 경계와 시험 선택

입력·자원 원본은 [02](02_combat.md), 기술 원본은 [03](03_skills.md), 피해 규칙 원본은 [07](07_attributes.md), HUD 원본은 [10](10_ui.md)다. 아래 내용은 이 시안의 임시 구현 선택이며 기획 승인으로 바꾸지 않는다.

- [trial.json](../game/data/trial.json)은 `test_values_not_approved_balance`로 비용·재사용·피해·적 체력·유지비·회복·소환 수명 등을 보관한다. 산탄은 부채꼴 즉시 공간 판정이며 탄도 시뮬레이션은 아니다.
- 비용/쿨다운/공구의 단일 시전 검사는 Python 참조 구현과 같은 정책이다. Godot 이동 계층이 사거리 부족 결과를 받아 대상을 기억하고 접근한 뒤 다시 검사한다. 좌클릭 적 공격 성공은 이전 클릭 이동을 대체하고, 우클릭·QWER 시전은 이동 명령을 지우지 않는다(아래 이동 중 시전). Shift 바닥 조준은 방향을 선택하며 실제 피해 사거리를 제한한다. 설치는 필드 경계·거리·캐릭터/소환체와의 겹침을 검사한다.
- 기술마다 `targeting: direction` 표시가 있으면 공간 판정에서 사거리 부족을 내지 않아 접근 후 시전을 건너뛴다. 현재 산탄만 방향 지정형이며, 기본 공격·포탑·표적 중계·태엽인형은 기존대로 접근한다. 이 표시는 Godot 시험 설정이며 Python 규칙 계약은 바뀌지 않는다.
- 접근 중에는 적의 현재 위치를 추적하고 지면 좌표는 고정한다. 시작 시 자원은 소비하지 않으며 실제 시전 때의 자원으로 기술/좌클릭 대체 여부와 사거리를 다시 판단한다. 현재 직선 이동이 1.5초간 진행하지 못하면 취소한다. 이 시간과 취소·대기 세부 정책은 [02 §1.1](02_combat.md)의 구현 시험값이다.
- 물리 프레임마다 쿨다운/유지비 → 0마나 해제 → 외부 자연회복(시험값 2 MP/s) 순으로 처리한다. 회복으로 공구가 자동 재활성화되지는 않는다. GDScript는 부동소수점과 1e-8 소진 허용오차를 사용하며 소수 유지비 고갈도 검사했다.
- 기본 태엽인형은 **소환 시점부터** 시험 수명이 진행되고 마지막에 범위 자폭한다. 포탑은 위치를 유지하며 근처 적에게 사격한다. 이동형은 화면 밖이면 플레이어에게 돌아온다. 소환체의 체력·몸막·피격·복잡한 장애물 길찾기는 아직 없다.
- 기본 공격은 재사용 대기 없이 **공격 동작 시간**으로 반복 간격이 정해진다. [04 §4.1](04_items.md)의 제안 곡선 `최소 + (기본 − 최소) / (1 + k × 공속 점수)`에 시험값(기본 0.6초, 볼트 커터 0.95초, 최소 0.25초, k 0.04, 시작 점수 0)을 넣었다. 동작 중에는 이동하지 않고, 그 사이 마지막 입력은 동작이 끝난 뒤 실행한다. 산탄 등 다른 기술의 시전 시간은 공격 속도와 무관하고, 별도의 시전 속도 점수(F8)로 같은 곡선을 따라 줄어든다. 최저 시간은 기술별 기본값의 40%, k 0.04다.
- **발동 시점:** 기본 공격과 정지형 기술은 입력 때 Python 규칙과 같은 검사를 미리 돌려 동작만 시작하고, 동작의 `release_ratio`(기본 공격·산탄 0.5, 태엽인형·포탑 0.85) 지점에서 규칙 `press`를 실제로 호출해 비용·쿨다운·효과를 적용한다. 따라서 Python 규칙 계약은 그대로이고 호출 시점만 늦다. 발동 때 표적이 사거리 밖이면 문구 없이 빗나가고(타격음·효과 없음), 사라졌으면 취소하며, 산탄은 마지막 위치 쪽으로 쏜다. 준비 동작 중에는 마녀가 몸을 뒤로 젖힌다(임시 표시). 동작은 끊기지 않고, 그 사이 입력은 동작이 끝난 뒤 실행한다.
- **이동 중 시전:** [02 §1](02_combat.md)에 따라 바닥 좌클릭 유지는 기술 입력과 별도로 기억되므로 Q·우클릭 등을 누르고 떼도 끊기지 않는다. `trial.json`의 `while_moving: true`(볼트 커터·표적 중계기)는 걸음을 멈추지 않는다. 나머지는 시전 시간 동안 멈춘 뒤 유지 중인 커서 이동이나 마지막 클릭 목적지로 다시 걷는다. 이 동작 동안 들어온 입력은 기본 공격 동작과 같이 끝난 뒤 실행한다. 접근 후 시전은 접근 중 이동 유지보다 우선한다. 시전 시간은 `cast_seconds` 기본값(산탄 0.25·태엽인형 0.6·포탑 0.6초)에 시전 속도 점수를 적용한 값이며, HUD 슬롯에 현재 값이 표시된다. 분류와 시간은 시험값이다.
- **카메라 각도는 고정**이다(사용자 요청). 직교 투영에 좌우 45°·내려다보는 각 30°를 써서 바닥 격자가 2:1 마름모로 보이는 2D 쿼터뷰 형태다. 마녀를 따라갈 때 평행 이동만 하고 지연·회전 없이 마녀를 화면 중앙보다 약간 아래에 둔다. 확대 배율(직교 크기 20)은 시험값이다.
- 적 선택은 이동 충돌 캡슐과 별도인 **모델 전체 크기의 선택 원기둥**(Area3D)으로 판정한다. 적이 어느 방향을 보더라도 머리·팔·발을 눌러 선택할 수 있다.
- 플레이어와 적은 충돌체가 있고 바깥 벽을 통과하지 않는다. 내부 장애물이 없는 평면 필드라 클릭 이동은 직선 이동이다. 적은 일반/무거운 도형 2종이며 추격·공격 예고·피격·처치가 가능하다.
- 피해는 **고정 시험값**이다. [07](07_attributes.md)의 성장 스탯·명중 굴림·치명·출혈 전체를 구현한 상태가 아니다. 표적 중계기의 스킬 레벨 보너스·전기톱·공통 공구 공격 2종·스킬 성장/특화도 후속 범위다.
- **물약([04 §8.2](04_items.md)):** 회복은 시간에 걸쳐 차오르고(일반 5초, 완전 회복 3초) 쿨타임은 종류별 묶음(체력·마나·이동 속도)이다. 회복 물약과 완전 회복은 체력·마나 쿨타임을 둘 다 돌린다. 쿨타임 6초, 이동 속도 물약은 +20% 20초·쿨타임 60초. 0개가 되면 빈칸으로 남고 자동 보충하지 않는다. 체력·마나 게이지에는 앞으로 차오를 양이 옅은 층으로 보이고, 이동 속도 버프는 왼쪽 위에 남은 시간과 함께 표시된다. 등급별 회복량(체력 25·45·70, 마나 20·35·55, 회복 15/12·30/22·45/35)은 04의 미결을 채운 시험값이다. **방어·상태이상 감소 물약은 방어 공식과 플레이어 상태이상이 아직 없어 넣지 않았다.** A5 기록에는 물약별 사용 횟수가 `metrics.potions`로 남는다. 재시작하면 등록과 개수가 처음으로 돌아간다.
- **피격 경직과 방패(A8 검증용):** 막지 못한 피격 중 최대 체력의 10% 이상(`hit_stun_min_ratio`)인 것만 0.4초 경직(타격 회복 점수로 최저 0.15초까지 단축). 진행 중 준비 동작·접근·클릭 이동·대기 입력을 취소하며, 자원은 발동 시점에 쓰므로 아무것도 소비되지 않는다. 경직 중에는 마녀가 흔들리고 움직이지 않는다. 방패 전개는 이동하면서 쓰는 즉시 기술(12 MP, 재사용 10초, 지속 6초)이며, 지속 중 강철색 고리가 보인다. 막기 확률 = 20% + 3%×(레벨−1) + 0.4%×기교, 상한 75%다. 막으면 피해·경직 없이 금속음과 강철색 파동만 나고 하던 행동이 계속된다. 기교·방패 레벨은 아직 성장 시스템이 없어 F10·F11 시험값으로만 바뀐다. 모든 수치는 시험값이다.
- **공구 2종(A4 검증용):** 볼트 커터(Q)와 그라인더(R, F9로 등록)는 같은 토글 규칙([02 §3](02_combat.md))을 따르며 서로 교체된다. 액티브 6슬롯이 모두 차 있어 R을 F9로 방패·그라인더·표적 중계 중에서 바꿔 넣는다(숨은 7번째 슬롯 없음). 공구별 값은 `trial.json` 스킬 항목에 있다. 볼트 커터: 동작 0.95초·피해 34·둔화 2초(이동 속도 ×0.45). 그라인더: 동작 0.4초·피해 12·방깎 4초. 07에 방어력 공식이 아직 없어서 **방깎은 "직접 피해 ×1.25"로 근사**했다. 산탄·소환체 공격 등 모든 직접 피해에 적용된다. 디버프는 적마다 공구별 타이머로 따로 유지되고, 공구를 바꿔도 지워지지 않는다. 같은 디버프를 다시 걸면 시간이 처음으로 돌아간다(반복 중첩은 02 미결). 모든 값은 시험값이다.
- 적 머리 위 HP/둔화, 상단 공구 상태·고갈 경고, 플레이어 머리 위 실패 문구, 하단 6슬롯의 쿨다운/마나 부족 및 세로 HP/MP 게이지를 표시한다. 피해 숫자와 음성 안내는 없다.
- 도형 캐릭터와 필드는 [shapes.gd](../game/scripts/shapes.gd)의 임시 메시다. 제공된 원화를 3D 모델로 변환한 것이 아니며 독립 PNG 파츠·리그·애니메이션은 여전히 미제작이다.
- 효과음 1개는 로컬 Agent Audio로 생성하고 앞 타격을 잘라 사용했다. 이벤트별 피치와 음량을 적용하며 M으로 끌 수 있다. [음원 검사](../reports/combat_audio_report.json)는 길이·피크·무클리핑 확인이며 에이전트가 청취 평가한 결과는 아니다.

## A5 마나 고갈 시험

[06 A5](06_vertical_slice.md)의 "아무 기술도 못 쓰는 구간"을 직접 플레이하며 재기 위한 시험 모드다. 측정 기능이며 마나 규칙이나 수치를 바꾸지 않는다.

1. 게임을 실행하고 **F5**로 연속 교전을 켠다. 적이 쓰러지면 2.5초 뒤 마녀에게서 먼 필드 가장자리에서 같은 종류가 다시 나와 적 6마리를 유지한다. 필드 정리 완료 화면은 나오지 않는다.
2. 평소처럼 **Q 볼트 커터를 켠 채** 산탄·태엽인형·포탑을 섞어 싸운다. 회복량을 비교하려면 **F7**로 1·2·4 MP/s를 바꾸고 각각 2~3분씩 싸운다. 기본값 2는 첫 A5 시험 뒤 사용자가 고른 약간 모자란 기준이다([02 §3.1](02_combat.md)).
3. 왼쪽 패널에서 실시간 값을 본다. **기술 공백**은 공구가 꺼져 있고 마나를 쓰는 등록 기술을 하나도 쓸 수 없는, 즉 기본 공격만 남은 교전 시간이다. 총 시간·교전 대비 비율·횟수·최장 시간, 지금 공백인지, 마나 부족 실패·좌클릭 대체 공격·공구 자동 해제 횟수를 표시한다. 공구는 비용 0이라 마나가 조금만 있어도 켤 수 있지만 곧 다시 해제되므로 공백 판정에서 제외했다.
4. 기록은 `reports/playtest/a5_mana_<시각>_<이유>.json`에 저장된다. **F6**, 사망, 일시정지·사망 후 Enter 재시작, F5 종료, 창 닫기 때 저장한다. F7·F4·F1로 설정을 바꾸면 그때까지의 기록을 저장하고 새로 잰다. 한 기록에 두 설정이 섞이지 않게 하려는 것이다. 기록에는 회복량·스킬 비용·재사용 대기·유지비·등록 슬롯, 스킬별 비용 부족 시간, 시전 횟수가 들어간다. F2/F3 사용 횟수는 `debug_mana_edits`로 남는다. F8도 설정 변경으로 새로 재며, 기록에 시전 속도 점수와 기술별 실제 시전 시간이 들어간다.
5. 숫자와 함께 **답답했던 순간과 그때 하려던 행동**을 메모해 둔다. 기록 파일은 체감을 대신하지 않는다.

HP 회복과 물약이 없어서 오래 싸우면 쓰러질 수 있다. 사망하면 그 시점까지의 기록이 저장된다. 시험 설정의 원본은 [trial.json](../game/data/trial.json)의 `mana_regen_steps`, `a5_respawn_seconds`다.
