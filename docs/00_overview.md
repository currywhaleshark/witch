# 마녀도시 — 개요와 문서 지도

> **현행 v0.3 · 2026-10-25.** 기획 단계의 기준 진입점. **세부 규칙은 아래에서 지정한 원본 문서 한 곳에서만 관리**한다. 확정하지 않은 내용은 [제안]/[미결]로 표시한다.

## 1. 게임의 방향

**[합의]** 이름을 부여받은 마녀가 자기 권능을 다양한 방식으로 활용하는 **디아블로 2형 쿼터뷰 핵앤슬래시 RPG**. 마녀의 외형은 마법소녀물에서 차용하되 이름이 곧 전사·궁수·마법사 같은 역할을 강제하지는 않는다.

**[합의]** 초기 클래스는 **기계장치(근접·원거리·소환 하이브리드)·유리(원거리 치중)·재봉(근거리 치중)** 3종이다. 이름과 성향의 현행 원본은 [01 · 세계관](01_world.md). **첫 시험판**에서는 기계장치 1종만 개발한다. 기계장치는 구조와 작동 원리를 이해한 기계를 구현하며, 하나의 권능을 아래 세 방식으로 운용한다.

| 활용 트리 | 전투 방식 | 구체적 기술·특화의 원본 |
|---|---|---|
| **화기** | 직접 사격·산탄·함포·광역 화력 | [03 · 스킬](03_skills.md) |
| **구동(가칭)** | 공구형 지팡이로 근접·제압·처형 | [03 · 스킬](03_skills.md) |
| **자동화** | 자율 인형·포탑·거대 전투기계 운용 | [03 · 스킬](03_skills.md) |

**핵심 원칙:** 세 트리는 어느 하나만 집중해도 일반 사냥과 보스전에 대응할 수 있고, 패시브는 **기계의 작동 원리**에 따라 트리 밖 스킬과도 연계할 수 있다. 스킬의 기본형은 미완성이 아니며 양자택일 특화는 자유로운 선택이다.

**육성·파밍:** 드롭을 통해 장비와 기술 운용이 달라진다. 일반·마법·희귀는 성능을, 고유 아이템은 기술의 동작 규칙 변화를 담당한다. 훌륭한 희귀가 특정 고유보다 나을 수 있어야 한다. 스킬·스탯은 **무료·무제한 초기화** 가능. 세부 숫자·드롭/균형은 시험판으로 조정한다.

| 첫 시험판의 재현 상황·통과 기준·단계별 범위 | **[06 · 검증 계획](06_vertical_slice.md)** | 규칙 정의·공식 복제 금지 |

**[결정 로그](decisions.md)는 현재 규칙 원본이 아니라 변경 이력**이다. 과거의 '당시 제안/미결'이 이후 승인되었을 수 있으므로, **현행 효력은 위 원본 문서의 상태 표기**로 확인한다. [v0.1 기획 스냅샷](마녀도시_핵앤슬래시_기획기록_v0.1.md)은 읽기 전용 보존 자료로 남긴다.

## 3. 최근 결정과 남은 구현 미결

**[2026-10-25 합의 완료]** 우클릭·QWER는 **키를 누르는 순간 커서 기준으로 즉시 시전**하며 추가 확정 클릭을 요구하지 않는다([02](02_combat.md)). 출혈 지속 피해에는 **위력 스탯을 적용하지 않고**, **해당 스킬 레벨 상승으로 출혈 성능이 강화**되어야 한다([07](07_attributes.md)). 상세 규칙을 여기 복제하지 않는다.

1. **입력 예외:** 대상·유효 지면이 없거나 사거리 밖인 경우의 실패/이동/피드백은 [02 §1.1](02_combat.md)에서 검토.
2. **마나 고갈 체감:** 토글 유지비·스킬 사용 비용과 부족 시 대체/실패가 겹치는 상황을 [02 §3.1](02_combat.md)과 [06](06_vertical_slice.md)에서 검증. 기존 마나 규칙은 합의 완료.
3. **출혈의 구체적 스킬 레벨 보정:** 성능 향상 자체는 합의됐으나 **피해율·지속시간·중첩 효율의 어느 항목을 얼마나 강화할지**는 [07 §2.3](07_attributes.md) 미결.
4. **밸런스와 시험 범위:** 등급별 출혈 계수, 감쇠 가중치, 치명/명중, 자원 회복, 소환체 스탯 상속, 재사용 대기 등은 [06](06_vertical_slice.md) 테스트 전 숫자로 확정하지 않는다.

## 4. 문서 유지 원칙

- **같은 규칙은 원본 한 파일만 수정한다.** 다른 파일에는 **한 줄 링크와 필요한 맥락**만 남긴다.
- **06에는 재현 입력·테스트 조건·기대 관찰 결과만** 작성한다. 규칙 확정 내용 자체를 복제하지 않는다.
- **decisions에는 무엇이 언제 왜 바뀌었는지**만 남긴다. 과거 판단은 덮어쓰지 않고 **후속 상태 변경을 새 이력으로 기록**한다.
- v0.3은 **문서 구조/원본 분리**를 의미하며, v0.2에서의 게임 메커니즘을 별도 승인 없이 바꾸는 버전이 아니다.
