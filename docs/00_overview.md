# 마녀도시 — 게임 개요

> 기획 v0.2 · 2026-10-24 · 사전 기획. 이 문서는 여러 주제별 기획서의 진입점이다.
>
> 표기: **[합의]** 현재의 설계 원칙 / **[원안/기존 구상]** 사용자가 오래전 생각한 배경 / **[제안]** 검토용 아이디어 / **[미결]** 아직 정하지 않은 사항.

## 1. 한 줄 소개

**[합의]** 이름을 부여받은 마녀가 자신의 권능을 창의적으로 해석하여 싸우는 디아블로 2형 쿼터뷰 핵앤슬래시 RPG.

마녀는 이름으로 정체성과 권능의 범위가 정해진다. 이름은 직업 선택에 해당하며, 한 이름 안의 스킬트리는 같은 권능의 **활용 방식**을 구분한다. 마녀의 외형은 마법소녀물의 이미지를 차용한다.

## 2. 지켜야 할 게임 디자인 원칙

1. **[합의] 이름은 권능의 범위를 정할 뿐, 전투 역할을 미리 지정하지 않는다.** 전사·궁수·마법사라는 전통 직업을 기계적으로 재현하지 않는다.
2. **[합의] 육성과 파밍은 분리할 수 없다.** 장비 획득 → 빌드의 강화·변화 → 유리한 사냥 지역·목표 선택 → 다시 파밍하는 순환을 만든다.
3. **[합의] 과도한 반복 앵벌은 지양하지만 희귀 드롭을 발견하는 기대감은 살린다.**
4. **[합의] 각 트리의 주특기는 달라도 단일 트리 집중 육성만으로 일반 사냥과 보스전을 수행할 수 있어야 한다.** 혼합 빌드는 필수가 아닌 선택이다.
5. **[합의] 주력 공격·소환 기술에는 대조적인 양자택일 특화 노드를 둘 수 있다.** 일반 강화/특화와 고유 아이템의 근본적 규칙 변경을 구분한다.
6. **[합의] 6개의 액티브 입력(좌클릭·우클릭·Q·W·E·R)** 이 기본이다. **클릭 이동**이며 빈 바닥 좌클릭=이동, 적 좌클릭=등록 스킬 시전. **기본 공격은 처음부터 좌클릭에 장착된 마력 소모 없는 스킬**로, 성장 후 교체 가능하다. **좌클릭 기술의 마나 부족은 기본 공격으로 대체(등록 유지)**하고, 우클릭·QWER의 마나 부족은 발동 실패. 패시브/강화 노드는 슬롯을 차지하지 않는다.
7. **[합의] 핵심 매개체 아이템을 장착하며 아이템에 따라 눈에 보이는 지팡이/대표 무장 외형이 바뀐다.** 스킬 투자만으로 모든 아이템 외형 변화가 대체되지는 않는다.

## 3. 첫 설계 대상: 기계장치의 마녀

**[원안/기존 구상]** 구조와 작동 원리를 이해하는 기계만 즉석에서 구현할 수 있다. 단두대와 같은 단순 장치에서 화승총, 복잡한 함포로 이해가 확장되는 이미지가 있었다.

| 활용 트리 | 핵심 | 대표 체험 |
|---|---|---|
| 화기 | 원거리 직접 화력 · 광역 특화 | 사격·산탄·기관포·포격 |
| 구동(가칭) | 지팡이를 공구형 근접 무장으로 전개 · 방어 · 제압 · 처형 | 볼트커터·그라인더·전기톱·외골격 |
| 자동화 | 독립적으로 작동하는 장치를 소환 · 통제 | 태엽인형(자폭/지속)·기계 수렵견·포탑·**거대 자동인형(가칭)** |

**[합의]** 디아블로 2의 드루이드(원소·변신·소환)와 비슷한 3갈래 구성으로 느껴지지만, 세 트리는 어디까지나 하나의 '기계 구현' 권능을 사용하는 서로 다른 방법이다.

**[합의]** 구동의 공구형 지팡이 변형은 **토글 유지 + 지속 마나 소모**. **같은 변형을 다시 사용하면 해제**, 다른 공구 변형에 성공하면 **기존 공구를 교체**, 마나가 0이면 **자동 해제**된다. **다른 모든 스킬(처형·화기·자동화·생존 등)을 사용해도 변형 상태는 유지**된다(마나 소진 예외). **공구별 전투 방식은 취향에 따른 선택지**이며 단두대 같은 독립 처형 기술은 기본 지팡이와 모든 공구 상태에서 사용 가능. **[사용자 제안·현재 방향]** 공구 기본 공격은 **볼트커터=단일 둔화, 그라인더=단일 방깎, 전기톱=소범위 출혈**로 구분하고, 서로 다른 디버프는 중첩 가능하다. **집중 공격/광역 공격** 두 공통 액티브가 공구에 따라 효과를 바꾸며, 각각 **피해 강화 vs 디버프 강화** 노드를 선택한다. 동일 디버프 반복 중첩 상한과 처형기에 별도 조건부 보너스를 붙일지는 [미결/제안].

**[사용자 승인·시험판 기준]** 화기 스킬트리는 현재 제시안으로 우선 구현·시험한다. **[사용자 제안·현재 방향]** 자동화는 **초기 태엽인형의 자폭형/지속공격형 분기**와 **최상위의 거대한 단일 전투 소환체**를 새 성장 축으로 삼는다. 이전 최상위 후보였던 자율공방은 **지원형 장치 후보**로 구분해 재검토한다. **피해량·마나·쿨다운·소환체 능력 등 구체적 수치는 실제 플레이 테스트에서 조정**한다.

## 4. 현재 추진 범위

**[합의]** 당장 개발을 시작하는 프로젝트는 아니며, 먼저 실제 시험판에 착수할 수 있을 정도로 규칙을 구체화한다.

**[제안]** 전투감, 구동 변형, 소환 제어, 성장·파밍 연계를 검증하기 위해 기계장치의 마녀 1명만 등장하는 작은 시험판부터 제작한다.

**[미결]** 전체 개발 규모, 기술 스택, 출시 범위, 클래스 수, 난이도·엔드게임, 스킬/아이템 수치.
