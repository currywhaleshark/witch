## 아직 합의하지 않은 것

- **스킬 상세 후보**: [03_skills.md](03_skills.md)의 이름·티어·선행·특화 세부 효과는 원칙적으로 [제안]이며, **화기 트리의 현재 후보 목록은 첫 시험판 기준안으로 사용자 승인**을 받았음. 시험 결과에 따라 변경 가능.
- **[구동 조작 결정]** 공구 토글 유지·지속 마나 소모, **같은 변형 재입력 시 수동 해제, 다른 변형 사용 시 교체, 마나 0 시 자동 해제**를 합의. **처형·화기·자동화·생존·CC를 사용해도 변형 상태 유지**. **남은 미결:** 변형 공격의 모션·판정, 전환 시 비용·애니메이션, 기술 간 자원 소비 순서.
- **[자원 부족 일부 해결]** 좌클릭 등록 스킬이 마나 부족이면 기본 공격 사용(슬롯 유지), 다른 스킬 입력은 실패. **남은 미결:** 재사용 대기시간·사거리 부족 등에서도 기본 공격으로 대체하는지, 사거리 밖 클릭 시 이동 후 시전, 좌클릭 유지 동작, 자동화의 목표 지정/명령 입력.
- **[새 방향]** 고유 디버프 3종 및 기본 공격 대상 범위, 공통 집중/광역 공격 2개와 각각의 피해/디버프 양자택일은 사용자가 직접 제안한 현재 설계안. **남은 미결:** 같은 종류 디버프의 반복 중첩 횟수·상한·지속시간, 각 공통 공격의 세부 모션/비용, 기본 지팡이 상태에서의 사용 가능 여부, 대조 특화의 숫자·교환 비용.
- **[미결]** 공구와 독립 처형의 **별도 조건부 보너스**를 추가할지. **독립 처형 기술은 어떤 공구 상태에서도 시전 가능하고 시전 전후 공구 토글도 유지**된다(마나 0 예외).
- **기본 회피·마력/쿨다운** 미결.
- **[자동화 추가 미결]** 태엽인형의 자폭 조건(자동·명령식)과 폭발 범위·생존형 지속/재소환, 거대 자동인형 단일/다수 분기의 **다수 정확한 개체 수·크기·소환 방식**, 다른 소환체와의 공존, 조립 인형대/자율공방의 역할 조정.
- **[소환 입력/AI 일부 해결]** 빈 땅 좌클릭=이동과 소환/설치 호출 충돌은 **Shift+좌클릭 강제 시전**으로 해결. **남은 미결:** 초기 지정 적에 대한 집중이 언제 해제되는지, 화면 경계 추적/복귀 여유 폭(카메라 이동 포함), 설치 불가 지형과 유지시간, 강제 시전 대상/지점이 사거리 밖에 있을 때 처리.
- **[표적 중계기 미결]** 표적 지정 효과의 유지시간·해제/교체·표적 사망 처리, 레벨별 공격력 보너스 수치·적용 범위. **지정 명령으로 화면 이탈·고정 사거리 제한이 해제되는 것은 아님(현재 제안).**
- **[스킬 포인트 원칙 결정]** 스킬 습득·스킬 레벨·일반 강화·양자택일 특화는 **동일 스킬 포인트** 소비, 강화/특화 노드는 완전한 선택 사항. **남은 미결:** 레벨당 포인트 지급량·전체 포인트 예산·개별 노드 가격·스킬 랭크 상한·스킬 자체의 해금/선행 조건·리스펙 정책. 패시브 투자도 동일 풀로 묶을지는 [제안].
- **자동화 소환체 한도와 명령 인터페이스** 미결.
- **아이템 슬롯/재료/드롭 경제/의상 코스튬** 미결.
- **이름 유출 사건의 원인, 회수, 원주인 상태** 미결.
- **시험판의 엔진·플랫폼·적 수·지역·일정** 미결.

## 변경 이력

- **v0.1 / 2026-10-24:** 장기 대화에서 합의/원안/제안/미결을 통합 기록. 3트리와 6슬롯, 장비/파밍 방향 수립.
- **v0.2 / 2026-10-24:** v0.1을 보존하고 주제별 문서로 분리. 스킬별 역할·기술적 복잡도 단계·대조 특화의 후보를 **제안 상태로 확장**. 시험판 명세는 검증 가설을 기준으로 분리. **사용자의 추가 승인 없이 구체적 스킬을 확정하지 않음.**
- **v0.2 문서 정합성 보완 / 2026-10-24:** 검토 의견 7건을 반영. 진자 절단→진자 톱날로 명칭 통일. 기계장치 원안의 **낙하 단두대**를 구동 초급 후보로 복원(새 스킬로 확정한 것은 아님). 구동/화기/자동화 학습표에 행 이름 추가. 선행 관계를 발전 관계로 명확화. 좌클릭·지속 무장 충돌을 피하도록 키 배정표 대신 입력 미배정 기술 구성표를 사용. 거울·실, 시계마녀·음악 금지는 **원안/비확정 예시**임을 명시. 기본 공격·이동 입력을 우선 논의 과제로 격상. **미결정인 조작 규칙은 임의로 확정하지 않음.**

- **v0.2 조작 규칙 보완 / 2026-10-24:** 사용자의 추가 설명으로 클릭 이동, 빈 바닥 좌클릭 이동, 적 좌클릭 등록 스킬 시전, **초기 좌클릭 기본 공격(마력 소모 없음) 및 후속 교체 가능**을 합의 사항으로 기록. 구동 트리의 **공구 전개 → 기본 공격 중심의 초기 전투 → 강화 공격 스킬 습득**이라는 성장 방향을 추가. 이 당시에는 전개 유지 및 자원 부족 처리가 미결이었다.
- **v0.2 구동 토글·자원 부족 보완 / 2026-10-24:** 사용자의 추가 설명으로 공구 변형은 **토글형+마나 지속 소모**, 다른 변형 사용 시 기존 공구 **교체**(중복 유지하지 않음) 방향을 채택. 마나 부족 시 **좌클릭 스킬은 기본 공격으로 1회 대체하고 등록 유지**, **우클릭·QWER는 시전 실패**로 구분. **마나 0 자동 변형 해제는 제안** 상태. 관련 문서 동기화.

- **v0.2 공구·처형 설계 보완 / 2026-10-24:** 마나 소진 시 **공구 변형 자동 해제**를 사용자가 명시적으로 승인. 공구별 전투 스타일을 달리해 취향대로 고를 수 있도록 하고, **낙하 단두대 등 별도 처형 스킬은 공구에 관계없이 사용**하는 방향을 반영. 공구의 제압·장갑 손상·절단 누적 등의 **상태 기반 시너지**는 검토 제안으로 남기고 특정 공구가 필수 조합이 되지 않도록 주의한다.

- **v0.2 공구 토글 해제 조건 확정 / 2026-10-24:** 사용자가 정상 전투 중 변형 유지와 해제 조건을 명확히 정함. **같은 변형 재입력=수동 해제, 다른 변형 사용=공구 교체, 마나 소진=자동 해제**. 그 외 처형·화기·자동화 등 **모든 다른 스킬 사용으로는 해제되지 않음**. 유지 중 마나 지속 소모는 계속됨. 기존의 재입력 수동 해제와 타 트리 시전 시 토글 유지 미결 표기를 해결함.

- **v0.2 공구별 디버프·공통 공격안 / 2026-10-24:** 사용자가 **볼트커터 기본 단일+둔화, 그라인더 기본 단일+방깎, 전기톱 기본 소범위+출혈**, 서로 다른 디버프 중첩, **공통 집중 공격/광역 공격 2개에 각 피해 강화·디버프 강화 선택**을 제안. 스킬 문서의 구동 트리 설계 방향으로 반영. 이전의 **그라인더 광역 기본 공격 / 전기톱 단일 기본 공격**, **볼트커터·그라인더 각자 확산/집중 분기**, **진자 톱날의 별도 액티브 후보**는 새로운 공통 공격 틀과 충돌하므로 보류·대체. **서로 다른 디버프 공존**과 **동일 디버프 반복 중첩 규칙**은 구분하여 후자를 미결로 둠. 독립 처형기에는 공구 필수 조건을 넣지 않는다.

- **v0.2 화기 기준안·자동화 성장 방향 / 2026-10-24:** 화기는 기존 제시안으로 **우선 플레이 테스트**하고, 수치 밸런스는 게임을 구현한 뒤 잡는다는 작업 원칙을 승인. 자동화의 **초기 태엽인형을 '자폭형'과 '지속공격형' 양자택일로 특화**시키는 방향을 제안. 최상위에는 **눈에 띄게 큰 전투기계 한 기체**를 구현하는 스킬을 제안. 문서에는 가칭 **거대 자동인형/태엽거인**을 최종 상징 기술 후보로 추가하고, 기존 **자율공방·조립 인형대는 정비·지원용 별도 후보**로 재검토. 폭발 제어·거대 유닛 AI·소환 한도·수치는 미결로 유지.

- **v0.2 자동화 소환 조작·거대 분기 / 2026-10-24:** 거대 자동인형을 **강력한 한 기 유지 / 개체별 약하지만 다수 유지**의 양자택일 특화로 나눔. **이동형 소환체는 무엇을 찍어도 캐릭터 옆에서 생성**, 적 지정이면 그 적부터 공격하고 이후 자율행동, 빈땅이면 즉시 자율행동. 화면 밖 추격을 금지하고 복귀. **고정형 함정/포탑은 클릭한 지면에 생성**되어 기본 자율작동하며 일정 시간 후 해체. 기존 **표적 중계기**로 공격 가능한 소환체들을 지정 적에게 일점사시키고, 스킬 레벨마다 지정 표적 공격력 소폭 상승. 초기 지정과 전투 중 집중 명령은 분리하되, 명령 우선순위·화면 경계 구현·빈땅 좌클릭 시전 충돌은 세부 검토 항목으로 남김.

- **v0.2 Shift+좌클릭 강제 시전 확정 / 2026-10-24:** 사용자가 **Shift+좌클릭은 반드시 있어야 한다**고 확인. 빈 바닥 일반 좌클릭은 이동, 적 일반 좌클릭은 등록 스킬 사용이라는 기존 규칙을 유지하면서 **Shift+좌클릭은 캐릭터 이동 없이 좌클릭 슬롯 스킬을 커서 지면/적에 강제 시전**하도록 확정. 이동형 소환은 Shift+빈 땅 클릭 시 플레이어 옆에 생성해 자율행동, Shift+적 클릭 시 플레이어 옆에 생성하고 초기 적 지정, 고정형은 Shift+유효 지면 클릭으로 그 위치에 설치. 사거리/설치 가능 지형/유지 입력은 별도 미결.

- **v0.2 공용 스킬 포인트·선택 노드 원칙 / 2026-10-24:** 사용자가 **스킬 레벨과 강화/특화 노드에 같은 재화를 사용**하는 방식에 동의하고 **노드 투자 자체를 선택**하게 하자고 결정. 액티브 스킬 기본 형태가 유효해야 하고, 공통 강화/양자택일 특화를 건너뛰어도 일반 사냥/보스에 대응할 수 있어야 한다. 노드를 찍지 않는 것만으로 상위 기술 습득이 막히는 **강제 노드 경유**는 금지. 포인트 수·랭크 상한·개별 비용·리스펙은 아직 미정. **태엽인형의 기본 반복 공격 형태도 노드 없이 작동**하며 자폭/지속공격을 선택할 때에만 변화한다.

## 다음 논의 우선순위

1. **구동 공통 스킬·디버프 상세:** 볼트커터 단일 둔화·그라인더 단일 방깎·전기톱 소범위 출혈을 바탕으로 집중/광역 공격 모션과 타격 판정, 각 피해/디버프 특화, 동일 디버프 누적 제한·강적 대응. **토글 유지·해제 규칙은 결정 완료.**
2. **기본 조작 예외 규칙:** **Shift+좌클릭 강제 시전은 확정**. 남은 것은 마나 이외의 시전 실패, 사거리 밖 대상 클릭·제자리 시전 유효 범위, 마우스 유지·강제 이동, 자동화 소환체 명령 지속시간.

4. **자동화 설계 세부:** 거대 자동인형 1기/다수 특화의 조작·공존, 이동형 소환의 첫 목표와 화면 경계 복귀, 고정형 타이머 해체, 표적 중계기 명령 우선순위와 레벨별 소폭 피해 증가. **태엽인형의 자동/명령 자폭도 미결**. 화기는 현행 기준안 시험.
5. **공유 포인트의 세부 경제(미결):** 포인트 획득량·스킬 레벨 상한·노드 비용·초급기 집중 투자와 특화 선택의 밸런스·리스펙. 같은 포인트 풀 사용과 노드 투자 선택권은 **이미 합의**. 자원·쿨다운·기본 생존 입력.
