## 변경 이력 — 당시 상태의 역사 기록

> 아래 항목의 '당시 제안/미결'은 **그 날짜에 그러했다는 뜻**이다. 후속 승인으로 변경된 경우가 있다. 예를 들어 10월 24일 초기에 **'마나 0 자동 해제 = 제안'**이었지만, 같은 날 뒤이어 승인되었다. **현재 규칙을 확인할 때 아래 로그가 아니라 [02](02_combat.md) 등 원본 문서만 사용**한다.

- **v0.1 / 2026-10-24:** 장기 대화에서 합의/원안/제안/미결을 통합 기록. 3트리와 6슬롯, 장비/파밍 방향 수립.
- **v0.2 / 2026-10-24:** v0.1을 보존하고 주제별 문서로 분리. 스킬별 역할·기술적 복잡도 단계·대조 특화의 후보를 **제안 상태로 확장**. 시험판 명세는 검증 가설을 기준으로 분리. **사용자의 추가 승인 없이 구체적 스킬을 확정하지 않음.**
- **v0.2 문서 정합성 보완 / 2026-10-24:** 검토 의견 7건을 반영. 진자 절단→진자 톱날로 명칭 통일. 기계장치 원안의 **낙하 단두대**를 구동 초급 후보로 복원(새 스킬로 확정한 것은 아님). 구동/화기/자동화 학습표에 행 이름 추가. 선행 관계를 발전 관계로 명확화. 좌클릭·지속 무장 충돌을 피하도록 키 배정표 대신 입력 미배정 기술 구성표를 사용. 거울·실, 시계마녀·음악 금지는 **원안/비확정 예시**임을 명시. 기본 공격·이동 입력을 우선 논의 과제로 격상. **미결정인 조작 규칙은 임의로 확정하지 않음.**

- **v0.2 조작 규칙 보완 / 2026-10-24:** 사용자의 추가 설명으로 클릭 이동, 빈 바닥 좌클릭 이동, 적 좌클릭 등록 스킬 시전, **초기 좌클릭 기본 공격(마력 소모 없음) 및 후속 교체 가능**을 합의 사항으로 기록. 구동 트리의 **공구 전개 → 기본 공격 중심의 초기 전투 → 강화 공격 스킬 습득**이라는 성장 방향을 추가. 이 당시에는 전개 유지 및 자원 부족 처리가 미결이었다.
- **v0.2 구동 토글·자원 부족 보완 / 2026-10-24:** 사용자의 추가 설명으로 공구 변형은 **토글형+마나 지속 소모**, 다른 변형 사용 시 기존 공구 **교체**(중복 유지하지 않음) 방향을 채택. 마나 부족 시 **좌클릭 스킬은 기본 공격으로 1회 대체하고 등록 유지**, **우클릭·QWER는 시전 실패**로 구분. **마나 0 자동 변형 해제는 제안** 상태. 관련 문서 동기화.

- **v0.2 공구·처형 설계 보완 / 2026-10-24:** 마나 소진 시 **공구 변형 자동 해제**를 사용자가 명시적으로 승인. 공구별 전투 스타일을 달리해 취향대로 고를 수 있도록 하고, **낙하 단두대 등 별도 처형 스킬은 공구에 관계없이 사용**하는 방향을 반영. 공구의 제압·장갑 손상·절단 누적 등의 **상태 기반 시너지**는 검토 제안으로 남기고 특정 공구가 필수 조합이 되지 않도록 주의한다.

- **v0.2 공구 토글 해제 조건 확정 / 2026-10-24:** 사용자가 정상 전투 중 변형 유지와 해제 조건을 명확히 정함. **같은 변형 재입력=수동 해제, 다른 변형 사용=공구 교체, 마나 소진=자동 해제**. 그 외 처형·화기·자동화 등 **모든 다른 스킬 사용으로는 해제되지 않음**. 유지 중 마나 지속 소모는 계속됨. 기존의 재입력 수동 해제와 타 트리 시전 시 토글 유지 미결 표기를 해결함.

- **v0.2 공구별 디버프·공통 공격안 / 2026-10-24:** 사용자가 **볼트커터 기본 단일+둔화, 그라인더 기본 단일+방깎, 전기톱 기본 소범위+출혈**, 서로 다른 디버프 중첩, **공통 집중 공격/광역 공격 2개에 각 피해 강화·디버프 강화 선택**을 제안. 스킬 문서의 구동 트리 설계 방향으로 반영. 이전의 **그라인더 광역 기본 공격 / 전기톱 단일 기본 공격**, **볼트커터·그라인더 각자 확산/집중 분기**, **진자 톱날의 별도 액티브 후보**는 새로운 공통 공격 틀과 충돌하므로 보류·대체. **서로 다른 디버프 공존**과 **동일 디버프 반복 중첩 규칙**은 구분하여 후자를 미결로 둠. 독립 처형기에는 공구 필수 조건을 넣지 않는다.

- **v0.2 화기 기준안·자동화 성장 방향 / 2026-10-24:** 화기는 기존 제시안으로 **우선 플레이 테스트**하고, 수치 밸런스는 게임을 구현한 뒤 잡는다는 작업 원칙을 승인. 자동화의 **초기 태엽인형을 '자폭형'과 '지속공격형' 양자택일로 특화**시키는 방향을 제안. 최상위에는 **눈에 띄게 큰 전투기계 한 기체**를 구현하는 스킬을 제안. 문서에는 가칭 **거대 자동인형/태엽거인**을 최종 상징 기술 후보로 추가하고, 기존 **자율공방·조립 인형대는 정비·지원용 별도 후보**로 재검토. 폭발 제어·거대 유닛 AI·소환 한도·수치는 미결로 유지.

- **v0.2 자동화 소환 조작·거대 분기 / 2026-10-24:** 거대 자동인형을 **강력한 한 기 유지 / 개체별 약하지만 다수 유지**의 양자택일 특화로 나눔. **이동형 소환체는 무엇을 찍어도 캐릭터 옆에서 생성**, 적 지정이면 그 적부터 공격하고 이후 자율행동, 빈땅이면 즉시 자율행동. 화면 밖 추격을 금지하고 복귀. **고정형 함정/포탑은 클릭한 지면에 생성**되어 기본 자율작동하며 일정 시간 후 해체. 기존 **표적 중계기**로 공격 가능한 소환체들을 지정 적에게 일점사시키고, 스킬 레벨마다 지정 표적 공격력 소폭 상승. 초기 지정과 전투 중 집중 명령은 분리하되, 명령 우선순위·화면 경계 구현·빈땅 좌클릭 시전 충돌은 세부 검토 항목으로 남김.

- **v0.2 Shift+좌클릭 강제 시전 확정 / 2026-10-24:** 사용자가 **Shift+좌클릭은 반드시 있어야 한다**고 확인. 빈 바닥 일반 좌클릭은 이동, 적 일반 좌클릭은 등록 스킬 사용이라는 기존 규칙을 유지하면서 **Shift+좌클릭은 캐릭터 이동 없이 좌클릭 슬롯 스킬을 커서 지면/적에 강제 시전**하도록 확정. 이동형 소환은 Shift+빈 땅 클릭 시 플레이어 옆에 생성해 자율행동, Shift+적 클릭 시 플레이어 옆에 생성하고 초기 적 지정, 고정형은 Shift+유효 지면 클릭으로 그 위치에 설치. 사거리/설치 가능 지형/유지 입력은 별도 미결.

- **v0.2 공용 스킬 포인트·선택 노드 원칙 / 2026-10-24:** 사용자가 **스킬 레벨과 강화/특화 노드에 같은 재화를 사용**하는 방식에 동의하고 **노드 투자 자체를 선택**하게 하자고 결정. 액티브 스킬 기본 형태가 유효해야 하고, 공통 강화/양자택일 특화를 건너뛰어도 일반 사냥/보스에 대응할 수 있어야 한다. 노드를 찍지 않는 것만으로 상위 기술 습득이 막히는 **강제 노드 경유**는 금지. 포인트 수·랭크 상한·개별 비용·리스펙은 아직 미정. **당시 문서에는 태엽인형의 기본형이 단순 반복공격이라고 적었으나, 뒤의 '기본 혼합형' 합의로 변경되었다.**

- **v0.2 기본형·특화의 성격 확정 / 2026-10-24:** 사용자가 **노드를 찍지 않은 스킬은 한쪽으로 치우치지 않는 형태**여야 한다고 보완. **태엽인형 기본형은 일정 시간 전투 후 자폭**, **자폭 특화는 적에게 접근하면 별도 일반 공격 없이 곧바로 폭발**, **지속공격 특화는 시간에 따른 자동 자폭을 없애고 계속 공격**하는 세 행동으로 정리. '접근하면 곧바로'는 소환 위치에서 즉시 폭발한다는 뜻이 아닌 적과의 접촉·유효 거리 도달로 해석. 포인트를 안 쓰는 기본형도 지속 공격과 자폭을 모두 보유하고, A/B 특화는 다른 성격을 포기해 전문화한다. 기존의 '기본형=단순 지속 공격' 문구를 교체. 폭발 타이머 기점·목표 부재·수동 폭파 지원과 수치는 미결.

- **v0.2 패시브의 기계 원리별 교차 적용 / 2026-10-24:** 사용자가 **패시브가 다른 트리에도 영향을 주는 방향**을 제안. 예: **구동 절삭 패시브로 칼날형 자동인형의 공격력 강화**, **화기 탄도 패시브로 자동포탑의 탄도·사격 성능 강화**. 핵심은 출처 트리보다 **공격·기계의 작동 원리**를 기준으로 적용하는 것. 타 트리 효과는 혼합 빌드의 추가 선택이며 **타 트리 패시브를 반드시 찍게 만들지 않는다**. **구조 보강→소환체 방어/내구**, **동력 관리→공구 유지 마나 절감**은 확장 제안으로만 기록. 스킬·소환체 기능별 태그·교차 계수·패시브 포인트 소비는 미결.

- **v0.2 수동 스탯 배분·스킬/스탯 무료 초기화 / 2026-10-24:** 사용자가 **근접·원거리·소환을 스킬로 선택하므로 기본 스탯도 직접 배분**하는 쪽으로 방향을 결정. **스킬과 스탯 양쪽 모두 무료·횟수 제한 없이 자유롭게 초기화/재배분**하는 원칙에 합의. 현재 스탯 명칭·개수·기능은 아직 미결이므로 [07_attributes.md](07_attributes.md)에 **당시에는 출력·정밀·내구·동력의 4축을 검토안**으로 기재. 이후 다른 클래스에도 적용할 수 있는 이름을 요구받아 새 후보로 대체. **스탯 포인트와 스킬 포인트 풀은 별도 관리가 우선 제안이지만 아직 미합의**이며, 초기화 UI의 위치·전투 중 허용·프리셋·장비 스탯 요구 조건은 미결. 기존의 '리스펙 정책 미정' 기록은 **비용/횟수 문제에 한해 이번 합의로 대체**한다.

- **v0.2 범용 스탯 명칭 검토 / 2026-10-24:** 사용자가 **다른 클래스에도 공통으로 사용할 수 있는 이름**으로 기본 스탯을 정해야 한다고 지적. **출력·정밀·내구·동력**은 기계장치의 마녀에게만 자연스럽다는 문제를 반영하여, 기계 전용 단어를 공통 기본 스탯에서 제외하고 **위력·기교·활력·의지**를 새 **[제안]**으로 기록. 명칭은 사용자 승인 전이므로 **확정하지 않음**. 해당 스탯이 실제로 어떤 권능·파생 수치에 영향을 주는지, 네 축이 적절한지도 [미결]. 기존 기계 용어는 스킬/패시브/기계의 동작 원리 설명에는 남긴다.

- **v0.2 공통 기본 스탯 이름 승인·핵심 역할 / 2026-10-24:** 사용자가 **위력·기교·활력·의지**라는 이름을 승인하며 순서대로 **데미지·명중률·체력·마나**로 쉽게 이해할 수 있다고 설명. 네 이름과 1차 역할을 [합의]로 격상하고, 이전 기계 중심 이름 **출력·정밀·내구·동력**은 대체했다. **치명타·체력/마나 회복 등 추가 효과나 상세 계산식은 승인하지 않은 [제안]/[미결]**로 유지한다. 특히 모든 권능에서 **명중률 굴림을 강제할 것인지**, 광역·장판·자동추적처럼 명중 판정 없는 기술에서 **기교**를 어떻게 활용할지는 별도 검토한다.

- **v0.2 기교의 치명타 확대·확정 적중/광역의 명중 굴림 제외 / 2026-10-24:** 사용자가 **확정 적중·광역 공격에는 명중률 판정을 빼고 대신 치명 확률은 모두 적용**하는 방안을 제안. 따라서 **기교는 명중 굴림을 사용하는 일반 공격의 적중률 + 피해를 주는 모든 공격의 치명타 확률**에 기여하는 방향. 공간·충돌·범위 판정은 제거하지 않음. 소환수·자동포탑도 실제 피해 공격에는 치명타 가능성을 부여하되, 어떤 공격에 확률적 명중 굴림이 필요한지는 유형별로 판단. **광역 다중 대상 치명타 단위, 출혈 등 지속 피해 치명타 처리, 소환체 기교 상속률, 치명 배율·상한**은 미결. 추가 효과를 새로 확정하지 않고 검토 방향으로 기록.

- **v0.2 광역 적별 치명·출혈 고정비율/방어무시/비치명 확정 / 2026-10-24:** 사용자가 **광역 직접 피해의 치명타는 맞은 적마다 별도 판정**하도록 승인. 또한 **출혈은 방어력을 무시하는 고정비율 지속 피해이며 치명타가 발생하지 않는 것**으로 결정. 출혈을 부여한 **전기톱의 직접 타격**은 정상적인 치명타 판정을 유지하되 **출혈 피해 틱은 예외로 제외**한다. 따라서 **방깎은 출혈 피해를 강화하지 않으나 방어력 영향을 받는 직접 타격에는 유효**하다. 이전 로그의 '모든 피해 공격에 치명타' 방향은 이 출혈 예외로 좁혀서 해석. **고정비율의 기준(대상 최대 체력/스킬 기준 등), 틱 간격·지속시간·중첩·보스 보정과 방어 외 저항 관계는 미결**로 둔다.

- **v0.3 초기 클래스 3종과 시대 명칭 확인 / 2026-10-25:** 사용자가 시나리오 담당과 **초기 3클래스(기계장치·유리·재봉)**를 이미 정했다고 확인했다. **기계장치는 하이브리드, 유리는 원거리 치중, 재봉은 근거리 치중**으로 구분하며, **2000년대 초반 한국의 기관명은 '동사무소'**로 쓴다. 이름·전투 성향은 [01 · 세계관](01_world.md)의 현행 합의이고, 4막 사건·NPC·인물 성격·다른 두 클래스의 상세 스킬은 **시나리오 담당과 후속 기획의 영역**으로 남긴다. **기계장치 1종 우선 시험판**이라는 개발 범위는 유지된다. 첨부된 `08_scenario_draft.md`의 독자적인 내용은 이번에 덮어쓰지 않았고, 이후 시나리오 담당이 내용을 보완한다.

- **v0.3 최초 시안의 전투 필드 우선·추가 클래스 3트리 윤곽 / 2026-10-25:** 사용자는 세부 시나리오 완성 전에 **스토리·동사무소 허브·NPC를 빼고 기계장치의 마녀 1종으로 전투 필드부터 구현**하기로 했다([06](06_vertical_slice.md)). 추가 클래스는 스킬 상세 없이 **유리: 파편(파편 투사·장판) / 거울(반사·교란·유틸) / 렌즈(집속 광선)**, **재봉: 재단(가위 공격·보조) / 바느질(포박·디버프) / 직조(방어·버프)**의 *역할 윤곽*을 [01](01_world.md)에 **[사용자 제안·미확정]**으로 기록. 유리의 거울·렌즈 통합 및 새 제3트리 도입 가능성은 열어둔다. 사용자가 재봉의 세 번째 항목을 '재단'으로 다시 표현한 것은 이전 3분류와 역할을 근거로 '직조'로 해석했으며 확인 가능하다. 스킬 이름/세부 수치, 4막 사건·인물·대사는 확정하지 않고 시나리오 담당 작업 영역을 유지한다.

- **v0.3 장비 슬롯·전용 매개체·이름 파편 / 2026-10-25:** 사용자가 장비를 **간결형 7칸**(핵심 매개체·머리장식·의상·장갑·신발·브로치·반지)으로 정하고, **의상 외형은 고정**·매개체는 **기본 지팡이에 장식만 바뀌는** 방식으로 결정. 장비를 **공용(일반 스탯·효과) / 클래스 전용(특정 스킬 레벨+, 전용 태그 등)**으로 나누고, 기계장치의 마녀 전용 장비 **설계도·부품을 모두 핵심 매개체**로 두어 공용 매개체와 한 칸을 두고 경쟁하게 함. 계정 공유 **주민센터 캐비닛**, **제작·분해·재굴림 도입**(제작 NPC는 시나리오 담당 제안 대기)을 합의. 공용 소켓물은 **이름 파편**으로, 자리별 효과 변화·룬워드식 조합·**베이스별 최대치 내 무작위 소켓 수**(초반 1~2개)·**NPC를 통한 파편 제거**를 합의. 설계도/부품의 역할 구분, 자리 3분류, 조합 효과의 범용성, 파편 희귀도와 몬스터 등급 연동, 소켓 차등은 **[제안]**. 상세는 [04](04_items.md) §3·§6·§7.

- **v0.3 소켓 최소값·파편 제거 비용·시험판 아이템 범위 / 2026-10-25:** 사용자가 **무작위 소켓 수는 0을 포함**하고 **파편 제거는 유료**로 결정. 스킬·스탯 초기화는 무료로 유지되며, 파편 제거 비용의 지불 수단과 크기는 미결([04](04_items.md) §6). 첫 시험판의 단계별 아이템 도입 범위와 검증 항목 C6~C9를 **[제안]**으로 추가([06](06_vertical_slice.md) §4·§4.1).

- **v0.3 마녀도시 화폐·물약 / 2026-10-25:** 사용자가 게임 재화를 현실 돈이 아닌 **마녀도시 화폐**로 정하고, 파편 제거 비용도 이 화폐로 낸다. **물약**을 추가해 **1·2·3·4 퀵슬롯**으로 사용하며, 같은 종류·같은 등급끼리 **개수 제한 없이 중첩**, 회복은 **시간에 걸쳐 차오르고**, 남용은 **쿨타임**으로 제한한다. 체력·마나·회복(둘 다)·버프(시간제)를 두고, **소·중·대 등급은 시나리오 진행에 따라 상점에서 점차 개방**, **완전 회복 물약은 드롭 전용**. 회복량 등급별 고정, 버프 물약의 상황형 효과는 **[제안]**. 쿨타임 공유 범위·길이, 완전 회복의 대상·즉시 여부는 미결. 같은 커밋에서 04의 '주민센터 캐비닛'을 현행 명칭인 **동사무소 캐비닛**으로, 거울의 마녀 예시를 초기 3클래스(유리·재봉) 기준으로 고쳤다. 상세는 [04](04_items.md) §8, 입력은 [02](02_combat.md) §1, 검증은 [06](06_vertical_slice.md) C9·C10.
