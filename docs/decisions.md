## 아직 합의하지 않은 것

- **스킬 상세 후보**: [03_skills.md](03_skills.md)의 기술 이름·티어·선행·특화별 효과는 모두 [제안]. 이번 문서화만으로 확정되지 않음.
- **구동의 무장 전개 입력 방식**: 지속 자세, 시전 시 일시 변형, 또는 혼합 중 미결.
- **[최우선 미결] 기본 공격과 이동/좌클릭 입력:** 마력 0 공격의 유무, 6칸 안팎 여부, 클릭 이동 vs 직접 이동, 변형 상태의 기본 공격과 자동화 조작. 이에 따라 스킬 로드아웃과 시험판이 바뀐다.
- **기본 회피·마력/쿨다운** 미결.
- **스킬 포인트 경제·리스펙, 자동화 소환체 한도와 명령 인터페이스** 미결.
- **아이템 슬롯/재료/드롭 경제/의상 코스튬** 미결.
- **이름 유출 사건의 원인, 회수, 원주인 상태** 미결.
- **시험판의 엔진·플랫폼·적 수·지역·일정** 미결.

## 변경 이력

- **v0.1 / 2026-10-24:** 장기 대화에서 합의/원안/제안/미결을 통합 기록. 3트리와 6슬롯, 장비/파밍 방향 수립.
- **v0.2 / 2026-10-24:** v0.1을 보존하고 주제별 문서로 분리. 스킬별 역할·기술적 복잡도 단계·대조 특화의 후보를 **제안 상태로 확장**. 시험판 명세는 검증 가설을 기준으로 분리. **사용자의 추가 승인 없이 구체적 스킬을 확정하지 않음.**
- **v0.2 문서 정합성 보완 / 2026-10-24:** 검토 의견 7건을 반영. 진자 절단→진자 톱날로 명칭 통일. 기계장치 원안의 **낙하 단두대**를 구동 초급 후보로 복원(새 스킬로 확정한 것은 아님). 구동/화기/자동화 학습표에 행 이름 추가. 선행 관계를 발전 관계로 명확화. 좌클릭·지속 무장 충돌을 피하도록 키 배정표 대신 입력 미배정 기술 구성표를 사용. 거울·실, 시계마녀·음악 금지는 **원안/비확정 예시**임을 명시. 기본 공격·이동 입력을 우선 논의 과제로 격상. **미결정인 조작 규칙은 임의로 확정하지 않음.**

## 다음 논의 우선순위

1. **기본 공격과 이동 입력:** 마나 없이 쓰는 행동을 둘지, 6칸에 포함할지, 좌클릭·우클릭과 이동이 어떤 관계인지 **먼저** 결정.
2. **구동 변형 입력:** 무장 변형이 지속되는지·여러 무장을 동시에 유지하는지, 기본 공격이 변하는지.
3. **화기·구동·자동화 스킬 후보:** 단두대 복원 등 개별 기술·선행 관계·특화 검토.
4. 포인트 투자·시너지·특화 재설정, 자원·쿨다운·기본 생존 입력.
5. 장비 슬롯·고유 효과와 스킬의 상호작용, 몬스터 대응.

> 새 합의 시 해당 주제 문서를 먼저 갱신하고, 이 로그에는 '무엇을 왜 바꿨는지'만 간결히 남긴다.
