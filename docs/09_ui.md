# UI·화면 구성

> **현행 v0.3 · 2026-10-25.** 전투 HUD와 메뉴 화면 배치의 단일 원본. 각 요소가 따르는 규칙은 해당 원본 문서를 링크한다(입력·마나 [02](02_combat.md), 아이템·물약 [04](04_items.md), 피해 판정 [07](07_attributes.md)). 확정하지 않은 내용은 [제안]/[미결]로 표시한다.

## 1. 화면 배치 — [합의]

| 위치 | 표시 | 상태 |
|---|---|---|
| **적 머리 위** | 일반 적의 체력과 디버프 | **[합의]** |
| **화면 상단** | **정예·보스**의 체력과 디버프 | **[합의]** |
| **화면 상단** | 플레이어의 **버프·디버프·공구 토글** 아이콘 | **[합의]** |
| **하단 바** | **물약 4칸 · 스킬 6칸 · 각 메뉴 버튼** | **[합의]** |

- **[제안]** 상단을 둘로 나눈다. **가운데는 정예·보스 정보**, **왼쪽은 플레이어 상태 아이콘**. 보스 정보와 내 상태가 서로 가리지 않게 한다.

```
 [버프·디버프·토글 아이콘]      [ 보스 이름 · 체력 · 디버프 ]

                    (전투 필드)
                 적 머리 위: 체력·디버프

 [HP] [1][2][3][4]  [좌][우][Q][W][E][R]  [메뉴 버튼들] [MP]
```

## 2. 피해 숫자 — [합의]

- **[합의] 피해 숫자를 띄우지 않는다.** 화면이 싸 보이는 것을 피한다.
- **[제안]** 숫자 대신 타격감으로 전달한다. 치명타는 타격 이펙트·사운드·짧은 화면 반응으로 일반 타격과 구분하고, 광역 공격의 적별 치명타([07](07_attributes.md))도 각 적의 반응으로 보이게 한다.
- **[제안]** 플레이어가 빌드를 비교할 수 있도록 **캐릭터 정보창**에는 공격력·치명타 확률·속도 등의 수치를 보여 준다.
- **[제안]** 개발 중에는 [06](06_vertical_slice.md) B3·B8처럼 피해를 재야 하는 검증이 있으므로 **개발자 전용 피해 표시**를 따로 둔다. 플레이어에게는 노출하지 않는다.

## 3. 전투 HUD 요소

| 요소 | 표시해야 할 것 | 따르는 규칙 |
|---|---|---|
| 체력·마나 | 현재 값과 **물약으로 앞으로 차오를 양** | 물약은 시간에 걸쳐 차오름([04 §8.2](04_items.md)) |
| 스킬 6칸 | 쿨타임, **마나 부족 상태**, 좌클릭 대체·우클릭/QWER 발동 실패 반응 | [02 §1](02_combat.md) |
| 물약 4칸 | 남은 개수, 쿨타임(같은 묶음은 함께 표시), **0개일 때 빈칸** | 종류별 쿨타임·회복 물약은 둘 다 돌림·자동 보충 없음([04 §8.2](04_items.md)) |
| 공구 토글 | 켜진 공구, 마나 소모 중임, **마나 0 자동 해제 직전 경고** | [02](02_combat.md) |
| 버프 | 아이콘과 남은 시간. 3종 동시 표시 가능 | [04 §8.2](04_items.md) |
| 적 디버프 | 둔화·방깎·출혈 아이콘, **출혈 중첩 수** | 최대 5중첩·중첩별 타이머([07](07_attributes.md)) |
| 적 등급 | 정예·보스는 상단 표시로 자연히 구분 | 등급별 출혈 비율([05](05_content.md)) |
| 소환체 | 소환체 수, 표적 중계기 지정 마커, 거대 자동인형 체력 | [02](02_combat.md), [03](03_skills.md) |

## 4. 하단 바 메뉴 버튼 — [제안]

- 인벤토리·장비, 스킬트리, 스탯, 캐릭터 정보, 설정.
- 첫 시안(전투 필드만, [06 §0](06_vertical_slice.md))에서는 쓰지 않는 메뉴를 비활성으로 두거나 숨긴다.

## 5. 클래스별 UI 모양 — [사용자 제안·현재 방향]

- **[사용자 제안·현재 방향]** HUD의 모양을 클래스에 따라 다르게 표현하는 방향을 검토한다. 예를 들어 기계장치는 톱니·놋쇠 계기판, 유리는 유리 조각, 재봉은 실과 천.
- **[주의]** 배치와 정보 위치는 클래스가 달라도 같게 유지하고, **장식만 바꾼다.** 클래스를 바꿔도 같은 자리에서 같은 정보를 찾을 수 있어야 한다.
- **[합의] 체력·마나 게이지는 클래스별 UI 장식에 맞춘 형태**로 만든다. 하단 바 양 끝이라는 위치는 클래스와 관계없이 같다.
- **[주의]** 형태가 달라도 **현재 값과 물약으로 차오를 양(§3)** 이 같은 방식으로 읽혀야 한다. 장식 때문에 남은 양을 가늠하기 어려워지면 안 된다.
- **[제안]** 첫 시안은 기계장치의 마녀만 있으므로 기계장치용 게이지 하나만 만든다. 예를 들어 압력계 바늘, 유리관 속 액체, 톱니가 감긴 원통형 게이지.

## 6. 미결

- **[미결]** 클래스별 체력·마나 게이지의 구체적 디자인.
- **[미결]** 마나 부족·발동 실패·사거리 밖의 구체적 피드백 방식([02](02_combat.md)의 입력 예외와 함께).
- **[미결]** 메뉴 화면(장비창 7칸·소켓, 툴팁의 기본 옵션/접두·접미/단계 표시와 비교, 스킬트리 A/B 특화, 스탯 배분, 무료 초기화, 제작·파편 제거, 상점, 캐비닛)의 배치.
- **[미결]** 미니맵·지도, 화면 해상도와 UI 크기 조절.
