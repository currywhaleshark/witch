# 전투·조작 시스템

> 기획 v0.2 · 아직 조작 프로토타입이 없으므로 세부 입력과 수치는 [제안]/[미결]로 남긴다.

## 1. 확정된 조작 틀

- **[합의]** 액티브 스킬의 장착 슬롯은 좌클릭 / 우클릭 / Q / W / E / R, 총 6개.
- **[합의]** 공격 외에도 생존기, 군중제어(CC), 소환 기술을 6슬롯 안에서 조합할 수 있어야 한다.
- **[합의]** 패시브와 스킬별 강화·특화 노드는 액티브 슬롯을 사용하지 않는다.
- **[미결·최우선]** 마력 등 자원 없이 계속 사용할 수 있는 **기본 공격이 존재하는가**, 있다면 좌클릭·우클릭·QWER의 **6개 스킬 슬롯에 포함되는가**.
- **[미결·최우선]** 클릭 이동인지 직접 이동인지, 좌클릭으로 빈 바닥/적을 클릭할 때의 행동과 스킬 시전 우선순위.
- **[미결]** 기본 회피의 유무·입력, 스킬 쿨다운·자원, 공격 명중 판정.

### 1.1 기본 공격과 6슬롯의 관계 — 아직 결정하지 않음

| 방안 | 설명 | 득실 |
|---|---|---|
| **[제안 A] 6슬롯 안에 배치** | 마력 0의 기초 공격 스킬을 6칸 중 원하는 곳에 장착 | 기존 6슬롯 유지. 대신 기본 공격도 한 칸을 차지하고, 장착하지 않았을 때 자원 고갈 대응이 필요 |
| **[제안 B] 6슬롯 밖의 기본 행동** | 마력 0의 기본 공격을 별도 기본 동작으로 제공하고 6칸은 모두 스킬로 사용 | 파밍/빌드용 슬롯을 보존. 다만 별도 입력 또는 상황별 자동 전환 규칙을 추가해야 함 |

**[미결]** 위 두 방식 중 무엇을 택할지, 공구 변형 상태에서 기본 공격의 형태가 바뀌는지, 자동화에 집중한 빌드도 자원 고갈 시 어떤 행동으로 대응하는지, 기본 공격이 모든 이름의 마녀에게 공통인지. **결정 전에는 스킬 후보를 좌클릭에 고정하지 않는다.**

**[미결]** 클릭 이동을 채택한다면 빈 바닥 클릭=이동, 적 클릭=공격·기술 발동 같은 상황별 규칙과 강제 이동 입력을 별도로 정해야 한다. 직접 이동을 채택한다면 좌클릭이 이동 명령과 충돌하지 않도록 입력 모델을 설계한다.

## 2. 전투 역할의 구분

| 트리 | 강점 | 보완 기술 | 전투감 |
|---|---|---|---|
| 화기 | 다수의 적에게 직접 화력 투사 | 강선 장총 등의 단일 공격, 반동 도약/연막 | 조준·간격 유지·발사 타이밍 |
| 구동(가칭) | 공구형 지팡이의 근접 공격, 제압, 방어 | 진자 톱날 등 좁은 광역 공격 | 위험을 감수한 접근·무장 전환·강한 일격 |
| 자동화 | 소환체의 지속 공격·역할 분담 | 집중 표적 지정, 호위·수리 장치 | 배치·유지·표적 통제 |

**[합의]** 트리는 역할의 우선순위를 나타낼 뿐 배타적이지 않다. 각각 혼자서 일반 사냥과 보스전에 대응 가능해야 한다.

## 3. 구동 트리의 변형 상태 — 논의가 필요한 핵심

- **[합의]** 구동의 대표 연출은 장착한 매개체에 대응하는 지팡이가 볼트커터·그라인더·절단기·전기톱 같은 근접 공구형 무장으로 변하는 것.
- **[합의]** 무장 전개는 근접 공격 방식과 방어·자기강화 효과를 제공한다.
- **[제안 A]** '무장 전개' 액티브를 누르면 일정 시간 그 공구를 사용하며, 기본 공격 입력의 모션/판정이 바뀐다. QWER 등에 다른 계열의 스킬을 계속 장착할 수 있다.
- **[제안 B]** 모든 공구 스킬을 단발형으로 만들어 시전하는 순간만 지팡이가 변형됐다가 복귀한다. 일부 고급 강화기에만 지속 변형을 둔다.
- **[미결]** 위 방식 중 어느 쪽을 주 방식으로 채택할지, 공구 전개 간 동시 사용 여부, 다른 계열 시전 시 자동 해제/유지, 좌클릭 슬롯과의 충돌 처리.
- **[주의]** 서로 다른 지속형 무장을 두 슬롯에 등록했다고 두 상태가 동시에 유지된다고 가정하지 않는다. 다중 전개 가능·상호 배타·자동 교체 가운데 무엇을 선택할지도 미결.

## 4. 타격·제어·생존의 기본 원칙

- **[합의]** 일반 스킬 강화로 넉백/경직/기절·그로기 같은 부가효과를 더할 수 있다. 예: 산탄포의 넉백 특화.
- **[제안]** 보스처럼 이동 불능/강제 이동에 저항하는 적은 제어 자체가 완전히 무효가 되기보다 그로기 누적 또는 일부 효과로 보상받을 수 있게 한다.
- **[제안]** 생존기는 트리마다 개성이 있지만 기본적인 회피·위기 탈출은 어떤 한 트리의 필수 스킬 포인트를 요구하지 않도록 한다.
- **[미결]** 기본 회피/가드의 존재, 저항·경직 규칙, 보스의 CC 저항과 관통 규칙.

## 5. 스킬 강화·고유 아이템과의 경계

- **[합의]** 액티브의 일반 강화는 수치 향상이나 본래 용법의 개선에 해당.
- **[합의]** 액티브의 양자택일 특화는 광역 대 집중, 공격 대 제어 등 **대조되는 사용 목적**을 제공한다.
- **[합의]** 고유 아이템은 스킬의 발동 위치, 연쇄·생성 방식 등 **작동 규칙의 질적 변화**를 담당한다.
- **[미결]** 특화 변경 비용, 강화 노드별 포인트 수, 고유 아이템과 특화의 예외적 충돌 처리.

## 6. 검증 기준

1. 마력 0 기본 공격과 좌클릭 이동·시전 규칙을 정하고, 자원이 바닥나도 전투가 끊기지 않는가?
2. 6슬롯 구성으로 일반 사냥/정예/보스에 답답함 없이 대응하는가?
3. 변형 상태에서 의도치 않은 입력 잠금이나 스킬 강제 해제가 생기지 않는가?
4. 화기·구동·자동화가 각기 다른 손맛으로 사냥과 보스를 모두 상대하는가?
5. 넉백·수리·호위 등의 제어/생존 기술이 단순 피해량 증가와 구분되는 선택인가?
