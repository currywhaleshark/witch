# 전투·조작 시스템

> **현행 v0.3 · 2026-10-25.** 입력 방식, 소환 위치/표적 지정, 변형 상태·마나 흐름의 **단일 규칙 원본**. 개별 스킬은 [03](03_skills.md), 명중·치명·출혈 피해 계산은 [07](07_attributes.md), 테스트는 [06](06_vertical_slice.md)을 참조한다.

## 1. 액티브 입력 — [합의]와 [미결] 분리

| 입력 | 행동 | 상태 |
|---|---|---|
| **빈 바닥 좌클릭** | 클릭한 위치로 이동 | **[합의]** |
| **적 좌클릭** | 좌클릭 슬롯에 등록된 스킬 사용 | **[합의]** |
| **Shift+좌클릭** | 이동 없이 현재 커서의 적/지면에 **좌클릭 슬롯 스킬 강제 시전** | **[합의]** |
| **우클릭·Q·W·E·R** | **입력을 누르는 순간 커서 위치·대상을 기준으로 등록 스킬을 즉시 시전** | **[합의]**. 스킬 유형별 구체적 대상 해석은 §1.1 |

- 액티브 슬롯은 좌클릭·우클릭·QWER **총 6개**. 시작 좌클릭 슬롯에는 **마나 소모 0인 기본 공격**이 장착된다. 이후 다른 기술로 바꿀 수 있으며 숨겨진 일곱 번째 스킬 슬롯은 없다.
- **[합의] 숫자 1·2·3·4는 물약 퀵슬롯**이며 액티브 6슬롯과 별개다. 물약 규칙은 [04 §8.2](04_items.md).
- **[합의] 좌클릭에 등록된 기술이 마나 부족으로 시전 불가하면 그 사용만 기본 공격으로 대체**한다. 등록된 스킬은 바뀌지 않는다.
- **[합의] 우클릭·QWER의 마나 부족은 발동 실패**이고 자동 기본 공격으로 대체하지 않는다.
- **[미결]** 마나 외 실패 조건(쿨다운, 유효 지점 없음, 사거리 부족)에서 좌클릭 대체를 허용할지, 클릭 유지/반복, 사거리 밖 적을 일반 좌클릭했을 때 이동 후 공격 여부, Shift 강제 시전의 사거리 밖 처리.

### 1.1 우클릭·QWER의 커서 즉시 시전 — [합의]

**[합의·2026-10-25]** **우클릭과 Q·W·E·R 키는 누르는 순간의 커서 위치/대상을 기준으로 바로 시전**한다. 키를 누른 뒤 별도 마우스 클릭으로 대상/지면을 다시 확정하는 **2단계 조작은 사용하지 않는다**. 우클릭과 QWER는 이 표적 판정 원칙을 공유한다.

| 슬롯에 등록된 스킬 유형 | 키 입력 순간의 동작 | 상태 |
|---|---|---|
| 적 지정 공격·표적 중계기 | **커서 아래 유효한 적**을 표적으로 지정해 실행 | **[합의]** |
| 고정형 포탑·함정 등 지면 설치 | 커서가 가리키는 **유효 지면 위치**에 설치 | **[합의]** |
| 이동형 자동인형 등 소환 | 적 위 커서면 **초기 표적** 지정, 지면 위 커서면 **표적 없이 자율행동**. 실제 생성 위치는 항상 플레이어 옆 | **[합의된 입력 + 기존 소환 방향]** |
| 자신에게 적용하는 강화·공구 토글 | 별도의 적/지면 표적 없이 **키 입력 즉시 발동** | **[합의된 즉시 입력 원칙]** |

**[미결·구현 예외]** 대상 지정 스킬에서 유효한 적이 없을 때, 지면이 사거리 밖이거나 설치 불가능할 때, 적 모델이 설치 지면을 가릴 때, 유효한 사거리까지 자동 이동할지, 누르고 있기·연속 시전·오입력 피드백 등. **이런 예외가 남아 있어도 '키를 누른 순간 커서 기준, 추가 클릭 없음'은 확정 규칙**이다.

## 2. 소환·설치와 표적 — [사용자 제안·현재 방향]

| 유형 | 시전 위치/지정 | 생성 위치 | 이후 행동 |
|---|---|---|---|
| **이동형 소환** | 적 지정 | **플레이어 옆** | 그 적을 첫 표적으로 공격 후 자율행동 |
| **이동형 소환** | 빈 지면 지정 | **플레이어 옆** | 즉시 자율행동 |
| **고정형 포탑·함정** | 유효 지면 지정 | **지정한 지면** | 독립 작동, 일정 시간 후 해체 |

- **[현재 방향]** 이동형 소환수는 화면 밖까지 적을 추적하지 않고 **플레이어 방향으로 복귀**한다. 카메라 화면 경계에서의 복귀 완충 폭은 [제안·미결].
- **[합의]** 좌클릭 슬롯에 소환을 장착한 경우에도 **Shift+빈 지면 좌클릭**으로 자율 소환/설치가 가능하다. Shift+적 좌클릭으로 이동형 소환의 첫 표적을 지정할 수도 있다.
- **[현재 방향] 표적 중계기**는 공격 가능한 소환수에게 지정 적을 집중 공격하게 하고, 스킬 레벨이 높아지면 **그 지정 적에 대한 피해가 소폭 증가**한다. **[제안]** 명령 우선순위: 중계기 > 소환 시 첫 표적 > 자율행동. 이동형의 화면 경계·고정형의 사거리 제한은 명령으로 우회하지 않는다.
- **[미결]** 표적 명령 해제/지속, 추적 종료, 카메라 경계, 설치 불가 지점, 일점사할 수 없는 수리형 소환체 처리.
- 태엽인형의 **기본형(전투 후 자폭) / 즉시 자폭 특화 / 지속공격 특화**와 거대 자동인형의 **단일 강화 / 다수 특화** 같은 **개별 스킬 동작은 [03 스킬 문서](03_skills.md#53-첫-스킬-태엽인형-기본-혼합형과-양자택일-특화)가 원본**이다.

## 3. 공구 변형 상태·마나 흐름 — [합의]

- 공구 변형은 **토글 + 유지 중 마나 지속 소모**이다. 기본 지팡이 ↔ 볼트커터·그라인더·전기톱 등으로 전개한다. **동시에 한 공구만** 활성화할 수 있다.
- 기본 공격은 공구 변형에 따른 근접 타격을 수행할 수 있다. 공구별 모션/효과와 **집중 공격·광역 공격**의 세부 스킬 설계는 [03](03_skills.md)을 참조한다.
- 다른 기술(화기·자동화·생존·처형)을 사용해도 **활성 공구가 해제되지 않으며 유지 마나 소모가 계속된다**.
- 정상 전투 이외의 사망/지역 전환 시 토글 종료는 별도 [미결]이다.

| 상황 | 다음 상태 |
|---|---|
| 기본 지팡이에서 공구 A 전개 성공 | 공구 A 유지·마나 소모 시작 |
| **같은 공구 A를 다시 사용** | 기본 지팡이로 수동 해제 |
| **다른 공구 B 전개 성공** | A 대신 B 유지 |
| **마나가 0에 도달** | 자동 해제·기본 지팡이로 복귀 |
| 처형·화기·자동화 등 **다른 스킬 사용** | 공구 유지(마나 0에 도달하지 않은 경우) |

### 3.1 마나 고갈의 플레이 체감 — [검증 필요, 신규 제안]

**[확인된 규칙 조합]** 토글 유지비와 기술 사용비가 함께 마나를 고갈시키면 **공구 자동 해제 + 우클릭·QWER 스킬 실패**가 겹칠 수 있다. **좌클릭에는 마나 부족 시 기본 공격 대체**가 존재하지만, 마나 회복 정책에 따라 일정 시간 공격 선택지가 빈약해질 수 있다.

- **[06 시험판 검증 항목]** 장기 교전에서 마나가 0이 되는 순간 전개·해제·스킬 실패의 피드백이 명확한지, 마나가 다시 차면 원래 스킬을 정상 사용 가능한지, 자주 '아무것도 못 하는 구간'이 발생하는지 측정한다.
- **[미결]** 마나 자연 회복·장비/패시브 보충·토글 유지비·기본 공격의 전투 성능·마나 부족 UI([09](09_ui.md)에서 표시 방식 검토)·실패 우선순위, 자동 해제 직전 시전 처리 순서. 이를 해결하려고 기존 자원 부족 규칙을 임의로 바꾸지 않는다.

## 4. 피해·상태이상 및 장비의 규칙 원본

- 명중·치명타·광역 판정·**출혈의 방어무시, 적 등급 계수, 중첩 5회 시험값, 개별 지속시간** 등 피해 판정은 **[07 · 스탯·피해 판정](07_attributes.md)**만을 따른다. **이 문서에서 별도 중첩 공식이나 퍼센트를 복제하지 않는다.**
- **둔화·방어력 감소·출혈**이 서로 함께 유지되는 스킬별 부여 여부와 효과는 [03](03_skills.md)에서 정의한다. 공구 교체로 이미 걸린 상태가 즉시 제거되지 않는다. 같은 종류의 **둔화·방깎 반복 중첩은 미결**이다.
- 장비와 패시브가 올리는 FCR·IAS·FHR 및 소프트캡 제안은 **[04 · 아이템·장비](04_items.md)**이 원본이다.
- 세 트리는 단독으로 일반 사냥·보스전에 대응 가능해야 하며, 넉백·경직·그로기·생존/CC 등은 단순 피해 증가와 구분되어야 한다. **구체적인 보스 제어 저항·기본 회피/가드 규칙은 미결**이다.

## 5. 검증 계획

이 문서는 **규칙만 정의**한다. 조작·마나 고갈·상태 이상·빌드 다양성을 어떻게 시험할지는 [06 · 첫 시험판](06_vertical_slice.md)에 **테스트 조건과 통과 기준**으로 기록한다. 현행 승인 사항을 바꾸려면 이 원본만 갱신하고 다른 문서는 링크한다.
