# UI·화면 구성

> **현행 v0.3 · 2026-10-25.** 전투 HUD와 메뉴 화면 배치의 단일 원본. 각 요소가 따르는 규칙은 해당 원본 문서를 링크한다(입력·마나 [02](02_combat.md), 아이템·물약 [04](04_items.md), 피해 판정 [07](07_attributes.md)). 확정하지 않은 내용은 [제안]/[미결]로 표시한다.

## 1. 화면 배치 — [합의]

| 위치 | 표시 | 상태 |
|---|---|---|
| **적 머리 위** | 일반 적의 체력과 디버프 | **[합의]** |
| **화면 상단** | **정예·보스**의 체력과 디버프 | **[합의]** |
| **화면 상단** | 플레이어의 **버프·디버프·공구 토글** 아이콘 | **[합의]** |
| **캐릭터 머리 위** | 마나 부족·발동 실패 등 **짧은 안내 문구**(§3.1) | **[합의]** |
| **하단 바** | **물약 4칸 · 스킬 6칸 · 각 메뉴 버튼** | **[합의]** |
| **화면 전체에 겹침** | 미니맵(§6) | **[합의]** |

- **[제안]** 상단을 둘로 나눈다. **가운데는 정예·보스 정보**, **왼쪽은 플레이어 상태 아이콘**. 보스 정보와 내 상태가 서로 가리지 않게 한다.

```
 [버프·디버프·토글 아이콘]      [ 보스 이름 · 체력 · 디버프 ]

                  "마나가 부족합니다"
                    (캐릭터)
                 적 머리 위: 체력·디버프

 ▮HP  [1][2][3][4]  [좌][우][Q][W][E][R]  [캐릭터][스킬][인벤][퀘스트]  MP▮
```

## 2. 피해 숫자 — [합의]

- **[합의] 피해 숫자를 띄우지 않는다.** 화면이 싸 보이는 것을 피한다.
- **[제안]** 숫자 대신 타격감으로 전달한다. 치명타는 타격 이펙트·사운드·짧은 화면 반응으로 일반 타격과 구분하고, 광역 공격의 적별 치명타([07](07_attributes.md))도 각 적의 반응으로 보이게 한다.
- **[제안]** 플레이어가 빌드를 비교할 수 있도록 **캐릭터 정보창**에는 공격력·치명타 확률·속도 등의 수치를 보여 준다.
- **[제안]** 개발 중에는 [06](06_vertical_slice.md) B3·B8처럼 피해를 재야 하는 검증이 있으므로 **개발자 전용 피해 표시**를 따로 둔다. 플레이어에게는 노출하지 않는다.

### 3.1 마나 부족·발동 실패 안내 — [합의]

- **[합의]** 음성은 아직 넣지 않는다. 마나 부족·발동 실패는 **캐릭터 머리 위에 짧은 텍스트**로 띄운다.
- **[제안]** 문구는 짧게 고정한다. 예: "마나가 부족합니다", "대상이 없습니다", "너무 멉니다", "설치할 수 없습니다".
- **[제안]** 같은 문구가 연달아 뜨지 않게 짧은 간격(예: 1초) 동안은 한 번만 표시한다. 좌클릭이 마나 부족으로 기본 공격으로 대체될 때([02](02_combat.md))는 문구 없이 스킬 칸 표시만 바꿔 전투 흐름을 끊지 않는다.
- 사거리 밖·대상 없음 같은 **실패 조건 자체**는 [02 §1.1](02_combat.md)의 미결이며, 이 절은 표시 방식만 다룬다.

## 4. 하단 바 메뉴와 단축키 — [합의]

| 순서 | 메뉴 | 단축키 |
|---|---|---|
| 1 | 캐릭터 (정보·스탯 배분) | **C** |
| 2 | 스킬트리 | **S** |
| 3 | 인벤토리 (장비 7칸 포함) | **I** |
| 4 | 퀘스트 | **L** |

- 위 네 키는 스킬(좌·우·QWER)·물약(1234)·Shift 강제 시전([02](02_combat.md))과 겹치지 않는다.
- **[제안]** 설정 메뉴는 버튼 대신 **Esc**로 연다.
- 첫 시안(전투 필드만, [06 §0](06_vertical_slice.md))에서는 쓰지 않는 메뉴(퀘스트 등)를 비활성으로 두거나 숨긴다.
- **[시험 구현·2026-10-30]** C1·C2 검증용으로 **캐릭터(C)·스킬트리(S) 임시 창**을 넣었다. 하단 바 버튼 없이 단축키로만 열고, 화면 위에 떠 있는 패널이며 열어 둔 채로 전투가 계속된다. 배치·모양은 시험용이고 §7의 메뉴 화면 미결을 정한 것이 아니다. 스킬트리창 아래 「슬롯 등록」에서 우클릭·Q·W·E·R에 스킬을 고르는 것도 시험용이다.

- **[사용자 결정·2026-11-02] 메뉴 화면은 디아블로식으로 정리한다.** 아직 임시 UI지만 방향은 다음과 같다.
  - **인벤토리:** 장비마다 차지하는 칸이 다른 격자 가방. 인벤토리를 정리하는 재미를 의도한다(호불호가 갈리는 요소임을 알고 고른 것).
  - **장비 그림:** 희귀 아이템은 이름만으로 부위를 알기 어렵고 이름이 겹치기도 하므로, 아이템마다 그림을 보여 준다. 지금은 코드로 그린 임시 그림이다.
  - **이름 파편:** 클릭해서 들고 소켓에 끼우는 방식. 진명이 깨어나면 아이템 이름에 그 이름이 들어간다([04 §6](04_items.md)).
  - **스킬트리:** 트리 모양으로 정리하고, 구현되지 않은 스킬은 비활성으로 보이게 한다.
  - **글자는 되도록 띄우지 않는다.** 그림·숫자로 보이고 설명은 마우스를 올렸을 때만 뜬다(스킬트리 노드도 이름 대신 아이콘 + 레벨, 단축키는 아이콘을 끌어다 놓기). 아이템 버리기는 따로 칸을 두지 않고 들고 창 밖을 클릭한다. 바닥 아이템은 클릭해서 줍는다(걸어 지나가면 줍지 않음). 인벤토리가 열려 있으면 주운 장비는 가방 대신 커서에 든다.
- **[시험 구현·2026-11-02]** 위 방향으로 인벤토리(I)와 스킬트리창(S)을 다시 만들었다. 조작과 크기는 [실행 안내](godot_prototype.md)에 있고, 칸 크기·배치·그림은 임시다.
- **[사용자 선택·시험 구현·2026-11-02] 아이템 이미지:** 기본 장비 20종·고유 2종·물약 13종에 생성한 투명 PNG를 연결했다. 가방·착용 칸·집은 아이템과 하단 물약 슬롯에서 같은 이미지를 사용하며, 희귀도·소켓·등급·수량은 별도로 표시한다. [35종 전체와 실제 화면](../reports/inventory_art_v1/review.html), [제작·검증 기록](../assets/ui/inventory_v1/README.md). 축소 필터와 소형 물약 크기 보정 후 사용자가 현재 외형을 선택하고 커밋을 요청했다.
- **[사용자 요청·시험 구현·2026-11-02] 물약 가방:** 아이템창의 「물약」 탭은 5×3 가방과 그 아래 1~4번 퀵슬롯을 보여 준다. 물약 그림·등급·개수로 표시하며 이름과 조작 안내는 마우스를 올리면 나온다. 클릭으로 묶음을 집어 가방이나 퀵슬롯에 놓는다. 가방 안에서는 자리 이동·교환, 같은 종류의 퀵슬롯에는 합치기, 다른 종류에는 기존 묶음과 교환한다(가방에서 넣으면 이전 물약은 가방으로 돌아옴). 슬롯에서 가방으로 빼거나 슬롯끼리 옮길 수도 있다. 우클릭·창 밖 클릭·다른 탭·창 닫기·재시작은 선택을 취소하며 물약을 버리거나 사용하지 않는다. 기존 임시 구매 목록은 슬롯 아래 스크롤 영역에 유지한다. 보관 용량·중첩·사용 규칙은 [04 §8.2](04_items.md#82-물약--합의)를 따른다.
- **[사용자 요청·시험 구현·2026-11-02] 분해 모드:** 빈손으로 모루를 클릭하면 분해 모드를 켜고 끈다. 켜진 동안 모루·커서와 가방에서 가리킨 아이템을 붉게 표시하며, 가방 아이템 좌클릭은 해당 아이템을 바로 분해한다. **분해 모드에서 아이템을 Shift+클릭하면 가방의 일반·마법 장비를 모두 분해**한다(희귀·고유 및 착용 장비 제외). 빈 칸이나 모루 Shift+클릭은 일괄 분해가 아니다. 아이템을 들어 모루 칸에 놓는 기존 방식도 유지한다. 우클릭·창 닫기·다른 탭 선택·이름 파편 선택·재시작으로 모드를 해제한다. 착용 칸은 분해 모드에서 변경하지 않는다. 분해 재료와 끼워 둔 파편 반환은 기존 [04 §9](04_items.md)의 시험 규칙을 따른다.
- **[사용자 요청·시험 구현·2026-11-02] 바닥 아이템 선택:** 장비·이름 파편·물약·각인전은 모두 주변의 걸을 수 있는 빈자리에 간격을 두고 놓으며, 허리 높이에서 회전하며 0.4초 동안 바닥으로 떨어진다. 이름 라벨은 화면에서 서로 겹치지 않게 배치하고 드롭 후 5초가 지나면 숨긴다(일시정지 중에는 시간·낙하 모션 정지). 숨겨진 아이템에 마우스를 올리면 그 라벨만 다시 나오며, 아이템이나 보이는 라벨 위에 있는 동안 아이템의 밝기·테두리와 라벨 배경·테두리를 함께 강조한다. 연결선은 표시하지 않는다. **Alt를 누르는 동안만 전체 라벨을 표시하며, 떼면 기존 숨김 상태로 즉시 돌아간다.** Alt는 각 아이템의 표시 시간을 초기화하지 않으며, 실제 아이템 위에 마우스가 있으면 해당 라벨만 보인다. 창과 하단 HUD 뒤의 아이템은 강조하지 않는다. 남은 전리품이 있으면 필드 완료 안내를 상단의 작은 배너로 표시한다. 획득·보관은 [04 §9](04_items.md)를 따른다.

## 5. 클래스별 UI 모양

- **[사용자 제안·현재 방향]** HUD의 모양을 클래스에 따라 다르게 표현하는 방향을 검토한다. 예를 들어 기계장치는 톱니·놋쇠 계기판, 유리는 유리 조각, 재봉은 실과 천.
- **[주의]** 배치와 정보 위치는 클래스가 달라도 같게 유지하고, **장식만 바꾼다.** 클래스를 바꿔도 같은 자리에서 같은 정보를 찾을 수 있어야 한다.

### 5.1 체력·마나 게이지 — [합의]

- **[합의] 세로 막대형 게이지.** 디아블로식 구슬은 지나치게 닮아 쓰지 않는다.
- **[합의]** 모든 클래스가 **세워 둔 유리 막대**를 공통으로 쓰고, 그 막대를 **받치거나 감싸는 장식**을 클래스에 어울리게 디자인한다. 위치는 하단 바 양 끝으로 클래스와 관계없이 같다.
- **[제안]** 유리 막대 안의 액체로 현재 값을 보여 주고, 물약으로 **차오를 양은 옅은 색의 액체 층**으로 미리 보여 준다(§3). 장식이 액체 높이를 가리지 않게 한다.
- **[제안] 장식 예시:** 기계장치는 놋쇠 받침과 톱니·압력 밸브, 유리는 유리 세공 틀, 재봉은 실로 감은 천 받침. 첫 시안은 기계장치용 하나만 만든다.

## 6. 미니맵 — [합의]

- **[합의] 디아블로식 겹침 지도.** 별도 작은 창이 아니라 **화면 위에 반투명하게 깔리는** 방식이다.
- **[제안]** **Tab**으로 켜고 끈다. 지도가 켜져 있어도 전투 조작은 그대로 가능하다.
- **[제안]** 표시 대상: 지나온 지형, 플레이어, 포탈·웨이포인트([05](05_content.md)), 정예·보스 위치는 시야 안일 때만.

## 7. 미결

- **[미결]** 클래스별 게이지 장식의 구체적 디자인.
- **[미결]** 메뉴 화면(위 §4의 디아블로식 방향 외의 세부: 장비창 7칸·소켓, 툴팁의 기본 옵션/접두·접미/단계 표시와 비교, 스킬트리 A/B 특화, 스탯 배분, 무료 초기화, 제작·파편 제거, 상점, 캐비닛, 웨이포인트 목록)의 배치.
- **[미결]** 화면 해상도와 UI 크기 조절, 단축키 변경 기능.
