# 첫 시험판(버티컬 슬라이스) — 검증 계획

> **현행 v0.3 · 2026-10-25 · [제안]**. 이 문서는 **무엇을 검증하고 어떤 결과를 기록할지**만 정의한다. 스킬·피해 공식·입력 규칙을 복제하지 않는다.

## 1. 우선 검증할 가설

1. **조작:** 클릭 이동과 6개 액티브, 이동형 소환과 지면 설치를 입력 충돌 없이 다룰 수 있는가?
2. **마나 흐름:** 공구 토글 중 마나가 바닥나도 스킬 사용과 전투 복귀가 지나치게 답답하지 않은가?
3. **성장 선택:** 화기·구동·자동화의 손맛이 달라지고, 스킬 랭크 집중과 선택적 A/B 특화가 모두 경쟁력이 있는가?
4. **피해 판정:** 명중·치명·출혈의 계산이 의도대로 작동하며, 보스에게 출혈이 과도하게 강하거나 무용지물이 되지 않는가?
5. **육성·파밍:** 무료 스킬/스탯 초기화와 아이템 옵션 교체가 실제로 다양한 빌드를 시도하게 만드는가?

## 2. 단계 A — 조작·자원 프로토타입 (가장 먼저)

**범위 제안:** 기계장치의 마녀 1명, 적 1종, 단순 시험장, 기본 공격·산탄포·공구 변형·태엽인형·포탑/함정 대용 설치기 일부. 구체적 입력·상태 전이의 원본은 [02](02_combat.md), 스킬 특화는 [03](03_skills.md).

| ID | 재현할 상황 | 통과 기준 |
|---|---|---|
| **A1** | 좌클릭 이동·적 공격·Shift+좌클릭 강제 시전 | 이동과 스킬 발동이 혼동되지 않음 |
| **A2** | 우클릭·QWER에 표적형 공격/이동형 소환/지면 설치를 각각 등록 | 대상과 지면 선택이 일관됨. **커서 해석 규칙은 사용자 결정 전 [차단 항목]** |
| **A3** | 이동형 소환을 적 위·빈 땅에 사용하고, 설치기를 지면에 사용 | 초기 표적·생성 위치·유효 위치 피드백이 자연스러움 |
| **A4** | 공구 토글 유지 중 다른 기술 사용·공구 변경·마나 소진 | 상태 전환이 원본 규칙과 일치하고 오류 없이 복귀 |
| **A5** | 장기 교전에서 토글 유지비+연속 스킬 사용으로 마나 0 유도 | 기본 공격은 계속 가능하고, 실패·변형 해제·재사용 가능 시점이 명확함. **'아무 기술도 못 쓰는 구간'의 빈도와 불편감 관찰** |

**A단계 차단/미결:** [02 §1.1 우클릭·QWER 입력](02_combat.md) 확정, 사거리 밖·설치 불가 위치 처리, 마나 자연 회복·토글 유지 비용·재사용 대기. 미결 규칙을 게임 확정 사양인 것처럼 구현하지 않는다.

## 3. 단계 B — 공격·상태이상·성장 선택

**원본:** [03 스킬](03_skills.md), [07 명중·치명·출혈 피해](07_attributes.md), [05 적 등급](05_content.md).

| ID | 검증 상황 | 평가할 사항 |
|---|---|---|
| **B1** | 일반 명중형과 확정 적중/광역 기술로 동일 적 공격 | 공간 판정과 확률 MISS 분리가 자연스러운지 |
| **B2** | 광역 스킬로 여러 적을 동시 타격 | **적별 치명타 독립 판정**이 이루어지는지 |
| **B3** | 전기톱 직접 타격 후 출혈 적용, 방깎 병행 | **타격과 출혈의 피해 계산이 분리**되는지 |
| **B4** | 일반/강화/정예/보스 후보에 출혈 적용 | 등급별 비율이 출혈 효율을 유지하면서 보스 폭주를 막는지 |
| **B5** | 출혈을 여러 번 적용한 뒤 중첩 하나가 먼저 만료되도록 함 | **잠정 5중첩 상한·후속 기여도 감소·중첩별 타이머 독립 만료**가 작동하는지 |
| **B6** | 같은 스킬의 노드 미투자/A/B 특화 비교 (태엽인형 우선) | 각 형태가 경쟁력 있는 별도 운용법인지 |
| **B7** | 절삭 정밀화→칼날형 인형, 탄도 계산→발사체 포탑 | **기계 원리 태그**에만 교차 패시브가 적용되는지 |

**[설계 차단 항목] B3/B4/B5의 수치 밸런스를 확정하기 전** [07 §2.3](07_attributes.md)에 남긴 **출혈과 '위력' 스탯·스킬 레벨의 관계**를 결정해야 한다. 이를 정하지 않으면 스탯·스킬 투자 효율을 정상적으로 검증할 수 없다.

**수치 미결:** 출혈 등급별 비율, 실제 중첩 감소 가중치, 5중첩 초과 적용 처리, 타이머 길이, 치명·명중 계수, 보스 피해 총량. **지금 단계에서 임의 확정하지 않는다.**

## 5. 시험 범위와 보류

**초기 가안:** 허브 하나·짧은 전투 지역 하나·일반 적 2~3종·강적 1종·보스 1종, 핵심 스킬 일부와 소수 매개체 아이템. 이 수치는 **시험 범위 제안이지 고정 사양이 아니다**. 먼저 A를 통과하고 B, C로 확장한다.

**의도적으로 제외:** 모든 스킬/아이템 대량 제작, 완성된 장편 시나리오·여러 클래스, 정밀 피해 수치의 사전 확정, 전체 드롭 경제, 완성 모델링·의상과 시각효과의 대량 제작.

**의사결정 순서:** (1) **우클릭·QWER 조작** → (2) **마나 고갈 체감 및 회복** → (3) **출혈과 위력·스킬 레벨의 관계** → (4) 전투 수치 조정. 규칙을 바꿔야 할 경우 이 시험판 문서가 아니라 위 **원본 문서**를 수정한다.
